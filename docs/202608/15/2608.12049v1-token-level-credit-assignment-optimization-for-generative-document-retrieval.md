## 摘要
生成式检索模型通过自回归生成文档标识符（DocIDs）来执行文档检索。该过程天然构成一个序列决策问题，其中每个解码步骤选择一个DocID词元，完整的词元序列决定检索到的文档。然而，检索效果通常仅在完整DocID生成后才能评估，这导致了词元级生成与文档级相关性监督之间的不匹配。因此，现有的用于生成式检索的强化学习方法大多依赖序列级奖励，将相同的文档级反馈传播到所有解码步骤。这种粗粒度的反馈难以识别哪些词元决策导致了检索成功或失败。在这项工作中，我们提出了一种用于生成式检索的细粒度强化学习框架，采用词元级相关性奖励。我们不是为整个生成的DocID分配单一奖励，而是通过衡量每个词元决策如何改变相应生成轨迹的预期检索质量来估计逐步奖励。这实现了更精确的信用分配，并鼓励策略倾向于更直接有助于文档级相关性的词元决策。我们进一步开发了针对DocID生成过程量身定制的实用奖励估计策略，并将其整合到策略优化框架中。在检索基准上的实验表明，我们的方法一致优于序列级奖励基线，证明了细粒度监督在将自回归DocID生成与检索目标对齐方面的有效性。

## Abstract
Generative retrieval models perform document retrieval by autoregressively generating document identifiers (DocIDs). This process naturally forms a sequential decision problem, where each decoding step selects a DocID token and the complete token sequence determines the retrieved document. However, retrieval effectiveness is typically evaluated only after the full DocID is generated, creating a mismatch between token-level generation and document-level relevance supervision. As a result, existing reinforcement learning methods for generative retrieval mostly rely on sequence-level rewards, where the same document-level feedback is propagated to all decoding steps. Such coarse-grained feedback makes it difficult to identify which token decisions are responsible for successful or failed retrieval.   In this work, we propose a fine-grained reinforcement learning framework for generative retrieval with token-level relevance rewards. Instead of assigning a single reward to the entire generated DocID, we estimate step-wise rewards by measuring how each token decision changes the expected retrieval quality of the corresponding generation trajectory. This enables more precise credit assignment and encourages the policy to favor token decisions that contribute more directly to document-level relevance. We further develop practical reward estimation strategies tailored to the DocID generation process and incorporate them into a policy optimization framework. Experiments on retrieval benchmarks show that our method consistently outperforms sequence-level reward baselines, demonstrating the effectiveness of fine-grained supervision for aligning autoregressive DocID generation with retrieval objectives.

## 1. 核心问题与整体含义

### 研究动机与背景

- **生成式检索（Generative Retrieval）** 将文档检索建模为序列生成问题：模型自回归地生成文档标识符（DocID），再将生成的 DocID 映射回文档。该范式可以统一索引与检索过程，近年来成为信息检索领域的重要研究方向。
- **存在一个根本性的粒度错配（Granularity Mismatch）**：模型逐 token 生成 DocID，但检索质量只在完整 DocID 生成后才以文档级相关性进行评估。标准的 token 级监督（如交叉熵）与文档级评估目标之间存在断层——一个包含多个局部合理 token 的 DocID 仍可能指向不相关文档，而某些中间 token 决策对最终检索结果的影响也各不相同。
- **现有强化学习方法仍受此问题困扰**：已有方法（如 GenRRL、DDRO）通常使用**序列级奖励**，即将同一个文档级相关性信号均等地传播给所有解码步骤。这种粗粒度信用分配无法区分哪些 token 决策真正促成或损害了检索成功。
- **核心论点**：有效对齐生成式检索需要**词元级（token-level）信用分配**——奖励的设计应当与逐 token 的决策粒度匹配，每一个 DocID token 对期望检索质量的边际贡献都应当被单独评估。

## 2. 方法论

### 核心思想

提出 **TCA（Token-Level Credit Assignment for Generative Retrieval）**，一个与优化器无关的细粒度强化学习框架。TCA 的核心思路是：**通过比较生成序列的隐藏状态轨迹与黄金 DocID 的轨迹，为每个 token 分配独立的奖励**，从而为策略优化提供密集且结构化的反馈信号。

### 技术流程

采用两阶段训练管道：

- **阶段一：监督微调（SFT）**。使用标准 teacher forcing 交叉熵损失训练基础生成式检索器，使模型获得基本的 query→DocID 生成能力。支持两种 DocID 类型：**TU（Title+URL）** 和 **PQ（Product Quantization 语义码）**。
- **阶段二：带 token 级信用分配的强化学习**。SFT 模型被冻结为参考模型，并预先缓存黄金 DocID 在 teacher forcing 下生成的隐藏状态轨迹 ℎ*ₜ；当前策略在 trie 约束解码下生成候选 DocID，记录其隐藏状态 ℎⁱₜ，并计算每个位置的奖励。

### 关键公式与技术细节

**Token 级奖励设计**由三部分构成：

- **轨迹奖励**：衡量生成隐藏状态与黄金隐藏状态在同一位置上的余弦相似度：  
  `r_traj(i,t) = cos(h(i,t), h*(t))`
- **长度惩罚**：当生成 DocID 超过黄金长度时，每个超额位置施加惩罚 λ_len = −0.5。
- **精确匹配奖励**：若生成 DocID 与黄金 DocID 完全一致，则在所有有效位置加上全局命中奖励 R_hit。

**两种优化器实现（核心贡献）**：

- **TCA-GRPO**：将 token 级奖励在组内（G 个候选 DocID）按解码位置进行归一化后得到 token 级优势函数 A_GRPO(i,t)，再使用带裁剪的策略目标更新策略。其 KL 正则将策略约束在 SFT 参考模型附近。
- **TCA-PPO**：使用相同的 token 级奖励，但改用**值函数基线 + GAE** 估算 token 级优势。值函数头附加在解码器隐藏状态之上，用于估计从当前 DocID 前缀出发的期望累积奖励。

### 方法定位

TCA 是**优化器无关**的信用分配框架——GRPO 与 PPO 均可作为底层策略优化器。框架无需额外训练奖励模型，且天然兼容约束解码，适用于不同 DocID 设计。

## 6. 主要结论与发现

1. **TCA-GRPO 一致超越强基线**：
   - MS MARCO-TU：R@1 = 39.60，MRR@10 = 51.10，相比 DDRO 分别提升约 3.56% 和 1.53%。
   - NQ-PQ：R@1 = 50.02，MRR@10 = 56.10，相比 DDRO 分别提升约 3.99% 和 3.28%。
2. **token 级奖励确实优于序列级奖励**：在同一 GRPO 优化器下，将序列级奖励替换为 token 级奖励带来一致的额外收益。
3. **TCA 是优化器无关的**：TCA-PPO 也能提升性能，但 TCA-GRPO 更稳定、更好，说明组相对优势估计更适合生成式检索的排名导向特征。
4. **改进主要集中于顶部精度**（R@1、MRR@10），对广泛召回（如 R@10）的提升有限。
5. **约束解码对 RL 训练至关重要**：无约束 rollout 会显著损害性能（NQ-PQ 上 R@1 下降约 5 个百分点）。
6. **KL 系数设置与 DocID 类型强相关**：TU 型需要少量 KL（β=0.01）保持词法模式，PQ 型完全无需 KL（β=0）即可最佳。

## 7. 优点

- **问题识别精准**：清晰指出了生成式检索中"逐 token 生成、文档级评估"的粒度错配，并给出合理的序列决策建模。
- **方法设计轻量优雅**：奖励通过**冻结参考模型的隐藏状态轨迹对比**获得，无需额外训练奖励模型，兼容不同 DocID 类型。
- **优化器无关性强**：同一奖励框架同时支持 GRPO 和 PPO，验证了方法的通用性。
- **深入细致的消融研究**：系统分离了奖励粒度、优化器选择、约束解码、组大小、KL 系数等因素的独立影响，逻辑链条完整。
- **案例分析具有解释力**：直观展示了 TCA 如何提升早期和后期的 gold token 概率，与候选空间在前期更为广阔的观察吻合，验证了方法的行为机制。

## 8. 不足与局限

- **训练流程复杂**：依赖两阶段管道（SFT + RL），需要预计算黄金轨迹、维护冻结参考模型，工程复杂度较高。
- **训练开销大**：RL 阶段需要 rollout 生成和逐 token 奖励计算，作者承认增加了非平凡（nontrivial）的训练成本，但未提供具体效率数据与对比。
- **收益集中于顶部指标**：对 R@5、R@10 的提升不如 R@1 和 MRR@10 明显，在高召回场景中的适用性有待验证。
- **模型规模与场景覆盖有限**：实验仅基于 T5-base，未验证在更大规模 LLM 上的有效性；数据集仅覆盖 MS MARCO 与 NQ，缺乏 BEIR 等更具挑战性的零样本基准。
- **KL 系数依赖人工调节**：不同 DocID 类型需要不同的 β 设置，增加了方法的调参成本。
- **参考基线复现公平性受限**：GenRRL、ROGER 等基线直接引用原论文结果，与本文复现的 DDRO 等基线的实验配置可能存在细微差异。
- **长期动态语料场景未涉及**：未讨论文档集合变化时黄金轨迹缓存的有效性和更新策略。
