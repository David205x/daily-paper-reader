## 摘要
在长时程环境中训练大型语言模型智能体，需要将稀疏的最终结果归因于各个动作。现有的无评论家方法在步骤间均匀传播轨迹级奖励，而近期方法通过匹配重复状态构建步骤级分组，并在每组内比较动作。前者无法将失败轨迹中的有效动作与成功轨迹中的无效动作区分开来。后者依赖于直接从单个轨迹结果导出的步骤信用，以及与片段级信用进行固定权重融合。我们提出Gated-BEPO，它从经验回放图中推导步骤级信用。对于每个回放组，Gated-BEPO构建一个经验图，并通过反映当前策略经验动作分布的均值备份贝尔曼不动点来估计节点值。然后，我们使用广义优势估计沿每条采样轨迹累积这些时间差分残差，得到同时捕获即时和下游影响的步骤级贝尔曼优势。为了自适应地融合片段级和步骤级信用，置信门仅在具有多个观测后继状态的状态处纳入贝尔曼信用，否则使用片段级信用。在WebShop、ALFWorld和视觉Sokoban上的实验表明，在语言和视觉语言模型上均取得了一致的改进，而诊断性消融研究支持了贝尔曼不动点值估计的有效性，并表明步骤级信用应有选择地而非均匀地纳入最终优势。

## Abstract
Training large language model agents in long-horizon environments requires assigning credit from sparse terminal outcomes to individual actions. Existing critic-free methods propagate trajectory-level rewards uniformly across steps, while recent approaches construct step-level groups by matching repeated states and compare actions within each group. The former cannot distinguish useful actions in failed trajectories from ineffective actions in successful ones. The latter rely on step credit derived directly from individual trajectory outcomes and fixed-weight fusion with episode-level credit. We propose Gated-BEPO, which derives step-level credit from empirical rollout graphs. For each rollout group, Gated-BEPO constructs an empirical graph and estimates node values through a mean-backup Bellman fixed point that reflects the empirical action distribution of the current policy. We then accumulate these temporal-difference residuals along each sampled trajectory using generalized advantage estimation, yielding step-level Bellman advantages that capture both immediate and downstream effects. To adaptively fuse episode- and step-level credit, a confidence gate incorporates Bellman credit only at states with multiple observed successors and otherwise uses episode-level credit. Experiments on WebShop, ALFWorld, and visual Sokoban show consistent improvements across language and vision-language models, while diagnostic ablations support the effectiveness of Bellman fixed-point value estimation and show that step-level credit should be incorporated selectively rather than uniformly into the final advantage.

# Gated-BEPO 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：在长时程（long-horizon）交互环境中训练大语言模型（LLM）智能体时，终端奖励非常稀疏，需要将有限的成功/失败信号**归因到序列中的每一个具体动作**，即信用分配（credit assignment）问题。
- **现有方法的不足**：
  - 无评论家方法（如 GRPO）将**轨迹级回报均匀分配给所有步骤**，无法区分"失败轨迹中的有效动作"与"成功轨迹中的无效动作"，导致学习缓慢、收敛性能低。
  - 最近的步骤级方法（如 GiGPO、HGPO、GAGPO、GraphGPO）虽然尝试构建更细粒度的信用，但存在以下问题：
    - 直接从**单个轨迹结果**推导步骤信用，未有效建模跨轨迹共享的下游转移结构；
    - 步骤信用与片段信用采用**固定权重融合**，缺乏"何时该用步骤信用、保留多少片段信用"的自适应机制；
    - GraphGPO 的图距离信用估计在面对**感知混淆（perceptual aliasing）**——即相同观测对应不同潜在状态——时表现脆弱。
- **论文意义**：提出 Gated-BEPO，在**无评论家（critic-free）** 前提下，从经验 rollout 图中恢复信息丰富的步骤级信用信号，并通过**置信门控**决定何时、以多大权重使用步骤级信用，显著提升长程 agent 任务上的学习效率和最终性能。

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体框架

Gated-BEPO 将**组相对结果优势（outcome advantage）**与**不动点步骤优势（fixed-point step advantage）**通过置信门控混合：

```
Â_i = η_i · Â_out_i + w · ρ(s_i) · Â_FP_i
```

- `Â_out_i`：轨迹级组相对优势（按组标准化）；
- `Â_FP_i`：基于 Bellman 不动点的步骤级优势；
- `ρ(s_i) ∈ {0,1}`：图置信门，决定是否启用步骤信用；
- `η_i`：自适应结果信用权重；`w`：步骤信用相对权重。

### 2.2 经验图构建与 Bellman 不动点

- 对每个 rollout 组，将**相同观测合并为同一状态节点**，保留转移次数（多重边）。
- 定义状态 `s` 的出边多重集：`E(s) = {(r_i, s'_i) : s_i = s}`。
- 使用**均值备份 Bellman 更新**估计节点值（无需学习评论家）：

```
V^(k+1)(s) = (1/|E(s)|) · Σ_{(r,s')∈E(s)} [ r + γ·V^(k)(s') ]
```

- 以蒙特卡洛回报初始化，迭代至收敛（γ<1 保证压缩映射，存在唯一不动点）。
- 该均值备份反映**当前策略的经验动作分布**，而非乐观的 max/softmax 备份。

### 2.3 TD 残差与 GAE 传播

- 对每条记录计算**不动点 TD 残差**：`δ_i = r_i + γV(s'_i) − V(s_i)`。
- 不动点处同一状态内残差和为零：`Σ_{i:s_i=s} δ_i = 0`，故残差衡量"该边相对该状态经验平均的优劣"。
- 沿原始轨迹用 **GAE** 累积传播：

```
Â_FP_i = δ_i + γλ · Â_FP_next(i)
```

- 门控在 GAE **之后**施加，因此下游不支持状态的残差仍可向上游传递延迟信用。

### 2.4 置信门控（Confidence-Gated Credit Mixing）

- 定义状态访问数 `n(s)` 与不同后继数 `|Succ(s)|`：

```
ρ(s) = 1  if  n(s) ≥ n_min 且 |Succ(s)| ≥ b_min; 否则 0
```

- 默认 `n_min = b_min = 2`，即要求**至少两个不同后继**，同时隐含重复访问。
- 结果信用权重自适应降低：`η_i = η_min + (1−η_min)(1−ρ(s_i))`，默认 η_min=0.5。
- 含义：有经验备选分支时激活步骤信用并降低轨迹信用占比；无分支证据时完全依赖结果信用，防止无依据的局部估计污染更新。

### 2.5 优化目标

- 计算组相对结果优势并记录级标准化，混合后广播给有效响应 token。
- 使用标准 **PPO 裁剪目标**更新策略，仅改变优势估计器，不改变优化框架。

## 6. 主要结论与发现

1. **Gated-BEPO 在成功率上全面超越现有无评论家方法**：
   - WebShop 成功率相对 HGPO 提升 3.51%（1.5B）和 4.17%（7B）；
   - ALFWorld 总成功率相对 HGPO 提升 2.78%（1.5B）和 2.95%（7B）；
   - Sokoban 达到 80.0%，超 GiGPO 3.13%；
   - 训练曲线显示收敛速度更快、最终成功率更高。
2. **步骤级信用应当"选择性"而非"均匀"地纳入优势估计**：置信门控比无门控均匀使用步骤信用带来显著提升（73.8% vs. 66.4%）。
3. **均值备份 Bellman 不动点是可靠的无评论家值估计器**：相比 max/softmax 等规划式备份，均值备份对稀有/混淆转移更鲁棒。
4. **结果信用不能完全放弃**：保留适当比例的结果信用（η_min=0.5）作为全局稳定信号，优于完全依赖步骤信用。
5. **对感知混淆的鲁棒性**：Gated-BEPO 在原始观测（保留混叠）下依然有效，而 GraphGPO 几乎无法学习。

## 7. 优点

- **方法新颖性**：
  - 首次在无评论家 LLM agent RL 中引入**经验图上的均值备份 Bellman 不动点**值估计，既避免了训练 critic 的成本和不稳定，又优于简单图距离信号。
  - **置信门控机制**从"是否使用步骤信用"和"使用多大权重"两个维度做出数据驱动的自适应决策，而非固定融合。
  - 门控与 GAE 传播的**解耦设计**（post-GAE gate）保留了下游延迟信用向上游传递的路径。
- **实验严谨性**：
  - 对 GraphGPO 同时运行"增强观测"和"匹配原始观测"两种协议，区分了"方法公平竞争"与"混叠敏感性诊断"两个不同问题。
  - 对门控形式、阈值、备份算子、迭代预算、GAE 衰减、混合规则等关键设计维度做了全面消融。
  - 补充了训练诊断（熵、梯度范数、优势尺度、响应长度等），排除训练不稳定、奖励作弊等混杂因素。
- **计算开销小**：优势计算仅占每步训练的 ~0.16%，几乎无额外成本。
- **泛化性好**：方法在文本（ALFWorld/WebShop）与视觉（Sokoban）环境、不同模型规模（1.5B/3B/7B）不同模型家族（Qwen2.5/Qwen3）均有效。

## 8. 不足与局限

- **实验覆盖范围有限**：
  - 只评估了 3 个环境，均为离散动作空间；未涉及更复杂的连续控制或大规模真实网页交互。
  - 消融实验仅使用 Qwen2.5-1.5B 单种子，可能存在对特定模型/种子的过拟合风险。
- **与最新方法对比不足**：
  - 未与 VinePPO（过程奖励/值函数类）等方法对比。
  - GraphGPO 论文的原始设置使用环境增强观测，匹配原始观测下其性能非常低，这种差距是否代表方法本身的缺陷或实现细节差异有待澄清。
- **感知混淆问题未彻底解决**：虽然通过均值备份和门控缓解了混叠的负面影响，但没有从根本上恢复隐藏状态（论文也承认这一点），此时结果信用分支仍然只是"减少损害"而非"消除误合并"。
- **门控的适用条件有限**：当观测是高度唯一、状态极少重复时，门控会关闭几乎所有步骤信用，退化为 GRPO 风格结果信用，该方法在"极少状态共享"的场景中的有效性尚未验证。
- **训练时长未报告**：论文未给出端到端训练总时间，难以评估实际计算成本的整体规模。
- **局限性**：由于论文来自 arXiv 预印本，部分引用文献年份较新（2026年），即使核心方法有扎实的数学基础，其大规模复现性和在更大模型（如 70B+）上的表现仍待验证。

## 9. 总结

Gated-BEPO 提出了一种新颖且实用的无评论家步骤级信用分配方案：通过经验图的均值备份 Bellman 不动点估计状态值，以 TD 残差 + GAE 生成细粒度步骤优势，再以"观测到分支"为置信依据自适应融合轨迹级与步骤级信用。该方法在文本和视觉长程 agent 任务上都取得了显著且一致的性能提升，实验设计与消融分析相当严谨。其核心洞见——"步骤信用应当被有选择地使用，而非均匀混合"——对后续 LLM agent RL 的信用分配研究具有参考价值。
