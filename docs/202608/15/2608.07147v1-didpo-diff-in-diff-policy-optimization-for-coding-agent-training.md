## 摘要
基于可验证奖励的强化学习（RLVR）已成为训练编码智能体的强大范式，其中来自编译和测试的执行反馈提供了客观验证。然而，与智能体任务不同，编码智能体面临独特且更细粒度的信用分配挑战：在每一步中，编码操作同时将不同的变化打包到代码版本的不同区域，这使得独立变化的贡献难以区分。现有的RLVR方法大多利用结果奖励或步骤级奖励，未能深入代码差异（diff）中，使得编码动作的独特属性对训练不可见。在本文中，我们提出了差分策略优化（DiDPO），一种基于评论家（critic-free）的强化学习方法，直接从代码差异的结构中构建细粒度的信用单元。DiDPO将多轮编码交互组织为多个思考-行动步骤，并在采样的轨迹中发现代码差异。然后，它通过聚合由我们的"可分组性分数"从每个整体差异中划分出的高度相似的子差异来选择锚点，该分数提供的划分模式能够最优地平衡锚点的语义范围和它们可能形成的组质量。最后，这些锚点形成优势组，并将差异级别的优势映射回单个响应令牌。在长时程编码和推理基准上的实验表明，DiDPO显著优于强智能体强化学习基线。在Qwen2.5-7B-Coder上，DiDPO超过可比方法10%以上，并缩小了与更大模型的差距，为编码智能体训练中的细粒度信用分配提供了一个原则性框架。我们还开源了verl-code，一个支持多种强化学习方法和编码基准的智能体强化学习代码库。

## Abstract
Reinforcement learning with Verifiable Reward (RLVR) has emerged as a powerful paradigm for training coding agents, where the execution feedback from compilation and tests provides objective verification. However, unlike agent tasks, coding agents face a unique and finer-grained credit assignment challenge: at each step, coding actions simultaneously pack varying changes into different regions of a code version, which makes the contribution of independent change indistinguishable. Existing RLVR methods mostly leverage the outcome reward or step-level reward, which fails to dive into a code diff and makes unique properties of coding actions invisible to training. In this paper, we propose Diff-in-Diff Policy Optimization (DiDPO), a critic-free RL method that constructs fine-grained credit units directly from the structure of code diffs. DiDPO organizes multi-turn coding interactions into multiple thought--action steps and discovers code diffs across sampled trajectories. It then selects anchors by aggregating highly similar sub-diffs split from each whole diff by our ``groupability score'', which provides the splitting schema that optimally balances the semantic scope of anchors and the group mass they may form. Finally these anchors form advantage groups and project the diff-level advantage back to individual response tokens. Experiments on long-horizon coding and reasoning benchmarks show that DiDPO significantly outperforms strong agentic RL baselines. On Qwen2.5-7B-Coder, DiDPO exceeds comparable methods by over 10\% and narrows the gap with far larger models, offering a principled framework for fine-grained credit assignment in coding agent training. We also open-source verl-code, an agentic rl codebase that supports various RL methods and coding benchmarks.

- **核心问题**：在编码智能体的每一步中，一个编码动作往往同时向代码的不同区域打包多种修改（即一个 diff 可能包含多个功能各异的子 diff）。现有 RLVR 方法主要使用**结果级奖励**或**步骤级奖励**，无法深入到代码 diff 内部，导致编码动作的独特结构属性对训练不可见，独立修改的贡献难以区分。
- **具体挑战**：
  1. 编码动作与代码片段捆绑，且代码片段随任务难度和项目规模扩张；
  2. 单个 diff 可能包含多个语义不同的子 diff，整体 diff 的处理会掩盖真正产生收益的语义单元；
  3. 代码受严格语法、执行和 pass/fail 标准约束，微小的错误编辑可能影响长轨迹，需要特殊关注。
- **整体含义**：该论文旨在回答“如何为代码 diff 构建动态、更细粒度的信用单元，以更好地将智能体 RL 应用于编码任务”这一问题，并提出了一个无评论家（critic-free）的 RL 优化框架。

## 2. 论文提出的方法论

### 2.1 核心思想

- 提出 **DiDPO（Diff-in-Diff Policy Optimization）**，利用代码 diff 自身的层级结构构造细粒度信用单元。
- 在保留轨迹级组相对优势的同时，进一步解析每个编码动作产生的 diff。
- 跨多条采样轨迹识别高度相似的子 diff，将其作为“锚点”（anchors），并据此对 diff 进行拆分和分组，从而将 diff 级别的优势传播到对应的 response token 上。
- 无需额外的 critic 模型，也无需额外环境 rollout。

### 2.2 关键技术步骤

- **Diff 的可分割性**：将轨迹中的所有 diff 聚合，并附加元数据 `(u(s), v(s), w(s), q(s))`，分别表示规范化文本、token 跨度、动作类型（add/del/none）和所属任务。
- **动态子 diff 锚点**：枚举每个 diff 的连续子片段，通过相似度矩阵匹配不同轨迹中的相似子 diff（限制相同编辑类型）。匹配后的子 diff 聚合为锚点 c。
- **Groupability Score（GS）**：定义了锚点的“可分组性分数”：
  \[
  GS(c) = \left(1 - e^{-\bar{L}(c)}\right)\left(1 - e^{-(n(c)-1)}\right)
  \]
  其中 \(\bar{L}(c)\) 为锚点平均大小（语义范围），\(n(c)\) 为组内出现次数（组质量）。该分数在“锚点应足够大以承载语义”和“锚点应吸引足够多的组内元素”之间取得平衡。
- **锚点选择**：将锚点选择建模为**基数约束的子模最大化问题**（Eq. 10），用贪心算法求解，保证 \((1-1/e)\) 近似。
- **Diff 级优势计算**：选定锚点后，同一锚点的子 diff 组成优势组 \(G(C^*)\)，计算局部组相对优势：
  \[
  A_D(a^{(i)}_{t,m}) = \frac{R^{(i)}_t - \text{avg}(\{R^{(j)}_t \in G\})}{F_{\text{norm}}(\{R^{(j)}_t \in G\})}
  \]
- **最终优势与训练目标**：将轨迹级优势 \(A_E\) 与 diff 级优势 \(A_D\) 结合：
  \[
  \hat{A}_{i,l} = A_E(\tau^{(i)}) + \lambda \cdot A_D(a^{(i)}_l)
  \]
  并采用标准 PPO clipped 目标进行优化（Eq. 14）。

### 2.3 理论支撑

- 论文基于 Gromov-Hausdorff 视角定义了子 diff 之间的对应误差/距离，并给出两个定理：
  - **定理 4.1**：若局部奖励贡献 Lipschitz 连续且组内子 diff 与锚点的对应误差有界，则锚点匹配带来的局部信用信号偏差为 \(O(L\epsilon)\)。
  - **定理 4.2**：若轨迹回报可分解为子 diff 贡献加非因果噪声，则 DiDPO 的局部优势估计器 MSE 为 \(O(L^2\epsilon^2) + O(\sigma_\xi^2/m)\)，而整段广播估计器会保留 \(O(\sigma_\xi^2)\) 的噪声污染。这解释了“组质量”的统计作用：锚点质量控制偏差，跨 rollout 支撑降低方差。

## 6. 论文的主要结论与发现

- DiDPO 在两个骨干模型上均取得最优平均成绩：
  - Qwen2.5-Coder-7B：平均 48.4%，比最强基线 GiGPO 高 4.2；
  - Qwen3.5-4B：平均 58.6%，比 GiGPO 高 4.9。
- DiDPO 缩小了与 GPT-5.5 的差距：在 7B 骨干上从基线的 56.4 个百分点差距缩小到 43.3 个百分点。
- 在 USACO 上，DiDPO 在 7B 骨干上达到 15.6%，是 GRPO（6.8%）的两倍以上。
- 相比单纯推理/提示方法，DiDPO 在 APPS 上高出最佳推理方法 5.4，在 LiveCodeBench 上高出 12.8，表明 RL 带来的增益是提示方法无法获得的。
- 消融显示：轨迹级优势 \(A_E\) 不可或缺（去掉后 APPS 降至 10.4%）；diff 级优势 \(A_D\) 带来约 7.5 个百分点的独立增益；去掉 sub-diff 拆分（即用完整 diff 作为原子单位）会使性能下降 6.3 个百分点。
- 训练动态：训练早期以碎片（Fragment）组为主，后期功能性代码块（Block）组占比上升，符合 GS 设计目标。
- 效率：DiDPO 相对 GRPO 仅增加约 2.3% 的训练时间开销，且为训练期开销，推理不受影响。

## 7. 优点

- **方法创新性强**：首次将代码 diff 的内部层级结构引入 RLVR 信用分配，提出了“差分中的差分”思路，细化了编码动作的信用单元。
- **无需 critic 与额外 rollout**：所有分组基于已有采样轨迹，额外开销低（约 2.3%），实用性强。
- **理论扎实**：提供了偏差–方差分解的理论分析，从 Gromov-Hausdorff 距离和子模优化角度为方法设计提供了支撑。
- **实验较充分**：覆盖多个长时程竞赛类编程基准和消融设计，并与多种强基线（包括大模型和 agentic RL 方法）进行了对照。
- **开源推动**：提供 verl-code 代码库，支持多种 RL 方法和编码基准，可复现性较好。

## 8. 不足与局限

- **模型规模覆盖有限**：仅在 7B 和 4B 模型上验证，未证明对更大模型（如 27B 以上）的扩展性。
- **训练数据单一**：基于 PRIME 数据集扩充，且 pipeline 依赖 GPT-5.5/Qwen3.6-27B 生成数据，可能在数据分布上存在偏差。
- **基准样本量较小**：部分 benchmark（如 ICPC 106、LeetCode 112）规模较小，结果置信区间较宽。
- **LLM judge 的使用**：在组类型分类和数据分析中引入 LLM 判断，可能带有主观性和不稳定性。
- **相似度计算成本**：跨 rollout 的 sub-diff 相似度计算为二次复杂度，虽然通过阈值控制，但在更大规模训练中可能成为瓶颈。
- **应用场景限制**：目前主要面向算法竞赛类长程代码生成，对真实仓库级软件工程任务（如 SWE-bench）的有效性尚未验证；λ 参数需要调优，且对过大值敏感（容易过拟合局部信用）。
