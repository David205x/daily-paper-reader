## 摘要
强化学习（RL）搜索智能体通常将检索建模为自由形式的自然语言查询生成，并使用最终答案奖励来优化多轮交互。当前研究主要利用更密集或更结构化的信用信号来改进训练，但很少考察检索在策略-环境接口上是否被恰当表述。我们在Search-R1训练中观察到明显的检索混叠现象：针对同一问题的轨迹会持续生成不同的查询字符串，但它们累积的证据集却日益重叠。我们将此现象称为检索等价坍缩；在这种状态下，轨迹在检索决策方面趋近于效用等价，导致组内回报缺乏有效的检索对比。为解决该问题，我们提出Harness-G，一种重新设计该接口的图结构检索框架。它将自由形式的查询生成重新表述为有限动作选择：策略选择证据句子或实体，或选择回答，而环境负责构建菜单、跟踪检索状态，并验证和执行每个选择。该接口减少了语言混叠，并使同一状态下的备选动作可直接比较。基于该接口，我们引入了结构化非近视信用（SNC），它使用冻结的答案评分器将所选动作与其备选动作进行比较，并将下游收益分配给促成这些收益的早期动作。在六个问答基准测试中，Harness-G在两种评估模型规模下均取得了最高的平均F1分数，分别比最强基线Graph-R1高出10.74个百分点（1.5B）和3.98个百分点（3B）。

## Abstract
Reinforcement learning (RL) search agents commonly model retrieval as free-form natural-language query generation and optimize multi-turn interactions using final-answer rewards. Current studies mainly improve training with denser or more structured credit signals, but rarely examine whether retrieval is properly formulated at the policy-environment interface. We observe pronounced retrieval aliasing during Search-R1 training: rollouts for the same question continue to generate distinct query strings, yet their accumulated evidence sets increasingly overlap. We call this phenomenon retrieval-equivalence collapse; in this regime, trajectories approach utility equivalence with respect to retrieval decisions, leaving within-group returns with little effective retrieval contrast. To address this problem, we propose Harness-G, a graph-structured retrieval framework that redesigns this interface. It reformulates free-form query generation as finite action selection: the policy selects an evidence sentence or entity, or chooses to answer, while the environment constructs the menu, tracks retrieval state, and validates and executes each choice. This interface reduces linguistic aliasing and makes same-state alternatives directly comparable. Building on this interface, we introduce Structured Non-myopic Credit (SNC), which uses a frozen answer scorer to compare the selected action with its alternatives and assigns downstream gains to the earlier actions that enabled them. Across six QA benchmarks, Harness-G achieves the highest average F1 at both evaluated model scales, outperforming the strongest baseline, Graph-R1, by 10.74 points at 1.5B and 3.98 points at 3B.

## 2. 方法论：Harness-G 与 SNC

### 核心思想
- 将"自由查询生成"重定义为**图上的有限动作选择**：策略选择证据句子/实体/终止回答，环境负责构建查询、验证并执行，从而消除语言混叠，使同一状态下的备选动作可直接比较。

### 关键技术细节
1. **语料诱导三部分图（Paragraph–Sentence–Entity Tripartite Graph）**
   - 离线程序化构建，包含段落节点、句子节点、实体节点。
   - 边：段落-句子、句子-实体、句子-句子（相邻句）、实体-实体（同义/规范链接）。
   - 构建过程仅需句子切分、NER（spaCy）、稠密编码，**不调用生成式LLM**，成本低、可复用。

2. **菜单环境（Menu Environment）**
   - 每步策略从动态菜单中选择动作 ID，动作类型有：
     - `Select(s)`：提交可见句子到已提交证据集 C_t；
     - `Lookup(e)`：环境围绕实体 e 自动构造查询并检索，更新候选句子 U_{t+1}；
     - `Answer`：终止检索并根据 C_t 生成答案；
     - 可选 `Answer_With(s1,...,sk)`：提交并一步终止。
   - 环境负责过滤、去重、验证无效目标；菜单具有**有限性、可验证性、可预览性**。

3. **结构化非近视信用（SNC）**

## 6. 主要结论与发现

1. **Harness-G 显著超越基线**：
   - 1.5B 规模：平均 F1 50.83，比 Graph-R1 高 **10.74 点**；
   - 3B 规模：平均 F1 55.24，比 Graph-R1 高 **3.98 点**；
   - 在六个数据集上均获得最高平均 F1，且在所有数据集上取得优于或并列于 Graph-R1 的 G-E 分数。
2. **结构化导航特别有益于多跳 QA**：提升幅度在 2Wiki、HotpotQA、MuSiQue 上最大（3B 下分别 +7.97、+9.12、+5.95）。
3. **小模型获益更大**：限制动作空间对低容量模型帮助显著。
4. **接口设计本身就有价值**：仅将 free-query 换成菜单（无额外步信用），F1 就能提升超过 17 点（MuSiQue 上超 35 点）；IGPO 虽能稠密化 free-query 信用，但无法弥补接口差距。
5. **SNC 提供有效信用分配**：完整 SNC 在多跳数据集上优于 leave-one-out 和 λ=0 变体；去除 frontier 或 enablement 均会降低 F1。
6. **训练稳定且鲁棒**：跨数据集训练 F1 稳定上升，无持续崩溃；可适配不同骨干网络（Qwen2.5-3B、Qwen3.5-4B、Llama-3.2-3B）和不同 RL 算法（GRPO、PPO、REINFORCE++、DAPO）。
7. **交互效率高**：Harness-G 在后训练期使用更多轮次但更短的响应；SNC 无额外 rollout，开销小；图构造免 API 成本。
8. **泛化性好**：30 个 O.O.D. 对中胜出 21 个，平均 O.O.D. F1 提升 +3.29；在医学、农业、CS、法律等未见领域也能零样本转移。

## 7. 优点与亮点

- **问题诊断精准**：用“检索等价坍缩”定性和定量刻画了自由查询接口的根本缺陷。

## 8. 不足与局限

- **规模有限**：主要评估模型为 1.5B 和 3B，未测试更大规模（如 7B、70B）的效果。
- **文本领域局限**：作者自述当前为纯文本系统，未扩展到多模态证据；多模态是其展望的下一步。
- **基线公平性风险**：主结果中的 Graph-R1 等基线取自已发表数值，可能存在训练协议、超参数、检索工具等跨版本差异；虽然消融实验匹配，但整体对比的公平性仍有潜在偏差。
- **部分数据集劣势**：在 NQ 上 3B 设置下 F1 仍比 Graph-R1 低 1.84 点；说明方法并非在所有单跳问题上都占优。
