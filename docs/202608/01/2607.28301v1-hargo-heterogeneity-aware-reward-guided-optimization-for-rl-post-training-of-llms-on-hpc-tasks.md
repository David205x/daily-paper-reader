## 摘要
监督微调（SFT）能够为高性能计算（HPC）任务（如数据竞争检测和基准问答）赋予大型语言模型（LLM）领域知识。然而，知识本身并不能保证任务合适的行为：同一个SFT模型能正确分类88.65%的C/C++数据竞争样本，但对事实性查询却产生冗长、不精确的答案，其中65.9%的MLPerf响应超过40个字符。强化学习（RL）后训练通过优化任务特定奖励而非词元级模仿来弥补这一差距。然而，HPC任务表现出极端的异构性，二分类、事实性问答和语义生成在答案长度上相差58倍，跨越三种不同的奖励分布，并显示出差异巨大的SFT准确率。这使得GRPO等均匀权重RL方法并非最优。我们提出HARGO，即异构感知奖励引导优化，它通过置信度调制优势引入每个响应的重要性权重：从组级奖励对比中计算判别信号，从参考模型对数概率中计算置信度信号，然后在计算每个响应权重之前调制优势，而无需任务类型标签。在四个HPC任务和九种方法中，HARGO在所有三个主要指标上均取得最佳性能：WinRate 54.62%，数据竞争F1 91.30%，PLP相似度0.8558。消融实验证实了两种信号的互补贡献。对于异构HPC任务，HARGO在比较方法中建立了最佳的整体对齐质量。

## Abstract
Supervised fine-tuning (SFT) can equip large language models (LLMs) with domain knowledge for high-performance computing (HPC) tasks such as data race detection and benchmark question answering. However, knowledge alone does not guarantee task-appropriate behavior: the same SFT model that correctly classifies 88.65\% of C/C++ data race samples produces verbose, imprecise answers to factual queries, with 65.9\% of MLPerf responses exceeding 40 characters. Reinforcement learning (RL) post-training addresses this gap by optimizing for task-specific rewards rather than token-level imitation. Yet HPC tasks exhibit extreme heterogeneity, with binary classification, factual QA, and semantic generation differing by 58x in answer length, spanning three distinct reward distributions, and showing widely varying SFT accuracy. This makes uniform-weight RL methods such as GRPO suboptimal. We propose HARGO, Heterogeneity-Aware Reward-Guided Optimization, which introduces per-response importance weighting via confidence-modulated advantage: computing a discrimination signal from group-level reward contrast and a confidence signal from reference model log-probabilities, then modulating the advantage before computing per-response weights, without requiring task-type labels. Across four HPC tasks and nine methods, HARGO achieves the best performance on all three primary metrics: WinRate 54.62\%, Data Race F1 91.30\%, and PLP Similarity 0.8558. Ablation confirms complementary contributions from both signals. HARGO establishes the best overall alignment quality among compared methods for heterogeneous HPC tasks.

- **背景**：监督微调（SFT）可以将 HPC 领域知识注入 LLM（例如 HPC-GPT 对 LLaMA-13B 的微调），使模型在数据竞争检测、HPC 基准问答等任务上获得领域能力。但论文指出，*知识本身并不保证任务合适的行为*：同一个 SFT 模型在 C/C++ 数据竞争分类上达到 88.65% 的准确率，却在 MLPerf 事实性问答中产生冗长、不精确的回答（65.9% 的响应超过 40 字符）。
- **核心问题**：SFT 的教师强制目标将所有参考回答视为同等信息量，无法区分简洁准确与冗长部分正确的回答，也无法利用多个候选回答之间的对比信号，更无法针对特定错误模式（如数据竞争检测中的假阳性）进行优化。
- **关键挑战**：HPC 任务存在极端异构性——四项任务在答案长度上相差 58 倍，跨越三种奖励分布类型，SFT 基线准确率从 51% 到 100% 不等。这种异构性使得 GRPO 等均匀权重 RL 方法不能适配：同一训练循环必须处理学习信号差异巨大的批次。
- **整体含义**：论文主张，与其通过增加计算量来提升 RL 效果，不如在固定预算内通过自适应重加权梯度贡献来提高每个单位计算量的有效利用率，从而更好地对齐异构 HPC 任务的模型行为。

## 2. 论文提出的方法论：HARGO

### 2.1 核心思想

HARGO 在 GRPO 基础上引入**每响应重要性权重（per-response importance weighting）**，用两个互补信号衡量每个响应相对于组内其他响应的“学习价值”：

- **判别信号（discrimination, d）**：由组级奖励对比（即调制后的优势绝对值归一化）生成，用于识别哪些响应携带明显的奖励差异，从而提供强学习信号。
- **置信度信号（confidence, c）**：由参考模型的对数概率生成，用于区分“模型已经知道自己错了”的噪声响应与“违背所学知识”的真实错误响应。

### 2.2 关键技术细节

1. **GRPO 基线回顾**：
   - 对提示 \( q \)，采样 \( G \) 个响应，计算组相对优势：
     \[
     A_i = \frac{r_i - \bar{R}}{\sigma_R + \varepsilon}
     \]
   - GRPO 最终损失对所有响应做均匀平均（权重 \( 1/G \)），导致信息量大的响应与平凡响应获得相同梯度贡献。

2. **HARGO 的加权目标**：
   \[
   L_{\text{HARGO}} = \sum_i w_i L_i, \quad \sum_i w_i = 1
   \]
   其中 \( w_i \) 由两个信号联合决定。

3. **置信度调制优势（confidence-modulated advantage）**：
   \[
   A_{\text{mod},i} = A_i \times (1 + \alpha \cdot c_i), \quad \alpha = 0.3
   \]
   - \( c_i \in (0,1) \)，由 sigmoid 归一化参考模型对数概率与全局 EMA 基线之差得到：
     \[
     c_i = \sigma(\text{ref\_logp}_i - \text{ref\_logp}_{\text{global}})
     \]
   - 该设计使置信度**调制但不逆转**优势方向，梯度放大范围被限制在 GRPO 的 1 到 1.3 倍，避免了加法组合的正反馈循环和乘法组合的信号抑制问题。

4. **判别信号与权重计算**：
   \[
   d_i = \frac{|A_{\text{mod},i}|}{\max_j |A_{\text{mod},j}| + \varepsilon}
   \]
   \[
   w_i = \frac{d_i}{\sum_j d_j}
   \]
   - 如果组内所有优势近似为零（全对组），则触发均匀回退：\( w_i = 1/G \)。

5. **训练流程**（算法 1）：
   - 生成响应 → 计算奖励与参考对数概率 → 更新 EMA 基线 → 计算调制优势 → 计算权重 → 执行加权策略梯度更新（带 KL 惩罚）。

6. **无需任务标签**：所有信号均由训练过程中的内部量（奖励、参考模型对数概率）计算，适用于任意异构任务混合，无需知道当前批次属于哪个任务类型。

## 3. 实验设计

### 3.1 数据集与基准

- 使用 **HPC-GPT** 开源指令数据集（5,273 训练 / 584 评估，按任务 9:1 划分），涵盖四类任务：
  - **race_c**：C/C++ OpenMP 数据竞争检测（二分类：是/否）
  - **race_fortran**：Fortran OpenMP 数据竞争检测（二分类）
  - **mlperf**：HPC 基准事实性问答（数字/名称/短文本）
  - **plp**：编程语言处理描述性问答（长文本）
- 数据来源：DataRaceBench（数据竞争）和 MLPerf（基准问答）。

### 3.2 对比方法

共比较 **9 种方法**（7 种 RL 变体 + SFT 初始化 + HPC-GPT 基线）：

- 在线 RL：PPO、GRPO、DrGRPO、HARGO
- 离线偏好优化：DPO、KTO、SimPO
- 非 RL 基线：SFT（所有 RL 方法的起点）、HPC-GPT（仅 SFT）

所有方法从同一 Qwen2.5-0.5B-Instruct 检查点出发，经过相同 SFT 数据微调，共享相同的奖励函数，唯一变量是训练目标。

### 3.3 评估指标

- **主指标（3 个）**：
  - WinRate：相对 SFT 基线的偏好胜率（win + 0.5×tie）
  - Data Race F1：race_c 和 race_fortran 的宏平均 F1（独立于奖励函数的词边界提取）
  - PLP Similarity：plp 上生成响应与参考回答的平均余弦相似度（all-MiniLM-L6-v2）
- **辅助指标（2 个）**：
  - EM（mlperf 精确匹配）
  - MLPerf AvgScore（奖励函数得分）

## 6. 论文的主要结论与发现

1. **HARGO 在所有三个主指标上取得最优**：
   - WinRate：54.62%（比 HPC-GPT 高 4.79，比 GRPO 高 1.45）
   - Data Race F1：91.30%（比 DrGRPO 高 0.51）
   - PLP Similarity：0.8558（比 KTO 高 0.011）
2. **每任务准确率**：HARGO 在 race_fortran 上最高（94.90%），plp 达到 100%（并列第一），mlperf 排第三（56.04%，落后 GRPO 59.34% 和 KTO 56.59%）；DPO 在 race_c 上最好（90.27%）但整体 F1 最差（77.61%）。
3. **辅助指标上 KTO 领先**（EM 27.47%，AvgScore 0.4537），HARGO 居中（EM 17.58%，AvgScore 0.4000）。论文解释这是 HARGO 通过置信度调制将学习资源更多分配给 race 和 plp 任务导致的合理权衡。
4. **消融证实信号互补**：完整 HARGO（B3）的 WinRate（54.62%）高于仅 d（53.34%）和仅 c（53.60%），PLP 也提升（0.8558 vs 0.8480），而 F1 基本持平（91.30 vs 91.37）。
5. **高召回策略**：HARGO 在数据竞争检测中采用高召回策略（Recall 94.23%，FN=9 最少），虽然 Precision 88.55% 排名第 8，但 F1 最优，说明权衡是划算的。
6. **KL 系数的调节作用**：HARGO 使用 β=0.02（低于 GRPO 的 0.04 和 DPO/KTO 的 0.1），因为优势调制的有界缩放提供了内置正则化。

## 7. 优点

- **问题定义清晰**：用三个可量化的维度（答案长度 58 倍差异、奖励分布类型、SFT 准确率 51%–100%）刻画 HPC 任务的异构性，并指出均匀权重 RL 的结构性缺陷。
- **方法设计巧妙**：置信度调制优势在数学上保证了「调制不逆转」和「梯度有界」，避免加法组合的正反馈与乘法组合的信号抑制；同时所有信号均在训练内部计算，无需任务标签或额外模型，计算开销可忽略。
- **对比实验规范**：所有 RL 方法共享相同 SFT 检查点、相同奖励函数、相同数据划分，公平性较好；评估指标包含主/辅分离，且 F1 与 PLP 指标独立于训练奖励，减少了对训练奖励的过拟合评估偏差。
- **消融实验设计合理**：通过三个变体（d-only、c-only、完整）清楚展示两个信号的独立与互补贡献，并合理解释了 EM/AvgScore 下降的权衡原因。
- **可复现性**：公开了训练配置、数据集链接、模型检查点。

## 8. 不足与局限

- **规模有限**：模型仅 0.5B，未验证在更大模型（如 7B/13B）上的有效性；HPC-GPT 原始工作用 13B 模型，但本文对比中所有方法均使用 0.5B，虽可控但无法推断规模扩展行为。
- **计算资源仅单卡**：没有多卡分布式实验；论文虽强调计算效率，但缺乏与 GRPO 在相同计算预算下的训练时间/吞吐对比数据，无法量化 HARGO 的真实计算效率优势。
- **数据集单一**：仅使用 HPC-GPT 数据集，未在其他 HPC 基准（如 HPC-Coder、OMPGPT 等）或更广泛异构任务集合上验证；任务种类有限（二分类、短 QA、长 QA），缺少代码生成或性能优化等更复杂任务。
- **统计可靠性不足**：未报告多次随机种子的标准差，未做显著性检验，单次结果在相近指标下（如 F1 91.30 vs 90.79）可能不具备统计意义。
- **辅助指标与主指标间的权衡解释偏向性**：论文将 EM/AvgScore 降低归因于“合理的资源重分配”，但缺乏直接证据（如各任务梯度贡献统计），此解释带有一定推测性。
- **偏好数据的质量风险**：DPO/KTO/SimPO 的偏好数据由 SFT 模型自动生成并用奖励函数打分，没有人工标注；DPO 在 race_fortran 上大幅失败（73.25%）提示自动偏好数据可能对某些任务不可靠，论文对此处理有限。
- **奖励函数本身的缺陷**：对 plp 使用 sentence-transformer 相似度作为训练奖励，评估也使用相似度（尽管是不同模型），存在一定程度的间接过拟合风险；对 mlperf 的多级离散奖励规则可能无法反映真实问答质量。
- **未报告训练稳定性指标**：只声称 WinRate 单调提升，未展示训练曲线、KL 漂移或奖励收敛情况。
- **创新性相对增量**：HARGO 是对 GRPO 的加权扩展，与现有基于优势加权的相关方法（如基于熵或置信度的自适应加权）相比，缺乏更直接的理论解释和更广泛的对比。
