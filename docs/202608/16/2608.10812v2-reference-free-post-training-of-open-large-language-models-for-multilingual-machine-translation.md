## 摘要
我们研究了使用开源大语言模型进行多语言机器翻译的无参考后训练。从监督微调的MiLMMT-46-v0.1模型开始，我们应用组相对策略优化（GRPO），奖励函数为两个无参考质量估计模型的平均值，并通过语言识别进行门控。然后我们对监督微调（SFT）和强化学习（RL）模型检查点进行线性插值，得到MiLMMT-46-v1.0。在46种语言中，所得模型相比其SFT对应模型持续提高了翻译质量，超越了近期强大的开源基线模型（包括Seed-X、HY-MT2和TranslateGemma），并在评估的专有系统（如Google Translate、Gemini 3 Pro和GPT-5）中取得了领先的无参考得分。我们进一步研究了在策略蒸馏（OPD），发现它达到但未超过通过RL与检查点插值实现的质量前沿。我们发布了模型和代码以促进未来研究。

## Abstract
We study reference-free post-training for multilingual machine translation with open large language models. Starting from the supervised-finetuned MiLMMT-46-v0.1 models, we apply Group Relative Policy Optimization (GRPO) with a reward that averages two reference-free quality estimation models and is gated by language identification. We then linearly interpolate the supervised fine-tuning (SFT) and reinforcement learning (RL) model checkpoints to obtain MiLMMT-46-v1.0. Across 46 languages, the resulting models consistently improve translation quality over their SFT counterparts, outperform strong recent open baselines, including Seed-X, HY-MT2, and TranslateGemma, and achieve leading reference-free scores against evaluated proprietary systems such as Google Translate, Gemini 3 Pro, and GPT-5. We further investigate on-policy distillation (OPD) and find that it reaches, but does not surpass, the quality frontier achieved by RL with checkpoint interpolation. We release the models and code to facilitate future research.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：开源大语言模型（LLM）已在多语言机器翻译中展现出强大潜力，通过持续预训练和监督微调（SFT）即可获得不错的翻译能力。然而，SFT 的进一步优化高度依赖高质量平行语料，而这类语料在低资源语言和非英语中心翻译方向上严重稀缺且分布不均衡。
- **核心矛盾**：相比之下，源语言文本更容易大规模获取，但传统监督学习无法直接利用无参考的源数据。因此，论文提出**无参考（reference-free）后训练**范式：不依赖参考译文，而是利用模型自身生成的译文与源句，通过质量估计模型作为奖励信号进行强化学习优化。
- **整体含义**：该研究旨在验证一条可扩展的翻译模型优化路径——在仅有源文本的情况下持续提升多语言翻译质量，降低对平行语料的依赖，为开源多语言翻译系统的后训练提供新的技术方案。

## 2. 方法论

### 核心思想
从 SFT 模型出发，使用 **GRPO（Group Relative Policy Optimization）** 进行强化学习，奖励由两个无参考质量估计模型给出，并用语言识别进行门控；随后对 SFT 与 RL 检查点做**线性插值**，在保留 SFT 所学行为的同时融入 RL 带来的质量提升。

### 训练目标（GRPO）
- 对每个源句 x 采样 G 个候选译文，采用 token 级重要性比率与裁剪项，并加入对 SFT 参考策略的 KL 惩罚（系数 β）以防止策略漂移。
- 优势函数 ˆA 由组内奖励归一化得到，GRPO 无需额外价值模型。

### 奖励设计
- 使用 **XCOMET** 与 **COMETKiwi** 两个参考无关 QE 模型的平均分作为基础奖励。
- 用 **OpenLID-v3** 预测译文语言，若与目标语言不一致，奖励直接置 0；该**语言识别门控**用于抑制"流畅但语言错误"的输出，防范奖励黑客攻击。

### RL 数据
- 从 MiLMMT SFT 数据中保留源句与翻译方向、丢弃参考译文，初始得到 263,982 条实例（192 个翻译方向）。
- 通过组内奖励筛选（0.30 < 均值 < 0.95 且标准差 ≥ 0.05）保留有足够奖励区分度的 31,572 条实例（30,572 训练 / 1,000 验证）。

### SFT–RL 检查点插值
- 采用线性插值 θα = αθSFT + (1−α)θRL，无需额外训练即可在 spBLEU 与基于参考的 XCOMET 之间进行可控权衡。
- 三个规模统一取 α = 0.5 作为 MiLMMT-46-v1.0。

## 6. 主要结论与发现

1. **无参考 RL 持续有效**：三个规模下，v1.0 相比 v0.1 在 WMT24++ 上 XCOMET 平均提升约 2.75 分、COMETKiwi 约 2.44 分；FLORES+ 上参考相关 XCOMET、参考无关 XCOMET、COMETKiwi 均提升，但 spBLEU 平均下降约 1.21 分（论文认为这是可接受的词汇重叠损失）。
2. **12B 模型达到领先水平**：MiLMMT-46-12B-v1.0 在无参考指标上全面超越 Google Translate、Gemini 3 Pro、GPT-5 等专有系统；在参考相关 XCOMET 上也排名前列。
3. **小模型同样有效**：1B 模型在多数指标上超越 TranslateGemma-4B；4B 模型可与 Tower-Plus-72B、HY-MT2-30B-A3B 等更大模型竞争。
4. **插值是可控质量权衡**：α=0.5 在恢复 spBLEU 与保留神经指标提升之间取得良好平衡；α 增大时 spBLEU 单调上升、XCOMET 单调下降。
5. **OPD 达到但不超越 RL+插值**：蒸馏可以将 12B 教师的质量增益迁移到 1B/4B 学生，但并未拓展质量前沿，因此被定位为替代方案而非改进方案。

## 7. 优点与亮点

- **方法创新**：将"语言识别的奖励门控"与"SFT–RL 检查点插值"结合，有效缓解了参考无关 RL 中常见的奖励黑客与策略漂移问题。
- **实用性强**：RL 数据完全来自源句，不依赖任何新增平行语料，且检查点插值无需额外训练即可得到多个质量权衡版本，工程成本低。
- **实验扎实**：覆盖 46 语言、3 个规模，对比对象包含当前最强的开源与专有系统，按共享语言子集分组比较保证了公平性；附录提供了大量可复现细节。
- **开源贡献**：模型与代码均已公开，有助于社区复现和后续研究。
- **奖励筛选策略**：通过组内奖励均值与标准差筛选训练实例，提高了 RL 样本效率。

## 8. 不足与局限

- **参考指标下降**：RL 后 spBLEU 明显下降，论文将其解释为"合法替换措辞被单参考惩罚"，但未通过人工评估或更多参考译本来验证这一解释，存在一定不确定性。
- **指标依赖风险**：优化目标完全依赖 XCOMET/COMETKiwi 两个 QE 模型，这些模型本身可能存在系统性偏好；论文对奖励模型偏差的鲁棒性分析不足。
- **算力信息缺失**：未披露 GPU 数量、训练时长、能耗等关键资源信息，影响可复现性评估。
- **语言覆盖局限**：46 语言仍以中高资源语言为主，低资源语言（如 kk、km、lo、my、uz 等）的实例数量较少，RL 训练数据筛选后部分方向的样本可能极少（如 es→en 仅 1 条训练数据），对低资源方向的结论需谨慎。
- **蒸馏实验未超越**：OPD 虽作为替代方案，但无法突破 RL+插值的上限，说明 RL 带来的增益难以完全通过蒸馏传递。
- **未涉及多模态与更大规模**：论文仅在文本翻译、最大 12B 规模上验证，多模态翻译与更大模型上的适用性留待未来研究。
