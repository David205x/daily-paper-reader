## 摘要
自然语言用户偏好为大型语言模型个性化提供了一种可解释的接口。然而，通用的偏好摘要通常包含与特定下游任务无关的信息。直接提供完整偏好摘要会浪费上下文容量并引入跨任务干扰，而手动设计任务特定偏好视图难以扩展。在本研究中，我们研究任务特定偏好适应：给定通用用户偏好摘要和下游任务，推导一种任务条件化表示，在保留足够决策相关证据的同时移除冗余上下文。为此，我们提出AlignXada，一种无需训练的元学习框架，通过语言强化学习诱导可重用的文本细化策略，将通用偏好摘要适应为任务特定摘要。在13个任务和三个下游模型（39个任务-模型单元）中，AlignXada实现了平均3.82分的提升，改善了33个单元，同时仅保留原始配置文件标记的22.8%，并在36个单元中优于RAG。扩展的忠实性分析进一步表明，细化后的配置文件在很大程度上仍源于源偏好，同时保留与任务相关的个性化信号，表明配置侧适应可作为通用记忆构建的实用补充，用于终身个性化代理。

## Abstract
Natural language user preferences provide an interpretable interface for LLM personalization. However, universal preference summaries often contain information irrelevant to a particular downstream task. Directly supplying the full preference summary therefore wastes context capacity and introduces cross-task distraction, while manually designing task-specific preference views is difficult to scale. In this work, we study \emph{task-specific preference adaptation}: given a universal user preference summary and a downstream task, derive a task-conditioned representation that preserves sufficient decision-relevant evidence while removing redundant context. To this end, we propose \textsc{AlignXada}, a training-free meta-learning framework that induces reusable textual refinement policies for adapting universal preference summaries to task-specific ones. The refinement policy is iteratively optimized by a meta learner through verbal reinforcement learning. Across 13 tasks and three downstream models (39 task--model cells), \textsc{AlignXada} achieves an average gain of 3.82 points, improving 33 cells while retaining only 22.8\% of the original profile tokens and outperforming RAG in 36 cells. An extended faithfulness analysis further shows that the refined profiles remain largely grounded in the source preferences while preserving task-relevant personalization signals, suggesting that profile-side adaptation serves as a practical complement to universal memory construction for lifelong personalized agents.

- **研究空白**：
  - 手动为每种任务设计任务特定的偏好视图（task-specific preference view）不可扩展；

### 2. 论文提出的方法论：核心思想、关键技术细节、流程

**核心思想**：不训练任何模型，而是通过**语言强化学习**（Verbal Reinforcement Learning）在文本空间内迭代优化一个**可复用的自然语言细化策略**（refinement policy），由该策略指导一个冻结的改写器（refiner）将通用偏好摘要改写为任务特定偏好摘要。

**关键技术细节与流程**（对应 Algorithm 1）：

- **两阶段框架**：策略归纳（few-shot policy induction）→ 策略部署（policy deployment）。
- **问题形式化**：
  - 支持集：$S^{(\tau)} = \{(P_{u_i}, x_i, y_i)\}_{i=1}^{b}$，其中 $P_{u_i}$ 为通用偏好、$x_i$ 为输入、$y_i$ 为参考答案；
  - 目标任务：$\max E_{(P_{u_i},x_i,y_i)\sim S^{(\tau)}} [\text{Score}_\tau(M(x_i, \tilde{P}_{u_i}), y_i)]$；
  - 改写器 $R$ 保持冻结，任务适应形式为 $\tilde{P}_{u_i} = R(P_{u_i}, \phi^{(\tau)})$，其中 $\phi^{(\tau)}$ 是待学习的文本策略。
- **Rollout（评估）流程**：每轮 $t$：
  1. 当前策略 $\phi_t$ 指导改写器 $R$ 对支持集每个用户生成改写配置 $\tilde{P}_{u_i,t}$；
  2. 冻结的下游模型 $M$ 基于 $\tilde{P}_{u_i,t}$ 和输入 $x_i$ 生成预测 $\hat{y}_{i,t}$；
  3. 用任务特定评分函数计算得分 $s_{i,t}=\text{Score}_\tau(\hat{y}_{i,t}, y_i)$；
  4. 同时在不与支持集重叠的开发集 $D^{(\tau)}$ 上计算策略效用 $J_{D^{(\tau)}}(\phi_t)$，存入历史 $\mathcal{H}$。
- **Update（更新）流程**：
  - 聚合模块将 rollouts 整理成**结构化反馈** $E_t$（含平均得分、实例级预测、低分样本的失败模式等）；
  - 冻结的元学习器 $\pi_{\text{meta}}$ 根据当前策略和反馈生成新策略：$\phi_{t+1} = \pi_{\text{meta}}(\phi_t, E_t)$；
  - 元学习器被要求遵循预定义策略模式，做最小必要修改，避免过拟合到单个样例。
- **策略选择**：所有轮次结束后，从历史中选择开发集上效用最高的策略作为最终策略 $\phi^{(\tau)} = \arg\max_{\phi_t \in \mathcal{H}} J_{D^{(\tau)}}(\phi_t)$。
- **自适应采样（Appendix B）**：将候选样本按"原始/改写结果组合"划分为 improved / regressed / stable-success / persistent-failure 四类转移状态，每轮均匀分配支持集预算，以提高反馈的覆盖度和均衡性。
- **全流程模型冻结**：元学习器、改写器、下游模型全部冻结，唯一变化的是策略文本。

### 6. 论文的主要结论与发现

1. **AlignXada 能持续改善性能与上下文效率的权衡**：
   - 39 个单元中改进 33 个，平均提升 +3.82 点（Qwen3-8B：+2.27；DeepSeek-V4-Flash：+7.00；GPT-5-mini：+2.19）；

2. **任务导向偏好重组优于查询级检索**：AlignXada 在 36 个单元上胜过 RAG（平均优势 +7.28 点），而 RAG 本身平均比原始配置低 3.46 点。
3. **最优偏好表示依赖任务与模型**：不同下游模型在同一任务上的增益有符号反转，说明从下游反馈学策略必要且有效。
4. **在更干净的源原生基准上依然有效**：PersonaMem-v2 平均提升 +1.30 点（9 任务中赢 7）、MemoryCD 平均 +1.69 点（4 任务全赢）。
5. **忠实度高，主要短板在源配置证据覆盖**：
   - 97.5% 的细化配置声明由原始配置支持，非幻觉率 97.9%，非矛盾率 99.8%；
   - 源配置对金标证据的覆盖只有 34.0%，条件于源配置包含证据时细化配置保留率达 83.3%。
6. **超参数规律**：更大的反馈批次（$b=20$）带来更可靠的策略归纳；大部分任务在 5 轮内收敛，但部分复杂任务需要更多轮。

### 7. 优点

- **方法层面**：
  - **无训练、全冻结**：同时兼容开源和专有模型，无参数更新，易于部署；
  - **策略-执行解耦**：策略以自然语言表达，透明、可解释、可人为干预纠错；
  - **任务间可复用**：学到的策略是任务级而非用户级，可迁移到未见用户。
  - **稳健的反馈设计**：支持集/开发集分离防止过拟合，历史保留避免单调更新陷阱，自适应采样缓解采样偏差。
- **实验层面**：
  - 构造复合基准，明确暴露了"通用偏好中跨任务干扰"的现实问题，评估更有说服力；
  - 做了多组消融（偏好来源、采样方式、超参数、元模型泛化），分析完整；
  - 做了严格的事实一致性审计，不只关注分数，还关注"改写是否篡改用户事实"，这在偏好压缩工作中比较少见。

### 8. 不足与局限

- **作者自述的局限**：
  - 基准仍是构建/策展的评估环境，不能完全代表真实终身代理中动态、嘈杂的交互数据；
  - 假定支持集能代表目标任务分布，当支持集有偏或多样性不足时，策略泛化性可能受限。
- **实验层面**：
  - 未报告 GPU 型号/数量/训练时长/API 调用成本，难以评估实际部署开销；
  - 未报告结果的方差或多次运行统计，API 模型的非确定性可能影响结论稳健性；
  - 少部分场景出现退化（如 Knowledge Query 在 DeepSeek 和 GPT-5-mini 上分别为 -0.06 和 -1.58），缺乏更深入分析。
- **方法层面**：
  - 依赖"已有通用偏好"这一前提，若源配置本身证据不足（源覆盖率仅 34.0%），方法无法超越源配置的天花板；
  - 对结构化偏好源（如 JSON 型 persona）效果反而下降（Source B 上 -0.84），说明方法面向自然语言偏好设计，对结构化源需要另行适配；
  - 策略归纳需要每任务一个支持集，多任务部署时仍需逐个任务做程序化归纳，有一定的每任务成本。
- **应用限制**：
  - 改写可能丢失精细字段（源 B 的 drop 说明）；
  - 方法未处理"偏好随时间变化"的演化问题，与终身学习中记忆更新的结合留待未来工作。

> **总结**：AlignXada 提出了一种轻量、可解释、无需训练的任务特定偏好适应框架，用语言强化学习在文本空间内"学习如何改写偏好"，在性能、压缩率、事实一致性三方面都取得了不错的表现。它为"通用记忆 + 任务适配"的终身个性化代理提供了一个实用的新组件，但其真实场景泛化性和部署成本尚需更多测试。
