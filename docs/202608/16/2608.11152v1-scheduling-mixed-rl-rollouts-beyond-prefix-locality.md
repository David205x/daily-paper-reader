## 摘要
现代大型语言模型（LLM）的强化学习（RL）后训练流程日益将跨多个领域和反馈范式的推出（rollout）工作负载结合在一起。前缀感知路由通过缓存复用和负载均衡提高推理效率，但它无法控制异构推出会话如何竞争KV缓存容量。当可验证奖励强化学习（RLVR）、人类反馈强化学习（RLHF）和智能体式推出共享一个异步推理服务时，它们各不相同的序列结构、交互模式和KV驻留时间会产生截然不同的服务需求。推出调度必须考虑这种异构性，同时不扭曲训练器指定的工作负载混合比例。我们提出了MISA-T，一种用于混合推出服务的路由层准入策略。MISA-T结合了自适应会话准入、工作负载感知的KV容量分配和驻留时间感知的KV记账。在Step3.7和Qwen3.6-35B-A3B上仅推出消融实验中，MISA-T相比经过扫描调优的缓存感知vLLM路由器，分别将推出吞吐量提高了53.3%和43.6%，同时保持了较高的前缀缓存命中率。在匹配的50轮迭代Step3.7实验中，它使推出吞吐量提高了35.6%，平均迭代时间减少了22.8%，同时保持所消耗的工作负载混合比例接近训练器目标，并实现了可比的任务分数。

## Abstract
Modern reinforcement learning (RL) post-training pipelines for large language models (LLMs) increasingly combine rollout workloads across multiple domains and feedback paradigms. Prefix-aware routing improves inference efficiency through cache reuse and load balancing, but it does not control how heterogeneous rollout sessions compete for KV-cache capacity. When reinforcement learning with verifiable rewards (RLVR), reinforcement learning from human feedback (RLHF), and agentic rollouts share an asynchronous inference service, their distinct sequence structures, interaction patterns, and KV-residency times create substantially different serving demands. Rollout scheduling must account for this heterogeneity without distorting the workload mixture specified by the trainer. We present MISA-T, a routing-layer admission policy for mixed rollout serving. MISA-T combines adaptive session admission, workload-aware KV-capacity allocation, and residency-time-aware KV accounting. In rollout-only ablations on Step3.7 and Qwen3.6-35B-A3B, MISA-T improves rollout throughput over a sweep-tuned cache-aware vLLM Router by 53.3% and 43.6%, respectively, while maintaining high prefix-cache hit rates. In a matched 50-iteration Step3.7 experiment, it increases rollout throughput by 35.6% and reduces mean iteration time by 22.8%, while keeping the consumed workload mixture close to the trainer target and achieving comparable task scores.

- **背景**：现代 LLM 的强化学习（RL）后训练流程越来越多地将跨多个领域和反馈范式的 rollout 工作负载混合在一起，常见的三类工作负载包括：
  - **RLVR**（可验证奖励强化学习）：短提示词、超长输出（decode 为主）；
  - **RLHF**（人类反馈强化学习）：提示词和响应长度较为均衡；
  - **Agentic**（智能体式）：多轮交互、跨轮长期保留长前缀，且包含工具执行间隔。
- **核心问题**：已有的前缀感知路由（如 vLLM Router、SGLang 的 RadixAttention、Preble 等）主要优化请求放置、前缀复用和负载均衡，但**不控制异构 rollout 会话如何竞争有限的 KV-cache 容量**。在混合工作负载共享同一推理池时，各工作负载在 KV 占用、驻留时间和服务需求上差异巨大，简单的放置策略会导致缓存抖动、前缀命中率崩溃和吞吐下降。
- **核心矛盾**：训练器规定了目标工作负载混合比例（mixture contract），而路由层出于服务效率需要对异构会话进行调度——两者必须兼顾，调度策略不能扭曲训练器指定的工作负载构成。
- **核心含义**：论文认为，高效调度混合 rollout 需要在路由层引入**会话粒度（session-level）的准入控制**，而不仅仅是请求粒度的放置决策。该问题属于**系统层面的 RL 训练基础设施优化**，而非算法层面的改进。

## 二、方法论：核心思想、技术细节与流程

### 核心思想

MISA-T（**Mix-aware Session Admission with a Time factor**）将训练器的混合比例契约与路由层的资源控制分离：训练器决定目标分布，路由器负责会话感知的准入控制、按工作负载类别划分受保护 KV 容量，并进行类别专属的 KV 驻留时间记账。核心洞察是：**准入一个会话等于一项 KV 容量承诺**——不仅包括当前请求，还包括后续 KV 增长、未来延续和轮间驻留。

### 三大关键技术组件

**1. 自适应会话准入（Adaptive Session Admission）**

- 对每个推理实例 w，定义受保护的会话上限 Kw(t)；
- 准入条件：已有会话（Ow）或待定会话（Pw）的延续请求可直接通过；新会话必须占用剩余容量，否则进入 HOLD 状态周期性重评估；
- 参考容量由保守的会话长度估计计算：Kbase(w,t) = ⌊Cw / k̄w(t)⌋；
- 当确认前缀命中率下降或等待队列持续累积（过载压力信号）时，临时收缩运营容量，待参考长度更新后逐步恢复；
- 对于缓存延续请求，若 `∆r + q_hit − q_cold < Hr/F`，则等待缓存实例优于立即冷路由。

**2. 工作负载感知的 KV 容量分配（Workload-aware Capacity Allocation）**

- 通过类别的空间 KV 需求按比例分配受保护的 KV 预算：
  - 空间需求：Sw,b = Nw,b · k̄b；
  - 块配额：M(w,b) = Cw · Sw,b / ΣSw,b′；
  - 会话上限：K(w,b) = ⌊M(w,b) / k̄b⌋；
- 全局容量上限和类别内软配额共同决定准入决策，防止单一类别耗尽全部受保护容量。

**3. KV 驻留时间加权（Residency-time-aware KV Accounting）**

- 引入驻留时间因子 T̂b（会话从准入门到完成/终结的观测持续时间，含智能体的工具调用间隔）；
- 块时间需求：Rw,b = Nw,b · k̄b · T̂b；
- 配额分配改为按 R 成比例，使各类别的预估排队排空时间大致平衡：
  - M(w,b) = Cw · Rw,b / ΣRw,b′；K(w,b) = ⌊M(w,b) / k̄b⌋；
- 通过在线估计最近完成会话的驻留时间，兼容性良好的中性先验稳定早期配额。

**4. 会话级缓存记账（辅助机制）**

- 会话快照：记录运行中和近期完成的会话、KV 块数、生命周期时间戳；
- 前缀位置追踪：通过引擎报告的 block hash 维护前缀到实例的映射，用于判断可复用前缀位置。

### 调度流程（文字说明）

1. **估计块时间需求**：路由器从会话快照中统计各工作负载类别的未完成会话数、参考 KV 占用和参考驻留时间；
2. **分配受保护 KV 上限**：按各类别块时间需求比例划分受保护的 KV 预算，再转换为会话准入上限；
3. **准入/挂起决策**：全局容量和类别容量均有空间则准入新会话；否则保持 HOLD 状态，周期性重新评估；已准入会话的延续请求不额外占用配额；
4. **实例选择**：在具有准入余量的实例中，由既有缓存感知放置策略选择最优实例。

## 六、主要结论与发现

1. **核心增益**：MISA-T 相比扫描调优的 vLLM Router，在 rollout-only 消融中提升 rollout 吞吐 53.3%（Step3.7）和 43.6%（Qwen3.6-35B-A3B），同时保持高前缀命中率（97.8% / 95.3%）；
2. **端到端训练收益**：50 轮 Step3.7 匹配实验中，rollout 吞吐提升 35.6%，平均迭代时间减少 22.8%，前缀命中率从 74.5% 提升至 96.2%；
3. **混合比例保持**：消耗的工作负载混合与训练器目标的 TV 距离从 vLLM Router 的 4.14 个百分点降至 2.71 个百分点，MISA-T 不扭曲训练器指定的工作负载构成；
4. **任务质量不变**：pass@4 在 SWE-Pro、SWE-Verified、SWE-MTLG 上与基线差距低于 0.5 个百分点；
5. **无准入控制的失效模式**：在高并发负载下，vLLM Router 由于前缀驱逐的正反馈循环（准入增多 → KV 工作集膨胀 → 前缀驱逐 → 冷 prefill 增多 → 队列变长 → 进一步驱逐），导致前缀命中率从 92.4% 崩至 4.5%，吞吐大幅下降；
6. **每个组件都有贡献**：类别感知分配和驻留时间加权分别在类别无关的 Session Admission 之上带来额外吞吐提升；
7. **与 CPU KV offload 兼容**：offload 可提高 GPU KV 利用率（>90%）和每副本 RPM（+35.6%），且 MISA-T 无需修改。

## 七、优点

1. **问题定位精准**：清晰区分了放置（placement）与准入（admission）两个正交的调度决策，指出现有系统对后者的忽视；
2. **设计优雅且工程可落地**：MISA-T 作为路由层策略，只依赖请求元数据、运行时指标和缓存快照，对推理引擎和 agent 运行时零侵入，可无缝集成到现有系统（独立调度器或网关插件）；
3. **度量创新**：引入 KV block-time（块-时间）概念统一了空间（KV 大小）与时间（驻留时长）两个维度的资源消耗，公式简洁且直觉清晰；
4. **消融严谨**：通过 Session Admission → MISA → MISA-T 的渐进构造，定量分离了三个组件各自的贡献；
5. **着眼实际痛点**：不仅优化吞吐，还验证了对 RL 训练迭代时间和混合比例保持的正向影响，具备实际部署价值；
6. **兼容性验证**：额外验证了与 CPU KV offload 的互补性，拓展了方法适用范围。

## 八、不足与局限

1. **依赖请求元数据与快照**：论文明确提到，延迟或不完整的会话快照会暂时降低 KV 需求估计和准入上限的准确性；
2. **实验结果统计强度有限**： rollout-only 报告 3 次运行均值，端到端实验仅 1 次运行，未提供标准误差、置信区间或多种子复现，无法判断差异的统计显著性；
3. **模型覆盖有限**：仅验证了两个模型（Step3.7 和 Qwen3.6-35B-A3B），且推测是 StepFun 的内部模型，缺乏对广泛使用的开源模型（如 Llama、Mistral 等）的验证；
4. **基准比较可争议**：vLLM Router 基线的扫描调优可能未达到其全局最优，且高负载配置的诊断结果展示了坍缩现象，但实际中用户也可能通过手动调整避免该问题；
5. **Qwen 上 MISA 的异常**：Qwen 上 MISA 的前缀命中率（79.2%）明显低于 Session Admission（96.3%）和 MISA-T（95.3%），文中未深入解释该非单调现象，可能暗示工作负载感知分配在某些配置下存在不稳定风险；
6. **离线 trace 与在线训练环境的差距**：rollout-only 使用的是固定检查点 + 内部 trace，端到端训练中权重同步会周期性重置前缀缓存，两种场景的绝对指标不可直接对比；
7. **适用边界未充分探索**：未测试极端工作负载比例（如 agentic 占 90% 以上）、更多工作负载类别共存、或配额需求剧烈变化时的行为极限。

## 九、总评

MISA-T 是一篇系统层面、工程导向的优质论文。它精准识别了混合 RL rollout 服务中"放置不等于准入"的盲区，提出了一套轻量、可组合的准入控制方案，并通过有说服力的渐进消融和端到端验证证明了其有效性。论文在问题定义、度量设计和系统实现方面均有亮点，但统计严谨性和实验覆盖范围仍有提升空间——若能补充多种子统计检验、更多开源模型验证和异常现象的深入分析，结论将更加稳健。
