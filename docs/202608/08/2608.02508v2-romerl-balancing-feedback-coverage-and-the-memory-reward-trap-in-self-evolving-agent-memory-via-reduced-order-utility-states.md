## 摘要
基于学习的自进化LLM智能体记忆系统面临两个紧密耦合的挑战。首先，以轨迹为索引的效用随交互历史增长，从而将有限的反馈分散到不断扩展的状态空间中。其次，由于轨迹级别的奖励被共同分配给共同检索的记忆，不相关的经验可能收到误导性的效用更新，进而陷入记忆-奖励陷阱。为解决这些挑战，我们引入了降阶记忆强化学习（RoMeRL），该方法通过由结果极性和记忆动力学分解的固定维度每任务记忆状态来表示不断增长的轨迹索引效用空间。RoMeRL通过一组固定语义坐标来纳入新经验，其内容随时间更新或替换，从而将反馈集中在有界的效用支持上。理论上，我们证明这种降阶参数化增加了每个效用坐标收到的平均反馈，并在一般坐标转移模型下刻画了错误坐标的稳态占用率。在ALFWorld和LifelongAgentBench上的实验表明，RoMeRL提高了任务性能，将Cold-Q比率降低了80.0%，将反馈密度提高了约6.0倍，将维护的记忆大小减少了84.4%，并将LLM调用削减了21.1%。这些结果表明，降阶效用状态支持高效的自进化智能体记忆，同时限制了持续的奖励污染。代码可在 https://github.com/YOUNG-fnxm/RoMeRL 获取。

## Abstract
Learning-based memory systems for self-evolving LLM agents face two tightly coupled challenges. First, trajectory-indexed utilities grow with the interaction history, thereby dispersing limited feedback over an ever-expanding state space. Second, because trajectory-level rewards are jointly assigned to co-retrieved memories, irrelevant experiences may receive misleading utility updates and consequently enter the memory-reward trap. To address these challenges, we introduce Reduced-Order Memory Reinforcement Learning (RoMeRL), which represents the growing trajectory-indexed utility space using a fixed-dimensional per-task memory state factorized by outcome polarity and memory dynamics. RoMeRL incorporates new experiences through a fixed set of semantic coordinates whose contents are updated or replaced over time, thereby concentrating feedback over a bounded utility support. Theoretically, we show that this reduced-order parameterization increases the average feedback received by each utility coordinate and characterize the steady-state occupancy of erroneous coordinates under a generic coordinate-transition model. Empirically, across ALFWorld and LifelongAgentBench, RoMeRL improves task performance, reduces the Cold-Q ratio by 80.0%, increases feedback density by approximately 6.0 times, reduces the maintained memory size by 84.4%, and cuts LLM calls by 21.1%. These results show that reduced-order utility states support efficient self-evolving agent memory while limiting persistent reward contamination. Code is available at: https://github.com/YOUNG-fnxm/RoMeRL

### 一、核心问题与整体含义（研究动机和背景）

- **背景**：大语言模型（LLM）智能体本质上是无状态的，无法跨交互累积和复用经验。智能体记忆系统通过存储和检索历史经验来解决这一问题，近期研究从“保存经验”转向“决定哪些经验应保持活跃并影响未来行为”。
- **核心问题**：基于学习的记忆系统（如 MemRL）为每条存储轨迹分配独立的可学习效用（utility），并利用下游任务结果进行更新。这种方式面临两个紧密耦合的挑战：
  1. **反馈稀释**：轨迹索引的效用空间随交互历史不断增长（维度 N_t 持续扩大），而反馈信号有限，导致大量记忆效用处于“冷启动”状态，反馈密度低下。
  2. **记忆-奖励陷阱（Memory-Reward Trap, MRT）**：轨迹级奖励被共同分配给所有被检索的记忆，导致弱相关、噪声乃至失败经验在成功场景中也可能获得正向效用更新，造成奖励误归因（reward misattribution）。
- **矛盾**：增强探索（如 UCB）虽能扩大反馈覆盖、缓解冷启动，但同时暴露更多弱相关记忆于错误奖励传播，反而降低任务性能。探索与污染之间存在本质困境。

### 二、方法论：核心思想、关键技术细节与公式

- **核心思想**：将不断增长的轨迹索引效用空间替换为**固定维度（2×2）的每任务记忆状态**，按“结果极性”（正/负）和“记忆动力学”（整合/自适应）两个维度分解，将有限的反馈集中到有界但语义固定的坐标上。
- **状态定义**：
  - 结果极性 O = {+, −}（成功/失败证据）
  - 记忆动力学 D = {C, A}（整合/自适应）
  - 笛卡尔积 I_fact = O × D，共 4 个坐标
  - 每个任务 g 的历史 D_{g,t} 被映射为 Z_{g,t} = Φ(D_{g,t})，维度恒为 4。
- **四个语义坐标及其更新规则**：
  1. **PCC（正向整合坐标）**：保存全局最优的成功轨迹（效率最高），新更优轨迹替换旧轨迹并继承效用值。
  2. **PAC（正向自适应坐标）**：保存“失败后首次成功”的恢复性轨迹，捕获失败到成功的边界转化。
  3. **NCC（负向整合坐标）**：保存获得正向效用证据（Q > Q⁻_init）的失败经验，可被提升至该坐标。保留有诊断价值的高效用失败经验。
  4. **NAC（负向自适应坐标）**：保存最近的失败轨迹，及时反映当前错误状态，新失败替换旧失败。
- **运行时更新规则**：
  - 检索评分：score = (1 − ω_Q) · cos(e(x_t), e(m)) + ω_Q · Q
  - Q 更新：Q ← Q + α · 1[m ∈ S_t] · (r_t − Q)，沿用标准增量 Q 学习，但更新对象是固定坐标而非不断增长的轨迹集合。
- **理论贡献**：
  - **定理 1（差距-方差分解）**：E[(Q̂_i − θ_i)²] = (v⁰_i + a_i)² + σ²_i/n_i。说明更多反馈只能降低方差项，无法消除任务基线 v⁰_i 和归因偏差 a_i 组成的信用差距。
  - **定理 2（反馈预算）**：全池估计所需反馈量 F_T = O(N_t/ε² · log(N_t/δ))，随记忆数 N_t 增长，解释全池学习的不可扩展性。
  - **定理 3（反馈集中）**：降维后每个坐标平均获得约 (N_t/4) 倍的反馈，方差从 O(σ²N_t/(kT)) 降至 O(4σ²/(kT))。
  - **命题 1（错误坐标稳态占用）**：在通用坐标转移模型下，稳态错误坐标占比 ≤ γ/(γ + λ)；当 d·γ/(γ+λ) < N_t·ρ_full 时，降阶状态比全池暴露更少的错误坐标。
