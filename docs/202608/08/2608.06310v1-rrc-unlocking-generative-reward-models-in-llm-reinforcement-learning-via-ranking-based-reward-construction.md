## 摘要
近期奖励建模的进展展示了从判别式奖励模型到生成式奖励模型的范式转变。然而，尽管生成式奖励模型在响应排序方面能力强大，但它们在强化学习（RL）中尚未发挥出其潜力。我们的分析表明，这一局限性源于生成式奖励建模的比较性质与现有 RL 算法采用的标量评分范式之间的不匹配。为了弥合这一差距，我们提出了一种基于排序的奖励构建（RRC）方法，通过从相对偏好排序中推导奖励，使生成式奖励模型能够提供更有效的 RL 学习信号。RRC 引入了两种互补策略：自竞争排序，利用采样响应之间的比较；以及锚点引导排序，通过少量参考响应实现可扩展的基于排序的奖励构建。在开放域聊天和推理基准上的实验表明，RRC 显著改善了使用生成式奖励模型的 RL 训练，相较于现有奖励构建方法取得了持续的性能提升。我们的代码可在 https://github.com/wangclnlp/RRC 获取。

## Abstract
Recent advances in reward modeling show a paradigm shift from discriminative reward models to generative reward models. However, despite their strong capabilities in response ranking, generative reward models have not realized their potential in reinforcement learning (RL). Our analysis reveals that this limitation arises from a mismatch between the comparative nature of generative reward modeling and the scalar scoring paradigm adopted by existing RL algorithms. To bridge this gap, we propose a Ranking-based Reward Construction (RRC) approach, which enables generative reward models to provide more effective RL learning signals by deriving rewards from relative preference rankings. RRC introduces two complementary strategies: self-competitive ranking, which exploits comparisons among sampled responses, and anchor-guided ranking, which enables scalable ranking-based reward construction with a small set of reference responses. Experiments across open-ended chat and reasoning benchmarks demonstrate that RRC substantially improves RL training with generative reward models, achieving consistent gains over existing reward construction approaches. Our code can be found at https://github.com/wangclnlp/RRC.

## 1. 核心问题与整体含义

本文关注的核心问题是：**生成式奖励模型（Generative Reward Model, GRM）在响应排序任务上表现卓越，但其优势未能有效转化为强化学习（RL）训练中的性能提升。**

- **背景**：奖励模型在 LLM 的 RL 训练中扮演核心角色。传统判别式奖励模型（DRM）通过回归式架构直接输出标量奖励分数，但其没有充分利用 LLM 的文本生成能力，缺乏指令微调和显式思维链（CoT）推理等关键优势。近年来，生成式奖励模型通过自然语言生成来表达偏好，在响应排序上显著优于判别式模型。
- **问题**：在 RL 中，现有算法（如 GRPO）要求奖励模型为每个采样响应提供**标量奖励分数**。现有做法（如 GenRM、GRAM）通常是利用生成式奖励模型输出的偏好 token 概率作为分数，但这种方式存在概率坍塌、置信度与人类偏好不一致等问题，导致生成式奖励模型在排序上的优势在 RL 中几乎消失。
- **核心论断**：判别式奖励模型天然为标量评分设计，而生成式奖励模型天然适用于比较式排序。**强行将生成式奖励模型当作评分器使用，会削弱其偏好建模能力，导致次优的策略优化。**
- **整体含义**：本文主张将生成式奖励模型仅用于响应**排序**而非标量评分，并提出了基于排序的奖励构建方法（RRC），从而释放生成式奖励模型在 RL 中的潜力，为奖励建模提供了一种新范式。

## 2. 方法论

### 2.1 核心思想

RRC 的核心思想是：**放弃使用偏好 token 概率作为奖励分数，而是完全基于响应之间的相对偏好排序来构建奖励分数。** 这需要满足两个关键属性：

- **序保持（Order Preservation）**：奖励应保持偏好排序，即若 \(o_i \succ o_j\)，则 \(r(x,o_i) > r(x,o_j)\)。
- **边缘感知（Margin Awareness）**：奖励差异应反映响应之间的潜在质量差距，即 \(r(x,o_i) - r(x,o_j) \propto \Delta q_{ij}\)。论文通过策略梯度视角给出了理论证明：奖励差异的比例校准直接影响 RL 更新方向的有效性。

### 2.2 两种排序机制

RRC 包含两种互补策略：

- **自竞争排序（Self-Competitive Ranking, SCR）**：
  - 对于同一输入 x 下从当前策略采样的一组（m 个）响应，查询生成式奖励模型进行两两比较，得到偏好关系 \(o_i \succ o_j\) 或 \(o_j \succ o_i\)。
  - 每个响应的奖励分数定义为它的获胜次数：\(r(x,o_i) = \alpha \times \sum_{j \neq i} \mathbb{1}[o_i \succ o_j]\)。
  - **多数投票（Majority Voting）**：对于每个响应对，多次查询生成式奖励模型并取多数投票结果，以提高偏好判断的鲁棒性。
  - **冲突感知排序调整（CARA）**：由于两两偏好可能产生循环不一致（如 \(o_i \succ o_j\)，\(o_j \succ o_k\)，但 \(o_k \succ o_i\)），论文将偏好视为带权有向图，采用 Kemeny 规则聚合，通过寻找最小权重反馈边集来恢复全局一致的排序。论文给出了该规则能够最大加权一致性的理论证明。

- **锚点引导排序（Anchor-Guided Ranking, AGR）**：
  - SCR 需要 \(O(m \cdot \log m)\) 次偏好查询，计算成本高，限制扩展性。
  - AGR 引入一组由**参考策略**生成的锚点响应 \(\{a_1, \ldots, a_n\}\)（n 较小，通常 8~16 个），将每个采样响应与每个锚点进行比较，定义奖励分数为：\(r(x,o_i) = \alpha \times \sum_{k=1}^{n} \mathbb{1}[o_i \succ a_k]\)。
  - 查询复杂度降至 \(O(m \cdot n)\)。
  - **使用参考策略生成锚点的理论优势**：论文证明，如果锚点来自当前策略，则锚点质量会随策略更新而漂移，形成"移动目标"问题，增加梯度方差和训练不稳定性。使用固定参考策略则锚点与 θ 无关，奖励景观保持平稳。

### 2.3 与现有算法的集成

产生的奖励分数可直接嵌入 GRPO、DAPO 等 RL 算法中。在推理增强策略设置中，论文还加入格式奖励以鼓励结构化输出（即包含 `<think>` 和 `<answer>` 标签）。最终奖励为排名奖励与格式奖励的组合。同时，在查询生成式奖励模型时，随机分配 "Response A" 和 "Response B" 位置以消除位置偏差。

## 6. 主要结论与发现

- 生成式奖励模型在响应排序上显著优于判别式模型，但在概率式奖励构建下，这种优势在 RL 中几乎消失（例如 AlpacaEval2 上仅比 DRM 高约 1%）。
- RRC 的两种策略（SCR 和 AGR）在**所有基准上一致且显著地**优于概率式基线。例如 8B 奖励模型带思考的设置下：AlpacaEval2 从 PRC 的 35.8% 提升至 RRC-AGR + voting@8 的 41.3%；ArenaHardV2 从 7.8% 提升至 11.2%；MMLU-Redux 从 52.9% 提升至 57.3%。
- 多数投票机制可进一步提升 RRC 性能，说明聚合多次随机偏好判断有助于降低噪声。
- AGR 通常优于或媲美 SCR，尤其在结合投票时优势明显；使用固定参考策略的锚点能提供稳定的比较基准。
- RRC 展现出**扩展性收益**：增加投票数或锚点数均能提升性能（具有边际递减的规模规律），为 RL 提供了新的扩展维度。
- 计算匹配实验证明：提升来自"排序与相对边缘的聚合"，而非简单增加推理计算量。
- 点式生成式奖励模型的分析表明，CoT 导致偏好 token 概率饱和（42.3% 概率落在 [0, 0.1]，46.0% 落在 [0.9, 1.0]），绝对标量分数丢失了相对差异，而 RRC 通过结构化比较保留了排序和边缘信息。

## 7. 优点

- **问题定位精准**：通过对照实验清晰展示了判别式与生成式奖励模型在排序 vs 评分之间的能力错位，提出了两个明确的设计原则（序保持与边缘感知），问题界定清晰。

- **方法局限性**：RRC 的整体性能高度依赖生成式奖励模型的排序质量。若奖励模型本身存在系统偏差（如对长度、风格的偏好），排序构建并不能消除这种偏差，甚至可能放大。
