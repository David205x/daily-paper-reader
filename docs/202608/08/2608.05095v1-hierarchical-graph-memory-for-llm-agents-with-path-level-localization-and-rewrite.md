## 摘要
长期推理的智能体需要一种能够随着新事实和外部反馈不断到来而高效、有效地随时间更新的记忆。近年来，图记忆被用于为多跳检索和推理提供结构化组织。然而，现有方法将所有记忆存储在一个平面图中，累积的历史记忆可能引入不相关的上下文，并增加检索过程中证据选择的成本。此外，它们通常独立更新记忆单元，需要重复的逐单元重写以覆盖相关变化。为解决这些问题，我们提出了HiGram，一个具有路径级定位和重写的演化层次化图记忆框架。具体来说，我们首先提出了一种层次化图记忆，将记忆组织成由上层节点和MemoryUnit组成的从粗到细的架构，从而减少检索过程中不相关信息的数量。我们进一步提出了基于MicroGraph的路径级定位，利用查询和更新条件化的MicroGraph在重写前识别支持子图和证据路径。最后，我们提出了一种协调重写方法，联合修改单元内记忆和单元间依赖关系，使得有效的依赖结构能够在局部证据路径中更新。在长期对话问答和冲突感知记忆评估基准上的实验表明，我们的方法在答案质量和token效率方面较基线有显著改进。此外，我们的方法在动态、静态和条件冲突下提高了答案准确性和查询有效的证据选择。

## Abstract
Agents for long term reasoning require a memory that can be efficiently and effectively updated over time, as new facts and external feedback continue to arrive. Recently, graph memory has been adopted to offer structural organization for multi-hop retrieval and reasoning. However, existing methods store all memories in a flat graph, and accumulated historical memories can introduce irrelevant contexts and increase the cost of evidence selection during retrieval. Moreover, they typically update memory units independently, requiring repeated unit-wise rewrite to cover related changes. To address these issues, we propose HiGram, an evolving hierarchical graph memory framework with path-level localization and rewriting. Specifically, we first propose a hierarchical graph memory, which organizes the memory into coarse-to-fine architecture composed of upper-level nodes and MemoryUnits, thereby reducing the amount of irrelevant information during retrieval. We further propose MicroGraph-based path-level localization, which leverages query and update conditioned MicroGraphs to identify support subgraph and evidence path before rewrite. Finally, we propose a coordinated rewriting method that jointly revises intra-unit memory and inter-unit dependencies, enable valid dependency structures updating in the localized evidence path. Experiments on benchmarks for long-term conversational question answering and conflict-aware memory evaluation demonstrate that our method demonstrate substantial improvements over baselines in answer quality and token efficiency. Besides, our method improves answer accuracy and query-valid evidence selection under dynamic, static, and conditional conflicts.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：长期推理的 LLM 智能体需要随时间持续更新记忆，以吸收新事实、纠正信息和外部反馈。记忆系统不仅要能检索相关历史信息，还要维持合理的记忆结构，保证后续推理能高效获得可靠证据。
- **现有方法的不足**：
  - 图记忆虽然能提供结构化组织，但现有方法大多将所有记忆存储在**平面图**中。随着历史记忆累积，检索可能引入大量无关上下文，增加证据选择的成本。
  - 现有更新机制通常**独立地更新单个记忆单元**，而答案通常由相互连接的证据路径支持；独立更新容易遗漏相关证据，使过期依赖继续参与推理，并导致需要反复重写大量单元，token 消耗高、更新效率低。
- **核心论点**：记忆的组织和更新粒度应与推理所需的证据结构粒度相匹配。记忆系统应先定位与查询相关的子图，再根据更新识别受影响的证据路径，并在限定区域内联合修订记忆状态和依赖关系。
- **整体含义**：本文提出 HiGram，一种演化式层次化图记忆框架，通过“粗到细”组织、路径级定位和协调重写，提升长期记忆智能体的问答质量、冲突处理能力与 token 效率。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 总体框架
- HiGram 包含三个主要阶段：
  1. **层次化记忆组织**：构建粗到细的结构，支持快速定位相关记忆区域。
  2. **基于 MicroGraph 的路径级定位**：结合查询与更新，识别支持子图和受影响证据路径。
  3. **协调重写**：在局部证据路径内同步更新记忆单元内部状态与单元间依赖。

### 2.2 层次化记忆组织
- 记忆表示为层次图 `G_t = (V_t, E_t)`。
- 节点集合：`V_t = V_sub ∪ V_cat ∪ V_ctx ∪ M_t`，其中：
  - `V_sub`：主语节点；
  - `V_cat`：对象类别节点；
  - `V_ctx`：上下文节点；
  - `M_t`：MemoryUnit 集合，保存细粒度事实。
- 边集合：`E_t = E_sub ∪ E_obj ∪ E_ctx ∪ E_dep`，其中 `E_dep` 是 MemoryUnit 之间的依赖边，表示显式证据依赖。
- MemoryUnit 记录主语、关系、对象、对象类别、事务时间、上下文、置信度、状态等；状态包括 active、superseded、outdated、pending。非 active 单元保留修订历史，但排除在定位步骤之外。
- 层级设计将“组织”与“事实存储”分离：上层节点提供粗粒度访问，MemoryUnit 保存细粒度信息和依赖结构。

### 2.3 基于 MicroGraph 的路径级定位
- **MicroGraph 构造**：MicroGraph `B_t,j` 是由一对节点（主语节点 `v_sub`、对象类别节点 `v_cat`）定义的局部子图，关联的 MemoryUnit 满足 `s_i = v_sub` 且 `o_i = v_cat`。MicroGraph 不额外增加记忆内容，只作为局部检索区域。
- **锚点提取与候选选择**：
  - 根据查询 `q_t` 和更新文本 `u_t` 构造临时 MemoryUnit `M_temp`；
  - 锚点提取器 `anch(·)` 从临时单元中提取主语和对象类别节点作为锚点 `A_t`；
  - 识别候选 MicroGraph：`B_cand = {B | ∃m_i ∈ M_t(B): {s_i, o_i} ∩ A_t ≠ ∅}`；
  - 按相关性分数 `R(B, A_t)` 排序，取 top-`K_g` 个 MicroGraph，构成支持子图 `G_S,t`。
- **路径级定位**：
  - 在支持子图内枚举连接 MemoryUnit 的候选路径 `P_cand`；
  - 用评分函数 `φ_H(P, M_temp)` 评估候选路径与临时 MemoryUnit 的一致性（考虑属性匹配、依赖一致性、时间有效性、上下文兼容性）；
  - 选择受影响证据路径：`P_hat_t = argmax_{P∈P_cand} φ_H(P, M_temp)`。
  - `P_hat_t` 中的 MemoryUnit 和依赖边定义重写区域。

### 2.4 协调重写
- 目标不是覆盖历史记忆，而是保持证据结构一致。
- 重写过程包含两部分：
  - **单元内重写（Intra-unit rewriting）**：将临时 MemoryUnit 与路径中匹配的 MemoryUnit 配对；新的记忆作为 active 单元加入；更新已有单元的内部状态和有效时间信息。
  - **单元间重写（Inter-unit rewriting）**：识别受影响的直接依赖单元 `D_t(m_i)`；检查依赖在更新后是否仍然有效，若依赖失效则标记为 outdated 并从当前证据视图排除；更新后的 MemoryUnit 不会自动继承原依赖，防止产生无证据支持的推论。
- 整体更新公式（文字描述）：
  - `G_{t+1} = Update(G_t, Rewrite_inter(Rewrite_intra(P_hat_t, M_temp), M_temp))`。
  - 重写区域外的 MemoryUnit 和依赖关系保持不变。

## 6. 主要结论与发现

- 在 LoCoMo 上，HiGram 在 GPT-5.4 和 GPT-4o 下均获得平均 F1、BLEU、LLM-J 的最佳结果，证明其提升不依赖特定 LLM 后端。
- HiGram 在 token 效率上优势显著：在 GPT-5.4 下仅使用完整上下文方案 token 量的 7.2%；在 GPT-4o 下约为第二好方法 ReadAgent 的 15.8%。
- 在 Temporal 问题上表现最强，在 Adversarial 问题上保持领先或接近最佳，说明路径级定位和时间有效性限制了过时/无关记忆的干扰。
- 在 MemConflict 上，HiGram 总体性能最佳，并在证据选择指标（SEH@3、SRS）上排名第一；在 Dynamic 冲突上 UOCS 最优，在 Static 冲突上 AA 和 CRS 均大幅领先，在 Conditional 冲突上 AA 最高。
- 消融实验表明，MicroGraph 组织和局部支持子图都有助于提升检索证据质量和降低 token 消耗；移除支持子图会导致多跳和时序问题性能下降，说明依赖与时间关系的保留很重要。
- 更新策略对比显示，Append-only 和 Relation-level 更新存在冲突类型间的权衡，而 HiGram 在动态和静态冲突上同时取得最好或接近最好的结果，避免“顾此失彼”。
- 整体结论：结合层次组织与路径级局部更新，可有效支持长期智能体的可靠记忆管理，减少检索噪声并实现高效精准的记忆更新。
