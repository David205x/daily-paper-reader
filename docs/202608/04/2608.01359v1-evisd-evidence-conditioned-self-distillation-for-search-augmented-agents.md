## 摘要
基于结果的强化学习使搜索增强语言代理能够从可验证的最终答案中学习，但其轨迹级别的信用无法区分多轮搜索过程中单个动作的贡献。我们提出了EviSD，一种证据条件自蒸馏框架，该框架使用实例级支持证据作为搜索动作的特权信息，并将黄金答案作为回答动作的补充特权。在训练期间，学生从原始上下文中采样动作，而同一模型作为特权教师在动作对齐的上下文中重新评分这些动作。EviSD将解耦的教师-学生差距转换为有界校正，应用于结果派生的GRPO优势，并且仅应用于生成的动作跨度。这种设计局部化了特权指导，同时保留了由结果奖励确定的更新方向，无需辅助蒸馏目标，也不在推理时进行任何更改。在七个问答基准和三个跨越模型规模和世代的骨干网络上，EviSD在所有评估设置中实现了最高的宏平均精确匹配，超过最强比较方法1.3-2.3个百分点，同时仅调制了6.7%-15.1%的响应令牌。代码可在https://github.com/JiananXie/EviSD获取。

## Abstract
Outcome-based reinforcement learning enables search-augmented language agents to learn from verifiable final answers, but its trajectory-level credit cannot distinguish the contributions of individual actions in a multi-turn search process. We propose EviSD, an evidence-conditioned self-distillation framework that uses instance-level supporting evidence as privileged information for search actions and golden answers as complementary privilege for answer actions. During training, the student samples actions from the original context, while the same model re-scores them as a privileged teacher under an action-aligned context. EviSD converts the detached teacher--student gap into a bounded correction to the outcome-derived GRPO advantage and applies it only to generated action spans. This design localizes privileged guidance while preserving the update direction determined by the outcome reward, without an auxiliary distillation objective or any change at inference time. Across seven question-answering benchmarks and three backbones spanning model scales and generations, EviSD achieves the highest macro-average Exact Match in all evaluated settings, outperforming the strongest compared methods by 1.3--2.3 points while modulating only 6.7%--15.1% of response tokens. Code is available at https://github.com/JiananXie/EviSD.

# 论文总结：EviSD——面向搜索增强代理的证据条件自蒸馏

## 1. 核心问题与整体含义

- **背景**：检索增强生成（RAG）结合了外部证据与语言模型；进一步地，搜索增强推理代理将检索转化为**序列决策过程**，在内部推理与外部检索之间交替，并决定何时搜索、搜索什么、何时停止。
- **核心问题**：基于最终答案可验证奖励的强化学习（如 GRPO）虽然可扩展，但**轨迹级信用无法区分多轮搜索中每个动作的贡献**。最终奖励只告诉轨迹是否成功，却无法判断：
  - 哪次搜索暴露了有用证据；
  - 哪些生成 token 真正贡献了答案；
  - 正确回答是源于有效的搜索策略，还是源于“碰运气”的轨迹。
- 在**多轮搜索**中，一个早期精准查询可能决定后续所有推理，而模糊或冗余查询会让轨迹信息不足；但 GRPO 将同一轨迹优势广播到所有响应 token，检索到的段落又被当作环境观测而忽略，因此无法进行动作级的信用分配。
- **论文目标**：提出 **EviSD（Evidence-Conditioned Self-Distillation）**，利用**实例级支持证据**作为特权信息来精细化信用分配，同时保持原有 GRPO 的更新方向、不引入辅助蒸馏损失、不改变推理流程。

## 2. 方法论

### 2.1 核心思想
- 让**同一个模型同时扮演学生和特权教师**：
  - 学生从**原始推理上下文**中采样动作；
  - 教师从**动作对齐的特权上下文**（包含支持证据或黄金答案）中对同一动作进行重新评分。
- 将解耦的教师–学生差距通过**有界函数**转换为对 GRPO 优势的**有界修正**，并且**只应用于搜索动作和回答动作的内容 token**。

### 2.2 关键技术细节

1. **实例级特权上下文构造**
   - 搜索动作：教师上下文引入当前问题的**实例级支持证据**（按来源文档分组，最多 2 个文档、每文档 2 句）；
   - 回答动作：引入**黄金答案（含别名）**；
   - 其他动作：无特权，教师与学生的上下文一致，差距为 0。
   - 特权上下文通过对齐动作类型来构造：`e_x = P(a, c_priv) || x`。

2. **教师–学生对比**
   - 定义解耦的 token 级 log-likelihood 差距：
     `δ = sg[ log π_θ(y | e_x, y_{<t}) − log π_θ(y | x, y_{<t}) ]`
   - 正 δ 表示该动作 token 与证据/答案更兼容，负 δ 表示与特权视图冲突。

3. **动作跨度定位（Where）**
   - 引入二进制动作掩码 `m_act`，仅覆盖生成的搜索与回答动作内容 token；
   - 推理 token、分隔符、检索文本等均保持原始 GRPO 信用；
   - 这使特权指导高度局部化，只对关键决策 token 起作用。

4. **结果锚定的调制（How）**
   - 使用有界调制函数 `g_τ(δ) = tanh(τδ)`；
   - 调制项：`ΔA_priv = λ |A| g_τ(δ) m_act`；
   - 最终优势：`A_hat = A + ΔA_priv`；
   - 性质：
     - 修正量有界：`|ΔA_priv| ≤ λ |A|`；
     - 当 GRPO 优势为 0 时，特权信息不会产生更新；
     - 当 `λ < 1` 时，`A_hat` 保持与 `A` 相同的符号，即 GRPO 结果决定更新方向，特权信号只调节强度。

5. **训练目标与推理**
   - 使用标准 GRPO 裁剪目标，将原始优势替换为 `A_hat`；
   - 无辅助蒸馏目标；
   - 教师特权上下文和重评分仅在训练时使用，推理时与普通策略完全一致，无额外开销。

## 6. 主要结论与发现

- **性能**：在所有评估设置中，EviSD 的宏平均 EM 均为最高，超过最强基线 **1.3–2.3 个点**；
  - 7B 平均 EM：50.8（次优 49.0）；
  - 3B 平均 EM：47.2（次优 44.9）；
  - 1.7B 平均 EM：44.2（次优 42.9）。
- **搜索效率**：7B 上 EviSD 平均仅 1.87 次搜索/轨迹，低于 SDAR 的 2.16 和 RLSD 的 2.27，说明搜索动作更精准、更少冗余。
- **消融发现**：
  - **实例级证据可用性是性能提升的关键驱动力**：仅用答案上下文会使平均 EM 下降 2.1 点；
  - **动作跨度定位至关重要**：全响应调制会下降 7.1 点；
  - 响应级辅助蒸馏损失也比 EviSD 低 5.8 点，说明简单将蒸馏扩展到全部 token 反而有害。
- **训练动态**：EviSD 在训练全程保持高 on-policy 成功率；教师–学生差距始终非零且 KL 保持低位，表明策略渐进改进而非突然偏离参考模型。
- **对特权证据质量不敏感**：用相关文档替换一个 gold 文档不影响性能（44.2），替换两个仅下降 0.6 点，说明没有人工标注时也可以用相关检索文档作为特权监督。
