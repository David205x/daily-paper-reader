## 摘要
检索增强生成（RAG）提高了事实性，但在服务时增加了延迟和工程开销。我们提出了RING（检索内化生成），一种涵盖架构和训练的整体范式，将大规模外部知识注入到\textit{混合记忆专家}中，并通过强化学习学习对这种内部记忆的参数化搜索，完全消除了外部检索器。训练分三个阶段进行：持续预训练通过我们新颖的\textit{双重因果注意力}将新语料库注入知识专家；监督微调教授“先搜索后回答”的模式；具有分层奖励的强化学习优化了参数化记忆上的路由与搜索策略。与先前将内部记忆与固定或基于规则的检索器配对的参数化注入方法不同，RING直接从任务信号中学习其检索策略。我们进一步从理论上将RING构建为经典RAG目标的无搜索近似。为了评估大规模注入真正\textit{新}知识而不发生测试时泄漏，我们还构建了News-2025，一个基于严格晚于基础LLM预训练截止日期的新闻构建的基准。RING在准确性和效率上均匹配或超过了基于搜索的RAG和参数化注入基线。

## Abstract
Retrieval-augmented generation (RAG) improves factuality but adds latency and engineering overhead at serving time. We propose RING (Retrieval-Internalized Generation), a holistic paradigm spanning both architecture and training that injects large-scale external knowledge into a \textit{Mixture-of-Memory Experts} and learns parametric search over this internal memory via reinforcement learning, removing the external retriever entirely. Training proceeds in three stages: continued pre-training injects new corpora into a Knowledge Expert via our novel \textit{Dual Causal Attention}; supervised fine-tuning teaches a ``search-then-answer'' pattern; and reinforcement learning with hierarchical rewards optimizes the routing-and-search policy over the parametric memory. Unlike prior parametric injection methods that pair internal memory with a fixed or rule-based retriever, RING {learns} its retrieval policy directly from task signals. We further frame RING theoretically as a search-free approximation to the classical RAG objective. To evaluate large-scale injection of genuinely {new} knowledge without test-time leakage, we further construct News-2025, a benchmark built from news strictly post-dating the base LLM's pretraining cutoff. RING matches or surpasses both search-based RAG and parametric injection baselines in accuracy and efficiency.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **RAG 的局限**：检索增强生成（RAG）通过外部检索器为 LLM 提供外部证据，有效提升了事实性，但带来了显著的服务延迟和工程复杂度。即使生成式检索（Generative Retrieval）也仍依赖外部语料库来将文档 ID 映射为内容。
- **参数化注入的瓶颈**：纯粹参数化注入方法存在多种问题：
  - 知识编辑（Knowledge Editing）和持续学习（Continual Learning）难以处理非结构化更新，且存在灾难性遗忘；
  - 模块化注入方法（如 KBLAM、SR-KI）的存储开销随语料库体积线性增长；
  - Parametric RAG 仍依赖外部检索器进行推理阶段检索。
- **核心论点**：RING 认为参数化知识注入的瓶颈不在于“如何将知识存入权重”，而在于“如何在推理时从权重中搜索到相关知识”。已有参数化方法均使用固定或基于规则的检索机制（如注意力相似度、kNN 模仿、分层剪枝、无监督路由），在大规模场景下性能不如 RAG。
- **研究目标**：提出 RING（Retrieval-Internalized Generation，检索内化生成）整体范式——通过架构与训练的联合设计，将索引和检索全部内化到 LLM 参数中，彻底移除外部检索器，同时匹配或超越 RAG 的准确率，并大幅降低推理延迟。

## 2. 论文提出的方法论（核心思想、关键技术细节、公式或算法流程）

### 2.1 模型架构：Mixture-of-Memory Experts

- RING 将稠密解码器替换为稀疏 MoE（Mixture-of-Experts）层栈：
  - **基础专家（Basic Expert，E_base）**：保留原始 LLM 权重，缓解灾难性遗忘；
  - **知识专家（Knowledge Expert，E_knw）**：参数化记忆外部语料库，充当隐式索引；
  - **可学习路由器（Router，r_ϕ）**：在每层每个 token 位置做 Top-1 稀疏路由选择，判断应由哪位专家处理。
- **参数分离**：知识专家内部进一步分成记忆参数（Memory Up/Down，用于存储知识）和搜索参数（Search Gate + SiLU 门控，用于查询相关记忆）。这避免了不同训练阶段之间的相互干扰，支持增量式知识扩展。

### 2.2 三段式训练流程

1. **持续预训练（CPT）— 记忆阶段（Memorization）**：
   - 数据预处理：将长文档切分为多个三句话片段，与文档标题组成 JSON 格式的记忆单元；
   - 提出 **Dual Causal Attention（DCA，双重因果注意力）**：在训练时使用三种注意力掩码（α = 1, 1/2, 1/4），在保持自回归生成能力的同时为目标块提供双向上下文证据，增强记忆效率；
   - 训练时冻结除 Memory Down/Up 之外的所有参数，强制将所有 token 路由到知识专家，优化 DCA 损失。

2. **监督微调（SFT）— 学习“先搜索后回答”（Search-then-Answer）**：
   - 基于注入语料，用 Qwen3-235B 合成问题-答案-引用片段三元组，通过精确字符串匹配对齐到记忆单元；
   - 训练模型在生成时先输出 `<retrieval>` 块（生成 top-1 相关记忆片段），再输出 `<answer>` 块（最终答案）；
   - 仅训练 Router 和 Search Gate，冻结 CPT 阶段学到的记忆参数。

3. **强化学习（RL）— 搜索策略优化（Search from Parameters）**：
   - 使用 **GSPO** 算法，设计分层奖励：
     - **格式奖励（R_format）**：是否遵守搜索-回答输出格式；
     - **搜索奖励（R_search）**：包含三个稠密子奖励——标题 LCS 相似度（学习检索）、内容 LCS 相似度（学习重排）、精确匹配奖励（是否输出精确 top-1 记忆单元）；
     - **答案奖励（R_answer）**：用 Qwen3-30B-A3B 对答案正确性进行二元判断。
   - 总奖励为三者加权和，引导模型同时优化路由、搜索和生成。

- 构建 **News-2025** 基准：约 17 万条中英文新闻文档（约 3.41 亿 tokens），时间严格晚于基础 LLM（Qwen3）的预训练截止日期（2025 年 6–7 月），确保测试答案不可能来自预训练知识，避免测试时泄漏（test-time leakage）。

## 6. 主要结论与发现

1. **对参数化注入基线全面占优**：在 Qwen3-8B 上，RING 达到 35.08%（英）/32.36%（中），超过最强参数化方法 SR-KI 3.23/3.14 个百分点；在 14B 骨干上优势进一步扩大到至少 3.5 分。
2. **与外部搜索 RAG 处于准确率-延迟 Pareto 前沿**：在 8B 骨干上，最强 RAG 管线（Top-10+重排序）超出 RING 4.43（英）/8.69（中）分，但延迟高约 10 倍（4.05s vs 0.40s）；在 14B 骨干上，RING（41.19/37.92）在英文上超过该管线，中文仅落后不到 2 分，同时快 6 倍。
3. **延迟优势显著**：RING 的 TTFT（0.40s/0.75s）与全参数微调相当，比所有 RAG 变体快 3–19 倍。
4. **抗遗忘能力突出**：即使在不使用回放数据的顺序注入下，RING 仍保持 30% 以上准确率，而全量微调下降至 ~12%。
5. **RL 是关键环节**：仅靠 SFT 仅达 28.41%，SFT+RL 提升至 35.08%，且搜索奖励对性能贡献显著。
6. **理论保证**：RING 的假设空间包含显式 top-K RAG，参数化检索理论上可达到外部搜索的表达能力。

## 7. 优点（方法或实验设计上的亮点）

- **范式创新**：首次将“检索策略”本身作为可学习参数，通过 RL 端到端优化，彻底区别于已有参数化注入方法的固定/规则式检索机制。
- **理论-实践闭环**：ELBO 视角将三阶段训练统一到单一目标函数（CPT→证据最大化、SFT→后验对齐、RL→策略泛化），理论自洽性较强。
- **架构设计精细**：基础专家/知识专家的分工、记忆/搜索参数分离、DCA 双向记忆机制都针对明确的问题设计，兼顾了抗遗忘、增量扩展和推理效率。
- **基准构建严谨**：News-2025 严格晚于预训练截止，有效排除了“记忆泄漏”干扰，保障了评测的公平性。
- **消融系统深入**：从架构→注意力→训练阶段→奖励组件逐层验证各设计贡献，因果链清晰。

## 8. 不足与局限

- **动态知识更新能力弱**：RING 面向相对稳定的知识库，刷新参数化记忆需要重新训练；无法像外部索引那样即时增删文档，不适合高动态知识源场景。
- **可审计性与溯源不足**：生成的 `<retrieval>` 块可能压缩、转述甚至扭曲记忆内容，不同于外部数据库的逐字返回，严格引用或法律溯源场景需要混合设计兜底。
- **实验覆盖有限**：仅测试了知识密集型 QA 场景；未覆盖多跳 Web 搜索、快速变化事实、多语言知识库、带引用长文生成等更广泛的检索场景。
- **训练成本高**：CPT + SFT + RL 三阶段管线需要大量精心构造的数据和计算资源（虽未给出总 GPU 小时数，但 32×H800 的成本推测不低），推理收益需与前期投入做权衡。
- **RL 搜索奖励的超参依赖**：多个奖励权重（λ_a、λ_b、λ_c、λ_format、λ_answer、λ_search）和 LCS 匹配机制的敏感性分析不足，泛化到其他领域时需重新调优。
