## 摘要
现有的技能生成方法在很大程度上依赖于启发式方法或流水线式整合，这些方法必须针对不同的证据来源进行专门设计。相比之下，基于学习的方法提供了一种更统一的方式来建模跨异构来源的技能生成。然而，基于学习的技能生成仍然具有挑战性，因为技能缺乏基于相关性或正确性的自然监督信号；它们的价值在很大程度上只能通过它们是否改善了智能体在下游任务上的行为来确定。为了应对这一挑战，我们提出了Skill-$\alpha$，一种用于逐步生成高质量智能体技能的强化学习方法。具体来说，我们将技能生成形式化为一个顺序编辑过程，将技能构建分解为可单独评估的编辑，并引入了一种新颖的回滚奖励，通过比较在锚定查询下，原始技能和编辑后技能的下游执行情况来评估每次编辑。大量实验表明，在文档到技能和体验到技能两种设置中，Skill-$\alpha$生成的有效技能均优于基于启发式或流水线的方法。在主GPT-4o工作器下，与最强的技能生成基线相比，Skill-$\alpha$在CL-Bench上的平均下游成功率提高了3.3个百分点，在tau2-bench上提高了6.7个百分点。进一步的消融实验验证了回滚奖励和渐进式生成的重要性。

## Abstract
Existing skill generation methods largely rely on heuristics or pipeline-style consolidation, which must be specially designed for different evidence sources. In contrast, learning-based approaches offer a more unified way to model skill generation across heterogeneous sources. However, learning-based skill generation remains challenging because skills lack a natural supervision signal based on relevance or correctness; their value can largely be determined only by whether they improve the behavior of the agent on downstream tasks. To address this challenge, we propose Skill-$α$, a reinforcement learning method for progressively generating high-quality agent skills. Specifically, we formulate skill generation as a sequential editing process that decomposes skill construction into individually evaluable edits, and introduce a novel rollback reward that evaluates each edit by comparing downstream execution under the original and edited skills on an anchored query. Extensive experiments show that Skill-$α$ generates more effective skills than methods based on heuristics or pipelines in both document-to-skill and experience-to-skill settings. Under the main GPT-4o worker, Skill-$α$ improves average downstream success rates over the strongest skill-generation baseline by 3.3 points on CL-Bench and 6.7 points on tau2-bench. Further ablations validate the importance of rollback reward and progressive generation.

## 一、论文的核心问题与整体含义

- **背景**：大语言模型智能体（LLM Agent）常借助外部“技能”（skill）作为模块化程序单元来调节推理、规划与工具调用。因此，从文档或经验中**自动生成高质量技能**成为重要问题。
- **现有方法局限**：已有技能生成方法多依赖**启发式规则或流水线式整合**，针对不同证据来源需单独设计，缺乏统一的学习框架；且难以对“每一条证据应当如何改变技能”提供细粒度指导。
- **核心难点**：技能本身**缺乏天然监督信号**（不像数学推理或搜索有明确正确答案）。技能质量只能通过其对**下游任务行为的改变**间接判断。这使得基于学习的技能生成面临**执行层面的信用分配**难题。
- **本文工作**：提出 **Skill-α**，一种基于强化学习的渐进式技能生成方法。通过将技能构建拆解为可单独评估的**顺序编辑过程**，并引入**回滚奖励（rollback reward）** 实现执行导向的编辑级信用分配，从而在统一学习框架下同时覆盖“文档→技能”和“经验→技能”两类场景。

## 二、方法论

### 1. 核心思想
- 将技能生成建模为**序列化编辑决策问题**：给定初始技能草稿 $z_0$，按顺序读取证据 $x_1,\dots,x_T$，每一步由技能编辑策略 $\pi_\phi$ 采样一个局部编辑动作 $A_t$，更新当前技能 $z_t = \text{Edit}(z_{t-1}, A_t)$，最终得到技能 $z_T$。
- 该形式化将不同证据来源统一为同一“局部编辑”问题，避免为每种证据单独设计管道。

### 2. 编辑动作空间
- 定义动作集合 $\mathcal{A} = \{\text{CREATE}, \text{UPDATE}, \text{MERGE}, \text{PRUNE}, \text{NOOP}\}$：
  - **CREATE**：添加缺失的规则或流程；
  - **UPDATE**：修正不完整或不准确的规则；
  - **MERGE**：合并重叠内容；
  - **PRUNE**：删除有害、过度具体或冗余内容；
  - **NOOP**：当证据无新增价值时保持不变。

### 3. 回滚奖励（Rollback Reward）
- 对每一步编辑，选取与当前证据同源的**锚定查询** $q^{\text{anc}}_t$，使用固定工作智能体 $\pi_\psi$ 分别在**原始技能** $z_{t-1}$ 和**编辑后技能** $z_t$ 下执行该查询，获得对比结果：
  $$a^{\text{ctrl}}_t \sim \pi_\psi(\cdot | q^{\text{anc}}_t, z_{t-1}), \quad a^{\text{edit}}_t \sim \pi_\psi(\cdot | q^{\text{anc}}_t, z_t)$$
- 使用基准专用验证器 $V_t$ 分别打分 $r^{\text{ctrl}}_t$ 和 $r^{\text{edit}}_t$，定义回滚奖励：
  $$
  R_{rb}(A_t^{(i)}) = 
  \begin{cases}
  1, & \text{if } A_t^{(i)} \neq \text{NOOP and } r^{\text{edit}}_{t,i} > r^{\text{ctrl}}_t,\\
  1, & \text{if } A_t^{(i)} = \text{NOOP and no other valid edit beats } r^{\text{ctrl}}_t,\\
  0, & \text{otherwise.}
  \end{cases}
  $$
- 该奖励将“编辑是否改善下游执行”作为唯一信号，避免把工作智能体自身能力或简单查询误判为编辑的贡献。论文附录从理论上证明，在标定验证器假设下，期望回滚奖励保持理想排序；对二值验证器则等价于成功概率排序。

### 4. 训练实现
- 策略 $\pi_\phi$ 初始化为指令微调的 **Qwen3-8B**，先经过 **SFT 热身**（使用 DeepSeek-V4-Pro 合成的监督编辑数据），再用 **GRPO**（Group Relative Policy Optimization）进行强化学习优化。
- 训练时固定工作智能体为 **GPT-4o**；CL-Bench 上验证器为 GPT-5.5 rubric 评判，SpreadsheetBench 与 tau2-bench 上直接使用环境反馈。
- 论文还设置了确定性质量门控（如拒绝非法动作格式、空技能 NOOP 等），防止策略利用验证器漏洞。

## 六、主要结论与发现

- **性能提升**：在主 GPT-4o worker 下，Skill-α 相对最强技能生成基线在 CL-Bench 上平均提高 **3.3 个百分点**，在 tau2-bench 上平均提高 **6.7 个百分点**；在 SpreadsheetBench 上也有显著提升（从 18.00 到 27.50）。
- **统一框架有效**：一个学习到的生成器即可同时服务文档和经验两类证据源，而无需针对证据类型定制管道。
- **跨 worker 迁移**：在 Claude-Sonnet-4.5 上，Skill-α 仍保持最优或接近最优，说明学到的是可复用的任务知识而非单骨干提示捷径。
- **回滚奖励关键**：去掉回滚奖励后性能跌至接近“只 SFT”水平，说明执行级信用分配是训练有效的核心。
- **动作空间完整重要**：去除 MERGE/PRUNE 导致 tau2-bench 大幅下降；去除 NOOP 仍有较强表现但略低于完整模型，说明合理“不变”亦是必要能力。
- **证据粒度影响**：批大小为 4 时最优；过小导致局部过拟合，过大导致信息混杂、信用分配模糊；证据顺序影响较小。

## 七、优点

- **问题建模新颖**：将技能生成从一次性生成转为**渐进式编辑决策**，天然适配长文档和多段经验，且为强化学习提供了可分解的动作空间。
- **奖励设计针对性强**：回滚奖励通过“同一锚定查询下新旧技能对比”剥离工作智能体能力、查询难度等混淆因素，实现编辑级信用分配；理论分析给出排序保持条件，严谨性较好。
- **统一框架覆盖多源**：同一策略、同一接口处理文档和经验两种证据，避免了为每个来源单独设计管道。
- **实验设计较全面**：包含同工/跨工评估、消融、训练动力学、证据顺序与粒度分析，以及理论分析；并公开代码，便于复现。
- **动作空间具有可解释性**：CREATE/UPDATE/MERGE/PRUNE/NOOP 对应明确编辑语义，生成过程透明可控。

## 八、不足与局限

- **验证器依赖基准**：回滚奖励依赖 benchmark-specific 验证器（CL-Bench 用 GPT-5.5 rubric，SpreadsheetBench/tau2 用环境反馈），迁移到新环境需重新设计评估协议，泛化受限。
- **技能表示简单**：当前技能为文本 Markdown（SKILL.md）形式，未覆盖结构化、多模态或可执行技能格式。
- **奖励信号噪声**：单次回滚比较仅是二值伯努利样本，不能估计期望分数差；理论分析只保证局部排序，不保证多步更新后全局最优。
- **算力披露不足**：未给出 GPU 型号、训练时间或总计算量；RL 过程中反复调用工作智能体进行评估，实际开销可能较高。
- **对比公平性有潜在偏差**：Skill-α 通过 RL 在大量锚定查询上迭代优化，而基线多为一次性提示或流水线；二者计算预算不对等，可能使比较偏向 Skill-α。
- **实验覆盖有限**：主要面向三类基准（CL-Bench、SpreadsheetBench、tau2-bench），未在更广泛、更真实的智能体任务（如网页操作、代码生成、机器人控制）上验证；跨 worker 迁移也仅测试了 Claude-Sonnet-4.5 一个替代骨架。
- **超参敏感性**：证据批大小对结果影响显著（最佳为 4），该超参可能需要针对不同场景仔细调节；论文未深入讨论其自适应调整策略。
