## 摘要
现有的搜索增强型LLM智能体使用强化学习进行训练，以提升其推理能力。然而，这些方法主要依赖于结果级奖励，对搜索行为的监督很少，并且忽视了智能体适当分解复杂查询的能力。为了解决这个问题，我们提出PROGRESS，利用教师引导的覆盖率奖励来显式塑造策略模型的分解查询生成。在训练期间，冻结的教师模型用于将复杂查询分解为必要的搜索查询。这些必要的搜索查询用于指导策略模型的搜索行为。集成到R1风格训练框架中，我们的方法为查询分解决策提供了轻量级指导，而无需密集的过程级监督。实验表明，覆盖率引导的强化学习提高了整体任务性能，凸显了在智能体LLM中显式监督搜索策略的重要性。

## Abstract
Existing search-augmented LLM agents are trained using Reinforcement Learning to boost its reasoning capabilities. However, these approaches primarily rely on outcome-level rewards, which provide little supervision over search behavior and overlook agent's ability to decompose complex queries properly. To mitigate this issue, we propose PROGRESS which utilizes teacher-guided coverage reward to explicitly shape decomposed query generation of the policy model. During training, frozen teacher models are used to decompose complex queries into essential search queries. These essential search queries are utilized to guide the search behavior of the policy model. Integrated into an R1-style training framework, our approach provides lightweight guidance over query decomposition decisions without dense process-level supervision. Experiments show that coverage-guided RL improves overall task performance, highlighting the importance of explicitly supervising search strategies in agentic LLMs.

## 1. 核心问题与研究动机

- **背景**：搜索增强型LLM智能体在推理过程中可调用外部搜索引擎获取实时信息，已在多跳问答等知识密集任务中表现优异。此前研究表明，使用强化学习训练小规模LLM的搜索与推理能力是可行的。
- **核心问题**：
  - 现有RL训练方法（如Search-R1）主要依赖**结果级奖励**（如最终答案是否精确匹配），对搜索行为的监督非常稀疏；
  - 模型缺乏将复杂查询**正确分解为多个原子子查询**的能力，常出现使用原始复杂查询直接搜索、生成复合查询、搜索效率低下等行为；
  - 小语言模型（如3B参数量级）在查询分解方面的能力显著弱于强LLM。
- **核心洞察**：多跳推理的成功取决于**查询分解质量**与对**潜在信息需求的覆盖率**，而强LLM能够较好地近似这种搜索行为，可以作为教师来指导小模型的训练。

## 2. 方法论

### 2.1 总体框架

PROGRESS 基于 **Search-R1 训练范式**，采用 **PPO（近端策略优化）** 算法，将搜索引擎视为环境的一部分，通过检索token掩码与KL正则保持训练稳定性。

### 2.2 教师引导的必要搜索查询生成

- 使用**冻结的教师模型**（Qwen2.5-72B-Instruct）离线将复杂输入问题 x 分解为必要搜索查询集合 QT(x) = {qT₁, qT₂, ..., qT_K}；
- 这些教师查询并非固定推理轨迹，而是对成功解决任务所需的关键子问题的**高层抽象描述**。

### 2.3 覆盖率奖励（Coverage Reward）

- 策略模型生成轨迹 y，其中包含自身的搜索查询集合 QP(x,y) = {qP₁, qP₂, ..., qP_M}；
- 使用 **LLM judge**（Qwen2.5-72B-Instruct）基于**语义与粒度**双重标准，判定策略查询与教师查询的匹配集合 I(x,y)；
- 计算：
  - **Precision** = |I| / |Q_P| （惩罚冗余或无关搜索）
  - **Recall** = |I| / |Q_T| （衡量是否覆盖关键子问题）
  - **F1分数**（精确率与召回率的调和平均）= 2·P·R / (P + R)
- 使用F1平衡了查询的完整性与聚焦性，避免只生成大量松散查询或只覆盖少量子问题的策略。

### 2.4 总奖励函数

> r(x, y) = r_ans(x, y) + r_format(y) + λ_cov · r_cov(x, y)

- r_ans：答案精确匹配奖励（结果的EM准确率）；
- r_format：格式奖励（输出是否包含规定的search/think/answer标记）；
- r_cov：覆盖率奖励，λ_cov 经验设为 0.2。

### 2.5 特点

- 奖励属于**轨迹级**信号，而非逐token的过程级密集监督，保留了自回归生成的灵活性；
- 无需人工标注每一步的推理与搜索行为，只需教师模型离线生成一次性查询集合。

## 6. 主要结论与发现

- PROGRESS在全部三个多跳QA数据集（HotpotQA、2wiki、MuSiQue）上显著优于Zero-search和Search-R1等强基线，**相对Search-R1平均提升约1.5–3个百分点绝对EM**，其中MuSiQue上约提升2.4个百分点（16.01 vs 13.65）；
- 仅在多跳数据（HotpotQA）上训练时，PROGRESS在MuSiQue上达到18.57 EM，较Search-R1提升约5个百分点，说明覆盖率奖励对学习正确查询分解具有关键作用；
- 覆盖率奖励显著改善了**查询的完整性与粒度**（如2wiki上完整性从29.77升至40.63）；
- 检索准确率在三个多跳数据集上均有提升（平均44.96 vs 38.66），说明更好的查询分解直接转化为更优的检索结果；
- 方法在更小的1.5B模型上仍然有效，具有规模泛化性；
- 通用QA（NQ、TriviaQA、PopQA）上的性能与最优基线相当，没有明显牺牲。

## 7. 优点

- **轻量级监督**：只需教师模型离线生成查询集合，不依赖密集的逐步过程级标注，实用性高；
- **结构化搜索行为建模**：通过精确率与召回率的调和平均（F1），同时兼顾查询的**聚焦性**与**完整性**，机制设计合理且可解释性强；
- **训练稳定**：基于Search-R1框架（检索token掩码+KL正则），在强化学习不稳定性方面做了有效控制；
- **验证链条完整**：不仅报告答案EM，还深入分析了查询质量和检索准确率，证据链完整；
- **公平比较**：与Zero-search、Search-R1等在相同基础模型和训练资源设置下对比，并额外验证了不同模型尺度的泛化能力；
- **成本可观**：教师模型虽然是72B，但只做离线推理（查询生成和judge），不参与在线RL训练，训练开销可控。
