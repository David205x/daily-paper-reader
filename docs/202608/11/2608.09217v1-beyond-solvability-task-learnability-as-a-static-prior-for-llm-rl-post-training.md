## 摘要
强化学习（RL）已成为激发大型语言模型推理能力的核心后训练范式，然而统一的任务采样在分配计算时并未考虑任务对优化响应的差异。现有的任务评估方法主要依赖基于快照的信号，如当前通过率或奖励，这些信号估计的是在当前策略下任务的可解性。然而，当前可解性相似的任务在进一步训练中的积极响应程度可能大不相同。我们将这一残余轴研究为任务可学习性：在固定RL后训练体制下，对继续训练的预期积极响应的制度条件度量。通过分析每个任务奖励轨迹，我们发现可学习性在独立采样的训练上下文之间可复现，并能预测下游效用。为了使这一信号在训练开始前变得实用，我们提出了TrajVal，一种轻量级基于探针的估计器，它能从短暂探针运行和两次端点评估中近似每个任务的可学习性。TrajVal既可作为任务采样的独立静态先验，也可作为现有在线调度器的乘法先验。在多种模型规模的数学和逻辑推理基准上的实验表明，TrajVal相比统一采样提高了数据效率，并在与在线调度方法结合时提供互补增益。

## Abstract
Reinforcement learning (RL) has become a central post-training paradigm for eliciting reasoning capabilities in large language models, yet uniform task sampling allocates compute without regard to differences in how tasks respond to optimization. Existing task-valuation methods mostly rely on snapshot-based signals such as current pass rate or reward, which estimate how solvable a task is under the current policy. However, tasks with similar current solvability can still differ substantially in how positively they respond to further training. We study this residual axis as task learnability: a regime-conditional measure of expected positive response to continued training under a fixed RL post-training regime. By analyzing per-task reward trajectories, we find that learnability is reproducible across independently sampled training contexts and predictive of downstream utility. To make this signal practical before training begins, we propose TrajVal, a lightweight probe-based estimator that approximates per-task learnability from a short probe run and two endpoint evaluations. TrajVal can be used either as a standalone static prior for task sampling or as a multiplicative prior for existing online schedulers. Experiments on mathematical and logical reasoning benchmarks across multiple model scales show that TrajVal improves data efficiency over uniform sampling and provides complementary gains when combined with online scheduling methods.

### 1. 核心问题与整体含义

- **研究动机**：在 LLM 的 RL 后训练中，训练池包含大量任务，但不同任务对优化过程的贡献差异显著。当前主流做法（均匀随机采样）未考虑这种异质性，导致计算资源分配效率低下。
- **关键缺陷**：现有任务估值方法（如 BOTS、GRESO）大多依赖**快照式信号**（当前通过率或奖励），即衡量任务的"当前可解性"（solvability）。但两个当前可解性相似的任务，其对持续训练的积极响应程度可能截然不同。这种"残余差异"正是本文研究的核心。
- **核心概念引入**：论文提出 **任务可学习性（learnability）** ——一个制度条件化的度量（regime-conditional measure），指在固定 RL 后训练体制（模型族、初始化、优化算法、奖励函数、数据来源、训练预算）下，任务对继续训练的预期积极响应的程度。
- **整体意义**：可学习性与可解性是互补的任务价值维度。只关注可解性会遗漏关于未来训练响应的关键信息，导致对"仍有提升潜力"的任务分配不足。将可学习性作为**静态先验**纳入采样策略，可同时提升收敛速度与最终性能，并可与现有在线调度方法互补。

### 2. 方法论：核心思想、技术细节与流程

#### 2.1 核心思想

论文通过三条递进的论证线索建构方法论：

1. **观察**：通过追踪训练过程中每个任务的奖励轨迹，发现任务之间存在高度异质的学习响应——有的稳定上升（STABLE/SLUGGISH），有的平坦或噪声化（INEFFECTIVE），有的饱和（MASTERED/UNLEARNED），有的甚至衰退（FORGETTING）。这些差异无法从单个快照中看出。
2. **验证**：可学习性信号具有两个实用属性——跨上下文可复现（不同随机训练混合下任务级判断高度一致）和可预测下游效用（按可学习性分配数据可显著提升训练效率）。
3. **简化**：为将可学习性变为训练开始前即可用的实用信号，论文应用了两个降维操作——用**端点摘要**替代密集轨迹，用**短探针运行**替代完整池训练。

#### 2.2 关键技术细节：TrajVal 的两个降维

**降低 I：从密集轨迹到端点摘要**

- 只需保留两个统计量：早期平均奖励 `r̄_early` 和晚期平均奖励 `r̄_late`，以及它们的差值 Δ = r̄_late − r̄_early。
- 每个统计量通过对 K 个检查点（checkpoint）上的任务准确率取平均得到；主实验采用最经济的 K=1 设置。
- 通过将任务投影到斜率–R² 空间验证，仅由端点对导出的标签在独立于端点近似的空间中仍然保持良好的分离性，说明端点摘要保留了可学习性排序所需的关键信息。

**降低 II：从完整池训练到探针训练**

- 从训练池 D 中均匀采样一个小规模探针集 P（|P| ≪ |D|，默认 |P|=512，约占池的 3%）。
- 在 P 上对基础模型 θ₀ 进行短周期 RL 训练（T 个 epoch），得到探针训练模型 θ_probe 及各检查点。
- 用 θ_probe 在完整池 D 上做两次推理，得到每个任务的 `r̄_early` 和 `r̄_late` 估计值。
- 验证结果表明，探针估计值与完整训练得到的 oracle 值之间的 Spearman 相关系数高达 ρ=0.940（早期）和 ρ=0.876（晚期），相对排序基本保留。

#### 2.3 连续可学习性评分与采样权重

论文用以下公式将探针统计量转换为任务采样权重：

- **方向性对齐项**：max(0, Δ(x)) —— 抑制奖励平坦或下降的任务
- **学习余量项**：(1 − r̄_early(x)) —— 降低已接近饱和任务的权重

两者相乘得到可学习性分数：

> s(x) = (1 − r̄_early(x)) · max(0, Δ(x))

- **功率压缩与概率下限**：w(x) = max(s(x)^α, ε)，其中 α ∈ {0.1, 0.3, 0.5} 控制分数压缩程度（默认 α=0.3），ε=0.05 作为概率下限，确保每个任务保留最小采样概率，防止采样过度集中。
- **最终采样分布**：p(x) = w(x) / Σ w(x′)

#### 2.4 与在线调度器的集成

TrajVal 的静态先验可与现有在线调度器**乘法组合**：

> w_final(x, t) = w_TrajVal(x) · w_online(x, t)

这种组合天然互补：TrajVal 提供从初始化开始的稳定离线先验，而在线调度器根据策略演化进行自适应调整，弥补了在线方法在训练早期证据不足时的分配缺陷。

### 6. 主要结论与发现

1. **可学习性确实独立于可解性**：初试通过率相似的任务在持续训练中可能呈现截然不同的响应趋势；within-pre-bin 分析证明，在匹配初始通过率后，高 Δ 任务在所有 bin 中均优于低 Δ 任务。
2. **可学习性跨上下文可复现**：在独立采样的训练混合中，任务的可学习性特征保持一致（Cohen's κ ≥ 0.776），支持其作为稳定任务级信号使用。
3. **TrajVal 作为独立方法有效**：相比均匀采样，TrajVal 在所有 4 个域–规模配置中同时提升 Best Acc 和 AUC，并显著加速收敛（Logic 4B 下 S2B 低至 40%）。
4. **TrajVal 作为插件先验同样有效**：与 BOTS 和 GRESO 组合时，在所有配置中均提升 Best Acc 和 AUC，并降低 S2B，证实静态先验与在线调度方法互补。
5. **分数设计依赖双因子联合**：单独使用 pre、post 或 Δ 均不如完整乘积形式，说明"学习余量"与"方向性响应"缺一不可。
6. **探针排序提前稳定**：Spearman 相关度在探针 epoch k=14（共 20）即达 ρ ≥ 0.85，探针预算可缩短约 30% 而不显著损失信号质量。

### 7. 优点

- **概念创新**：清晰地区分"可解性"与"可学习性"，将训练动态视角引入 LLM RL 后训练任务估值，补充了快照式信号无法捕捉的时间维度。
- **方法轻量实用**：仅需约 3% 池规模的探针训练 + 两次推理即可获得有效先验，计算开销（约 0.01% 流水线时间）远低于收益（S2B 最低可降至 40%）。
- **设计简洁**：评分为 (1 − pre)·max(0, Δ) 的乘积形式，具有明确的直觉解释；功率压缩 + 概率下限保证采样覆盖度。
- **即插即用**：天然适配现有在线调度器，以乘性先验方式融合，无需修改在线方法的内部机制。
- **验证严谨**：包含受控 within-bin 分析（隔离 Δ 效应）、跨上下文稳定性验证（Cohen's κ 统计）、跨模型族验证（Qwen + Llama）、跨体制迁移分析和计算开销审计等，证据链条完整。
- **透明性**：代码已在匿名仓库开源（GitHub）。

- **领域覆盖有限**：仅在数学和逻辑推理任务上验证，且奖励信号均为二值精确匹配；对于开放生成、模型评分器（LLM judge）等非二值奖励场景是否适用尚未验证。
