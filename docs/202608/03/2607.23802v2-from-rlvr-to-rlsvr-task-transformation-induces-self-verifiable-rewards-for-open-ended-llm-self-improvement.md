## 摘要
基于可验证奖励的强化学习（RLVR）通过支持大规模优化，推动了面向推理的大型语言模型（LLM）的近期进展。然而，其适用性在很大程度上仍局限于数学和编程等领域，在这些领域中正确性可以被确定性验证。相比之下，开放式的任务通常依赖人类偏好、奖励模型或基于LLM的评判者，从而引入评估偏差、评判者能力瓶颈以及额外的推理成本。借鉴自监督学习的原则，即构建前置任务以从数据本身获取监督信号，我们提出了一种基于任务转换的训练范式——基于自验证奖励的强化学习（RLSVR），旨在将RLVR扩展到开放式任务。RLSVR将开放式任务转换为可验证的代理环境，其内部规则和交互结果自动生成奖励信号。我们用SpyRL实例化了RLSVR，这是一种受社交推理游戏《谁是卧底？》启发的自我博弈强化学习方法。智能体接收不对称信息，完成相同的目标任务，并通过投票识别指定的卧底。由于卧底身份是预先确定的，投票结果提供了完全可验证的奖励，而成功识别与输出质量密切相关。在文本摘要、创意写作和数学推理上的实验表明，SpyRL在非可验证任务上优于现有的自我改进方法，并在可验证推理任务上产生一致的收益。这些结果表明，任务转换可以将基于RLVR的可扩展自我改进扩展到固有可验证领域之外。模型和代码已在https://github.com/wangqinsi1/RLSVR/tree/SpyRL发布。

## Abstract
Reinforcement Learning with Verifiable Rewards (RLVR) has driven recent progress in reasoning-oriented large language models (LLMs) by enabling large-scale optimization. However, its applicability remains largely limited to domains such as mathematics and coding, where correctness can be deterministically verifiable. Open-ended tasks instead often rely on human preferences, reward models, or LLM-based judges, introducing evaluation bias, judge capability bottlenecks, and additional inference costs. Drawing on the principle of self-supervised learning, which constructs pretext tasks to derive supervision from the data itself, we propose Reinforcement Learning with Self-Verifiable Rewards (RLSVR), a task-transformation-based training paradigm for extending RLVR to open-ended tasks. RLSVR transforms open-ended tasks into verifiable proxy environments whose internal rules and interaction outcomes automatically generate reward signals. We instantiate RLSVR with SpyRL, a Self-PlaY Reinforcement Learning method inspired by social deduction game Who Is the Spy?. Agents receive asymmetric information, complete the same target task, and vote to identify a designated spy. Because the spy identity is predetermined, voting outcomes provide fully verifiable rewards, while successful identification remains closely related to output quality. Experiments on text summarization, creative writing, and mathematical reasoning show that SpyRL outperforms existing self-improvement methods on non-verifiable tasks and yields consistent gains on verifiable reasoning tasks. These results demonstrate that task transformation can extend scalable RLVR-based self-improvement beyond inherently verifiable domains. Models and code have been released at https://github.com/wangqinsi1/RLSVR/tree/SpyRL.

## 2. 方法论

### 2.1 RLSVR 总体框架（四个步骤）

1. **隐变量注入（Latent-variable injection）**：从输入分布 $D$ 采样 $x$，环境额外采样一个隐变量 $z$ 作为该 episode 的 ground truth（具体形式可为"哪个输入被扰动"、"哪部分被隐藏"等），但不对策略直接透露。
2. **条件化任务执行（Conditioned task execution）**：环境基于 $(x, z)$ 构造观察 $o$，策略在 $o$ 上执行**原始目标任务**，生成输出 $y \sim \pi_\theta(\cdot \mid o, \tau)$。这保证了代理环境中所训练的能力和目标任务高度一致。
3. **可验证交互（Verifiable interaction）**：环境规则基于输出对 $z$ 提出一个问题（例如"哪个输出是由被隐藏信息的人生成的"），且回答正确与否与输出质量密切相关。
4. **规则化奖励（Rule-based reward）**：环境将交互结果与 $z$ 对照，计算确定性奖励。该奖励不需要人类标注、不需要学习型奖励模型、也不需要外部评判者。

### 2.2 SpyRL 实例化：信息不对称自博弈

- **整体结构**：SpyRL 将开放任务改造成类似"谁是卧底"的多智能体博弈，每轮包含**表演阶段（Performing Stage）**和**检测阶段（Detection Stage）**，形成闭环迭代训练。
- **信息不对称设计**：
  - $n$ 个玩家中，$n-1$ 个平民（civilian）获得完整信息 $x$，1 个卧底（spy）获得退化信息 $g(x)$（如表征级连续掩码、局部上下文删除等）。退化算子 $g(\cdot)$ 只移除任务关键信息，保留文体、长度和主题一致性，防止检测者利用表层捷径。
  - 每个玩家用各自观察执行目标任务（摘要、写作或数学问题构造与求解），生成公开输出 $y_i$。
- **检测阶段**：每个玩家基于自己的观察和全部公开输出，投票推断谁是卧底 $v_i \sim \pi^D_\phi(\cdot \mid (o_i, Y))$。由于卧底身份由环境预先指定，投票是否正确可以**完全可验证**：$r^D_i = \mathbb{I}[v_i = u]$。
- **表演阶段奖励（零和设计）**：
  - 卧底奖励：$r^P_u = -\beta(m_u - \bar{m}_c)$（被投票越多惩罚越大）；
  - 平民奖励：$r^P_{c_j} = \frac{\beta}{n_c}(m_u - \bar{m}_c) - \lambda(m_{c_j} - \bar{m}_c)$（内含平民间的组内竞争）；
  - 满足零和约束 $r^P_u + \sum_j r^P_{c_j} = 0$，促进双角色持续共演化。
  - 用 **Role-Advantage Estimation (RAE)** 对不同角色分别维护 EMA 基线，消除信息不对称带来的奖励分布偏差。
- **优化目标**：采用 GRPO 风格的裁剪目标 + KL 正则，分别优化表演策略 $\pi^P_\theta$ 和检测策略 $\pi^D_\phi$（见公式 7、8）。
- **交替训练策略**：两阶段交替更新而非同时更新，通过检测准确率 / 不确定性阈值（滞回控制 + 最小驻留时间）动态切换训练阶段，避免固定自博弈中的策略停滞、奖励失真和共同演化失败。

- **算法流程**（Algorithm 1）：每轮采样 $x$ 和卧底索引 $u$ → 构造不对称观察 → 所有玩家生成输出 → 所有玩家投票 → 计算检测奖励（验证正确性）与表演奖励（-β·投票数）→ 用 GRPO 分别更新两个策略 → 依据检测表现动态切换下一轮训练阶段。

## 6. 主要结论

- **RLSVR/SpyRL 在非可验证（开放式）任务上显著超越现有自改进方法**：Qwen3-8B 在摘要上平均 A/B 胜率 75.4%，创意写作 77.3%（对自身 backbone），大幅超过 R-Zero（几乎无提升甚至退化）和 Absolute Zero（小幅度提升）。
- **在可验证任务上同样有增益**：Qwen3-4B/8B 数学推理平均提升 8.97%/6.16%（7 基准均值），在 AIME25 上 Qwen3-4B 从 6.7 提升到 20.0。
- **投票与质量正相关**：获得越多怀疑票的输出其 GPT-4o 质量排名越差（图 4），说明规则化投票奖励与真实任务质量高度对齐。
- **跨任务迁移具有方向性**：摘要与创意写作相互正迁移；数学推理训练对写作任务负迁移。
- Agent 内部 ablation 表明：**两阶段交替优化、信息不对称的卧底机制、RAE 角色校准**都是关键组件，缺一不可。
- 总体：任务转换可以将 RLVR 范式扩展到缺乏直接验证信号的开端任务，实现**无外部评判者的可扩展自改进**。

## 7. 优点

- **思想新颖**：将 SSL 的"前置任务构造标签"思想迁移到 RLVR 的奖励构造，提出 RLSVR 这一通用范式，理论定位清晰（任务转换 Φ 是 pretext，隐变量 z 是自动标签）。
- **无需外部验证器**：奖励完全由环境规则和预分配身份产生，避免 RLHF/裁判模型带来的偏差和额外成本。
- **信息不对称设计巧妙**：卧底必须"在信息不足条件下尽力完成目标任务而不被发现"，迫使模型生成质量真正更高、更有说服力的输出；同时退化算子保留表面一致性，防止检测者钻空子。
- **奖励设计合理**：表演阶段零和奖励 + 组内竞争 + RAE 角色基线，保证双角色持续对抗共演；检测阶段组内归一化优势（GRPO 风格）降低方差。
- **交替训练机制**：解决了固定自博弈中策略停滞、评价失真问题，有明确的切换阈值和最小驻留约束。
- **实验全面**：覆盖 3 大任务域、多种 backbones、多种评估方式（自动指标 + 双 LLM 评判者 + 人类盲评 + 跨域迁移 + 多种消融），可复现性好（开源代码）。
- **工程实践考量**：掩码比例敏感度低（20% vs 40% 差异不大），说明方法对具体退化算子选择不敏感，易迁移到新任务。

## 8. 不足与局限

- **模型规模覆盖有限**：所有实验只在 Qwen3-4B/8B 上进行，缺乏更大模型（如 70B 级）验证，无法确认方法在大模型上的扩展性和收益趋势。
- **训练成本偏高**：100 epochs × batch 1024，8 卡集群训练；虽然论文对比了 RaR 的外部验证器成本，但未报告自身训练耗时，实际训练开销可能不低。
- **退化算子设计仍需任务特定实例化**：虽然掩码比例不敏感，但 g(·) 的选择（连续 span 掩码 vs 局部上下文去除）仍因任务而异，需要一定的领域判断。
- **数学任务中的检测标准可能偏向"完整性"而非"推理深度"**：数学代理环境中卧底因信息缺失而暴露，可能主要惩罚"遗漏条件"而未必能精细区分不同推理路径的质量。
- **跨任务负迁移**：数学训练模型在写作任务上显著负迁移（40.9% 胜率），说明该方法获得的能力还不是通用的开放式能力，而是有一定任务边界。
- **潜在博弈坍塌风险**：虽然交替训练缓解了局部均衡，但论文没有分析长训练时长下是否出现"双角色互相欺骗但实际任务质量停滞"的退化模式。
- **LLM 评判的主观性**：虽然使用了双 LLM 评判者 + 人类验证，但检测阶段中"投票"本身由 πD 生成，其质量受限于检测策略的判别能力——如果检测器存在系统性盲区，表演者可能学会利用该盲区获得高奖励而非真正提高质量。
- **检测阶段成本**：多智能体交互需要多次 rollout 和投票推理，比单模型 RLVR 的推理成本更高。
