## 摘要
多轮信息寻求对话既需要多跳推理，也需要跨轮次的长程依赖跟踪。然而，现有的RAG系统通常将对话记忆表示为原始对话历史、重写查询或非结构化摘要，使得难以恢复后续查询所需的特定先前推理步骤和证据。我们的关键见解是通过将对话上下文表示为子问题级别的推理痕迹，来使对话记忆与检索对齐。基于这一见解，我们引入了MuMu-QA，一个具有明确跨轮次子问题依赖标注的多轮多跳RAG基准，以及CMT-RAG，一种用于该场景的互补记忆框架。在每一轮中，CMT-RAG采用状态空间痕迹生成器，其循环状态作为运行时记忆，以纳入最近的对话上下文并将当前查询分解为包含面向检索的子问题和对早期痕迹依赖的结构化痕迹草稿。然后，它用检索到的证据为基础，将这些草稿存储为会话级有向无环图中的持久记忆痕迹，使未来轮次能够高效地恢复相关的先前推理和证据。在MuMu-QA和语料库级RAG基准上的实验表明，CMT-RAG在答案准确性上持续优于五类RAG基线。

## Abstract
Multi-turn information-seeking conversations require both multi-hop reasoning and long-range dependency tracking across turns. However, existing RAG systems typically represent conversational memory as raw dialogue history, rewritten queries, or unstructured summaries, making it difficult to recover the specific prior reasoning steps and evidence required for follow-up queries. Our key insight is to align conversational memory with retrieval by representing dialogue context as sub-question-level reasoning traces. Building on this insight, we introduce MuMu-QA, a benchmark for multi-turn multi-hop RAG with explicit cross-turn sub-question dependency annotations, and CMT-RAG, a complementary memory framework for this setting. At each turn, CMT-RAG employs a state-space trace generator, whose recurrent state serves as runtime memory, to incorporate recent conversational context and decompose the current query into structured trace drafts containing retrieval-oriented sub-questions and dependencies on earlier traces. It then grounds these drafts with retrieved evidence and stores them as persistent memory traces in a session-level DAG, enabling future turns to efficiently recover relevant prior reasoning and evidence. Experiments on MuMu-QA and corpus-level RAG benchmarks show that CMT-RAG consistently outperforms five categories of RAG baselines in answer accuracy.

- **核心问题（现有方法的弊端）**：

  - 查询分解方法（如 IRCoT、Self-Ask）虽能暴露子问题结构，但通常假设查询是自包含的且依赖关系仅存在于当前轮内。

- **核心洞察（Key Insight）**：应当将"对话记忆"与"检索需求"对齐——把对话上下文表示为**子问题级别的推理痕迹（sub-question-level reasoning traces）**。一个有用的记忆单元应当：(1) 保留检索目标；(2) 暴露解析缺失参数的依赖关系；(3) 保留使先前答案成立的证据。子问题级痕迹恰好打包了这三要素，使跨轮召回从"全局历史解读"简化为"痕迹选择与证据复用"。

## 二、论文提出的方法论

### 2.1 任务形式化定义

- 将多轮多跳对话 RAG 形式化为**会话级痕迹 DAG 归纳**（trace-DAG induction）。
- 每个节点（trace, answer） 中的 trace 绑定四元组：
  - **子问题**（q_sub）：被 reader 和 retriever 消费的自然语言子问题；
  - **关键词**（kw）：用于 DAG 查找的轻量级锚点；
  - **依赖边**（deps）：指向先前必要痕迹的先决条件集合；
  - **段落 ID 集**（para_ids）：直接从语料 C 中为本子问题检索到的段落。
- 每一条边表示：被依赖的痕迹引入了某实体/主题，当前痕迹在此基础上继续推理，从而**将对话记忆单元与检索单元统一为同一个持久化对象**。

### 2.2 CMT-RAG 框架：两条互补记忆通道

本框架的核心思想是通过两个互补通道将对话状态完全外部化：

- **通道一：状态空间痕迹生成器（SSM Trace Generator）——局部短期记忆**
  - 基于 **Mamba-2** 骨干（2.7B），利用其选择性状态空间混频器（selective state-space mixer）的循环状态 `h_t` 作为**运行时记忆（runtime memory）**，在轮次间传递。
  - 好处：避免每轮重复编码完整历史，减少"lost-in-the-middle"影响，支持高效长对话生成。
  - 每轮输入当前查询 `q_t` 和前一轮隐状态 `h_{t-1}`，输出结构化痕迹草稿集合和更新后的状态 `h_t`：
    - `{T_draft_k}, h_t = TraceGen_θ(h_{t-1}, q_t)`。
  - 草稿形式为三元组：`(q_decom_k, kw_k, deps_k)`，其中 `q_decom` 是分解出的子问题、`kw` 是关键词、`deps` 是依赖的先前痕迹标识符列表。
  - 引入**全局痕迹命名空间**：每个完成的痕迹分配持久标识符 `[T_k]` 和对应的答案引用 `[A_k]`，使得"依赖解析"变成显式的标识符引用操作。

- **通道二：会话级痕迹 DAG（Trace DAG）——持久长期记忆**
  - 每轮对草稿执行**引用解析**（将 `q_decom` 中的答案引用 `[A_i]` 替换为被引用痕迹的实际答案），得到可检索的 `q_sub`。
  - 同时执行两种证据收集：
    - **依赖边直接恢复证据**：从被引用的历史痕迹节点直接取出其存储的段落 ID。
    - **关键词检索历史痕迹**：通过轻量级词法匹配（二进制余弦/Ochiai 系数）找回额外的历史痕迹，并复用其证据段落。
  - 对解析后的子问题，用 DRAGON 稠密检索器从外部语料中获取新段落 `P_local`。
  - 合并历史证据与新证据，形成最终证据集 `P_k = P_local ∪ P_prior`。
  - 完成痕迹 `T_k = (q_sub, kw, deps, P_local)` 连同子答案 `a_k` 以拓扑顺序追加到 DAG 中。
  - **Reader 保持无状态**：只接收"解析后的子问题 + 组装好的证据"，不重放对话历史。

### 2.3 训练方法：课程学习 + DPO

- **三阶段课程 SFT**：
  - 阶段1：单轮示例，学习轨迹语法与基本分解结构；
  - 阶段2：短多轮对话，引入跨轮依赖；
  - 阶段3：长多轮对话，增加对话长度与跨轮依赖密度，同时重放早期阶段样本防止遗忘。
  - 目标为线性化黄金轨迹序列上的自回归语言建模损失。
- **DPO 偏好优化**：
  - 从长对话模型采样多个候选轨迹，通过固定检索-reader 流水线执行。
  - 组合奖励：`R(τ; c) = F_final(τ) + γ · F_sub(τ)`，其中 `F_final` 是最终答案 F1，`F_sub` 是匹配子问题的平均 F1，默认 γ=0.2。
  - 偏好对由奖励差至少 0.05 的最高与最低奖励轨迹构成；无效格式轨迹在配对前过滤，得到 45,420 个离线偏好对。

### 2.4 推理流程（Algorithm 1）

1. 由 SSM 生成器基于 `h_{t-1}` 和 `q_t` 产出痕迹草稿与更新状态 `h_t`；
2. 按拓扑序处理每个草稿：引用解析 → DAG 依赖证据检索 → 关键词痕迹检索 → 新证据检索 → 合并证据 → reader 回答子问题；
3. 将完成的痕迹与子答案追加至 DAG；
4. 最后用一次额外的 reader 调用，将当前轮用户查询、子问题与子答案聚合成最终答案 `a_t`。

## 三、实验设计：数据集、基准与对比方法

### 3.1 基准：MuMu-QA（论文自建）

- **来源**：由 MuSiQue 多跳问答数据集合成。
- **合成算子**：
  - **子问题重定位（Sub-question Relocation）**：把一个子问题移动为单独一轮，改写剩余的推理链为依赖该轮答案的后续问题，从而形成跨轮依赖。
  - **图拼接（Graph Splicing）**：通过"桥接答案"连接两个推理链——先导轮解决桥接实体，后续轮从该实体继续推理，显式依赖先前的痕迹节点。
- **三种对话长度划分**：
  - 短对话（short）：3–7 轮，用于训练；
  - 长对话（long）：6–32 轮，训练+开发（主评测）；
  - 超长对话（ultra-long，压力测试）：33–67 轮，仅用于评估长度外推能力。
- **标注信息**：对话级子问题命名空间、跨轮依赖边、痕迹关键词、支撑段落 ID、完整痕迹 DAG 监督——这是此前多轮 RAG 基准（如 CORAL、MTRAG）所不具备的细粒度标注。
- **泄漏控制**：按支撑文档标题和桥接实体分组划分，防止训练/开发时共享相同证据配置。

### 3.2 对比方法（五类基线）

### 5.2 充分性评估

- **规模充分**：主实验覆盖 14 种以上基线，涵盖五种方法范式（直接 RAG、智能体、对话上下文、查询分解、对话结构），对比范围广。
- **控制变量严谨**：所有基线共享同一 reader、同一 DRAGON 检索器与同一语料，排除检索与生成能力差异带来的干扰。
- **消融系统**：从框架整体到记忆通道再到单个证据来源均有对应消融，能清晰回答"哪个组件贡献了什么"。
- **迁移实验适度**：三个外部基准覆盖了多轮对话检索、单轮多跳 QA 等邻近任务，但缺少在另一个多轮多跳对话基准（如 CORAL、MTRAG）上的直接对比，是充分性的一个小缺口。
- **统计显著性**：论文未报告多次运行的标准差或显著性检验（如 bootstrap 检验），对提升幅度（如 +7.8 EM）的稳健性未做统计验证，属于方法论上的小瑕疵。

## 六、主要发现与核心结果

### 6.1 主实验结果（MuMu-QA，长对话集）

- **CMT-RAG 显著领先**：在 Qwen3-32B reader 上，EM 达到 **58.0**，比最强基线的 44.8 提升 **13.2 个点**；token-level F1 为 72.9 vs. 60.8（+12.1）。在 Llama-3.3-70B reader 上模式一致（EM 60.3 vs. 47.2，+13.1）。
- **五个关键结论**：
  1. **显式子问题分解优于隐式依赖压缩**：所有将依赖压缩进单一查询的方法（如 ChatQA、RQ-RAG）显著落后于显式分解类方法，验证了"子问题级记忆"的核心主张。
  2. **结构记忆优于原始历史回放**：UnstructuredDDP、RLTST 等基于话语/关系图的方案弱于痕迹级 DAG，说明"检索依赖"才是对话记忆应该对齐的粒度。
  3. **互补记忆通道缺一不可**：去掉 SSM 通道（只留 DAG）或去掉 DAG 通道（只留 SSM）均导致明显下降；两者结合在长对话上收益最大。
  4. **证据复用是关键增益来源**：通过依赖边直接恢复历史证据（而非重新检索）贡献了最大比例的提升，尤其在长对话后期轮次。
  5. **关键词痕迹匹配是廉价而有效的补充**：轻量级词法匹配虽简单，但在 DAG 依赖稀疏时能高效找回丢失的痕迹。

### 6.2 误差分析

- **证据扰动**：当证据集包含来自误匹配痕迹的干扰段落时，reader 容易混淆答案归属。
- **痕迹漂移**：在超长对话（33–67 轮）中，SSM 的隐状态遗忘导致草稿质量下降，部分痕迹关键词不再与早期锚点对齐。
- **关键词失配**：用户指代与文献中出现形式不一致的桥接实体，导致词法匹配失败（例如别名、缩写），此时退化为新证据检索但依赖丢失。

### 6.3 延迟与效率

- CMT-RAG 的端到端延迟约为基础 C-RAG 的 1.6 倍，主要开销来自多个子问题的顺序检索与 reader 调用；
- 但由于无状态 reader 无需重放历史、SSM 避免重复编码，在全历史基线（replay-based）上的延迟节省显著，随对话长度增长优势扩大。

## 七、论文的局限性与未来方向

1. **超长对话仍存在隐状态遗忘**：压力测试（ultra-long）中 EM 明显低于长对话，SSM 记忆容量是主要瓶颈；
2. **合成数据依赖**：MuMu-QA 由 MuSiQue 合成，天然带有"子问题可分解"的结构偏置，可能低估了现实对话的指代多样性、噪声与开放性；
3. **关键词匹配过于简化**：基于词法匹配的历史痕迹召回在面对语义等价表达（如"计算机科学之父" vs. "图灵"）时鲁棒性不足；
4. **reader 无状态设计的代价**：最终答案聚合仅依赖当前轮子答案，若子答案本身有误，聚合阶段缺乏全局纠错能力；
5. **检索器未参与训练**：DRAGON 检索器固定不变，痕迹生成器无法根据检索反馈调整分解策略，端到端联合优化是潜在改进；
6. **跨语言与模态**：当前仅在英文文本语料上验证，对多语言或多模态对话 RAG 未做探究；
7. **未来方向**：可学习的关键词替代策略（如小型编码器）、记忆压缩与遗忘机制、人机交互式痕迹修正、以及在真实对话日志上的验证。

## 八、对后续研究的启示与总结性评价

- **理论贡献**：首次明确提出"对话记忆粒度应等于检索依赖粒度"这一洞察，并以"子问题级痕迹 DAG"作为统一记忆单元；提出的两个互补通道（SSM 运行时记忆 + DAG 持久记忆）为多轮对话系统提供了可复用的设计范式。
- **工程贡献**：代码、模型权重、MuMu-QA 数据集及标注将开源，为社区提供标准化训练与评测基准。
- **客观评价**：论文工作量大、实验完备、写作清晰，在"多轮检索级依赖建模"问题上代表了当前最先进的系统性解决方案；但合成数据偏置、关键词机制朴素、统计检验缺失等问题使得其结论的普适性仍有待真实对话场景检验。

**总体一句话**：CMT-RAG 通过将对话记忆重构为子问题级互补记忆痕迹（SSM短时状态 + 持久痕迹DAG），在多项基准上大幅超越现有 RAG 方法，是"记忆粒度对齐检索粒度"这一方向的代表性工作。
