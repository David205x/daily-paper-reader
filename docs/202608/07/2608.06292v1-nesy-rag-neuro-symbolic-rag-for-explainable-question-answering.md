## 摘要
检索增强生成（RAG）通过将大型语言模型（LLM）置于外部知识（如文本语料库）中，改善了问答效果。然而，其推理过程在很大程度上仍然是不透明的：中间推理步骤难以验证，也无法可靠地归属到具体证据。此外，缺失的用户特定上下文很少被系统性地检测到，常常导致不完整或错误的输出。我们提出了NeSy-RAG，一个模块化的神经符号RAG框架，它从检索到的文本块中综合可归属的Prolog模块。对于每个文本块，系统生成语义上有意义的谓词，这些谓词编码布尔声明，可能依赖于用户事实。利用联合自然语言-代码嵌入，谓词被检索并组合成Prolog查询。为了解决不完整的用户上下文，我们引入了一种符号知识差距检测机制，该机制识别缺失的用户事实，这些事实的真值影响查询结果，并自动触发后续交互。执行生成的Prolog查询产生确定性答案以及透明的执行轨迹，将每个推理步骤与其来源关联起来。在ShARC基准上，无需特定领域的训练，NeSy-RAG达到了61.1%的准确率，优于同一模型RAG基线的42.8%准确率。

## Abstract
Retrieval-augmented generation (RAG) improves question answering by grounding large language models (LLMs) in external knowledge such as text corpora. However, its reasoning process remains largely opaque: intermediate reasoning steps are difficult to verify and cannot be reliably attributed to specific evidence. Moreover, missing user-specific context is rarely detected systematically, often leading to incomplete or incorrect output.   We propose NeSy-RAG, a modular neuro-symbolic RAG framework that synthesizes attributable Prolog modules from retrieved text chunks. For each chunk, the system generates semantically meaningful predicates that encode Boolean claims, which may depend on user facts. Using joint natural language-code embeddings, predicates are retrieved and composed into Prolog queries. To address incomplete user context, we introduce a symbolic knowledge-gap detection mechanism that identifies missing user facts whose truth values affect the query outcome and automatically triggers follow-up interactions.   Executing the resulting Prolog queries yields deterministic answers together with transparent execution traces that link each reasoning step to its originating source. On the ShARC benchmark, without domain-specific training, NeSy-RAG achieves 61.1% accuracy, outperforming a same-model RAG baseline that achieves 42.8% accuracy.

## 2. 论文提出的方法论：核心思想、关键技术细节与技术流程

### 核心思想
NeSy-RAG 将检索到的每个文本块（chunk）模块化地合成为可归属的 Prolog 知识模块，通过 0-arity 谓词抽象将查询构建转化为受限的谓词选择与组合问题，并在 Prolog 执行过程中以符号化方式检测缺失的用户事实，自动触发追问。

### 关键技术细节

**（1）可归属的 Prolog 合成（Attributable Prolog Synthesis）**
- 对每个检索到的文本块 cₘ，由 LLM 独立合成一个 Prolog 模块 pₘ = (Rₘ, Fₘ)，包含规则和事实。
- 模块化带来两个优势：
  - **唯一归属**：每条规则/事实可唯一映射回其源文本块，执行轨迹可提供细粒度的可解释性和可验证性。
  - **可扩展聚合**：模块随文本块一起检索，按需聚合相关符号知识，避免构建庞大单一知识库。

**（2）知识间隙检测机制（Knowledge-Gap Detection）**
- 将 Prolog 事实划分为两类：
  - **普遍事实（universal facts）**：所有参数在合成时已由领域知识完全确定。
  - **动态事实（dynamic facts）**：至少有一个参数（聚焦于布尔参数）无法在合成时确定，需要推理时从用户获取或验证。
- 为每个动态事实生成交互方法（interaction method）：查询时若值未知则询问用户；若规则条件中已有值则请用户确认/否定。
- 每个事实形式化为 fᵢ = (hᵢ, Aᵢ)，参数 aⱼ = (n, t, v) 记录名称、数据类型和值；存在无法从领域知识推断取值的参数即视为动态事实。

**（3）0-arity 谓词抽象**
- 在模块合成时，LLM 额外将非 0-arity 规则封装为 0-arity 规则，作为模块功能的布尔声明接口（例如：`could_claim_married_couples_allowance :- eligible_for_married_couples_allowance.`）。
- 这使得查询生成时无需加载完整知识库、检查变量绑定，显著降低 LLM 的认知负担和幻觉风险。

**（4）分层检索与查询构建**
- 第一层：基于向量嵌入检索相关文本块（附带的 Prolog 模块作为元数据）。
- 第二层：从相关模块中提取 0-arity 规则，使用联合 NL-PL 嵌入模型（jina-code-embeddings-1.5b）按与用户问题的余弦相似度排序，取 top-k 规则。
- LLM 仅基于这组受限的 0-arity 谓词组合生成 Prolog 查询，约束生成空间，提高可扩展性和查询精度。

**（5）答案生成与执行**
- 查询在 swipl 上执行，动态谓词通过 PySwip 调用 Python 外部函数向用户追问。
- Prolog 响应结合执行轨迹（每条规则/事实可追溯至源文本块和文档）由 LLM 加工为自然语言答案。
- 若模拟用户无法回答追问，则评估该未决谓词在两种布尔赋值下对查询结果的影响：结果不一致则输出 `more`，一致则输出相应确定答案。

- **准确率显著领先**：NeSy-RAG（k=10）在 ShARC 测试集上达到 **61.1%** 准确率，显著优于同模型 LLM RAG 基线（**42.8%**，gpt-oss:20b），提升 18.3 个百分点；也优于更大模型 gpt-5-mini 的 RAG 基线（53.7%）。

- **推理效率更高**：NeSy-RAG 平均执行时间（7.4s）低于 LLM RAG 基线（11.4s），得益于模块复用、小上下文窗口、算法化追问触发。
- **错误模式分析**：
  - NeSy-RAG 主要错误为将 `yes` 误判为 `more`（31%），源于动态谓词过生成；该保守偏差在高风险场景中优于虚假确定性。

- **可解释性**：执行轨迹将每个推理步骤链接至唯一源文本块，提供了纯 LLM 管线无法提供的粒度化验证能力。

## 7. 优点与亮点

- **模块化可归属设计**：每个事实和规则可唯一追溯到源文本块，实现细粒度的可解释性和可验证性，克服了标准 RAG 归属不保证的问题。
- **0-arity 谓词抽象创新**：将非零元谓词封装为自包含的布尔声明，将查询构建从知识库检查问题转化为受限谓词选择问题，有效解决知识库增大时查询生成的瓶颈。
- **符号化知识间隙检测**：将缺失信息识别从隐式、概率性的 LLM 行为转变为显式、确定性的符号推理，算法性地触发追问，是该领域的重要补充。
- **两阶段分层检索**：先检索相关块，再在模块内检索相关谓词，使查询生成仅暴露于小型相关问题子集，兼顾大规模领域知识和符号推理的扩展性。
- **无需领域训练**：领域无关设计，在新领域可直接部署，无需标注数据训练。
- **效率优势明确**：模块复用 + 小上下文窗口 → 更低延迟和 token 消耗。
- **实验实现考虑周全**：预测 `more` 时进行双向赋值评估，保证了结论稳健性；动态谓词缓存避免重复提问。

## 8. 不足与局限

- **动态谓词过生成**：主要误差来源——合成阶段生成过多不必要的动态谓词，触发多余追问，导致 31% 的 `yes` 实例被保守地判为 `more`。这是缩小与上界差距的最关键改进方向。
- **实验覆盖有限**：仅在单一数据集（ShARC）上验证；未覆盖多跳推理、不同领域（医疗/法律）、真实检索器或多语言场景，泛化性结论尚不充分。
- **演示原型未完整实现检索器**：用“目标片段+随机干扰”近似检索结果，未评测检索质量对端到端性能的真实影响。
- **未做系统性消融**：无法量化各组件（0-arity 抽象、知识间隙检测机制、NL-PL 嵌入检索等）的独立贡献。
- **对底层 LLM 的依赖**：Prolog 合成质量受 LLM 能力限制，存在 2.2% 的语法错误率（无效 Prolog 模块/查询）；更大模型的增益未被探索。
- **只能处理布尔问答**：知识间隙检测目前限于单布尔参数的动态事实，对更丰富的数据类型和参数结构尚未扩展，限制了应用范围。
- **确定性符号推理的固有约束**：ProLog 的封闭世界假设和规则精确匹配可能不适用于需要常识推理或模糊语义理解的开放域问题。
