## 摘要
多领域机器翻译（MDMT）不仅需要流畅的生成，还要求领域敏感的翻译决策，如领域消歧、术语控制和风格适应。大型推理模型（LRMs）通过中间翻译步骤使此类决策显式化，但我们在15个领域和四个翻译方向上的分析表明，这种显式推理是一把双刃剑：它能改善长篇和高难度翻译，但在术语密集和风格受限的场景中常常发生漂移。我们将这一失败归因于信用分配瓶颈：现有方法优化最终输出或粗略轨迹，但无法识别哪些翻译步骤真正有助于最终翻译。为解决此问题，我们提出PAMT，一种过程对齐的训练框架，将冷启动的领域感知Long-CoT监督与强化学习相结合。PAMT使用序列级格式和结果奖励来评估最终翻译，并采用步骤级过程奖励来衡量每个显式翻译步骤增加参考翻译可能性的程度。在两种骨干模型上，PAMT相较基础模型均有提升，在平均性能上优于机器翻译专用基线，并在域内、域外和多语言设置中与强LLM/LRM保持竞争力。

## Abstract
Multi-domain machine translation (MDMT) requires more than fluent generation: it demands domain-sensitive translation decisions such as domain disambiguation, terminology control, and stylistic adaptation. Large reasoning models (LRMs) make such decisions explicit through intermediate translation steps, but our analysis across 15 domains and four translation directions shows that this explicit reasoning is double-edged: it improves long-form and high-difficulty translation, yet often drifts in terminology-intensive and stylistically constrained settings. We trace this failure to a credit-assignment bottleneck: existing methods optimize final outputs or coarse trajectories, but cannot identify which translation steps actually help the final translation. To address this, we propose PAMT, a process-aligned training framework that combines cold-start domain-aware Long-CoT supervision with reinforcement learning. PAMT uses sequence-level format and outcome rewards for the final translation, together with a step-level process reward that measures how much each explicit translation step increases the likelihood of the reference translation. Across two backbones, PAMT improves over base models, outperforms MT-specialized baselines on average, and remains competitive with strong LLMs/LRMs across in-domain, OOD, and multilingual settings.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：多领域机器翻译（MDMT）不能只追求生成流畅性，还必须做出领域敏感决策，包括**领域消歧、术语控制、风格适应**等。
- **观测到的矛盾**：大型推理模型（LRMs）通过显式的中间翻译步骤（如 Long-CoT）来曝光决策过程，但作者在 **15 个领域、4 个翻译方向（En↔Zh 与 En↔De）** 上的系统分析显示，这种显式推理呈现"双刃剑"效应：
  - **有帮助**：在长上下文、高难度输入的翻译中，显式推理能显著改善效果（文档级 BlonDe 得分更高，高难度级别下 COMET/Kiwi 全面超越传统 LLM）。
  - **有损害**：在术语密集和风格受限的场景中，看似合理的推理步骤会偏离领域约定，导致术语错误与风格漂移。
- **根因诊断——信用分配瓶颈**：现有方法（序列级最终输出奖励、粗粒度轨迹奖励）无法定位**是哪一步翻译决策出了问题**。监督粒度与决策粒度不匹配，使得中间步骤难以被正确归因与优化，进而引发术语与风格漂移。作者用一个法律翻译案例（"送达→service/delivery"）直观展示了该瓶颈。

### 2. 方法论：PAMT 框架

PAMT 是一个**两阶段过程对齐训练框架**，核心思想是"让翻译过程和最终结果一起被优化"。

#### 2.1 冷启动 SFT（Cold Start）

- 使用从 DeepSeek-R1 蒸馏的 **约 7K 条领域感知 Long-CoT 翻译数据**，覆盖 10 个领域、3 个翻译方向（De→En、En→Zh、Zh→En）。
- 每条数据采用 `<think>...</think><answer>...</answer>` 结构化格式，先显式生成翻译过程，再输出最终译文。
- 目的：激活基础模型的推理能力，使其具备产出显式翻译过程的能力。

#### 2.2 RL 阶段

**任务设定**：对每个源句采样 G 条 rollouts，每条 rollout 包含推理过程 $z_{i,g}$ 与最终译文 $y_{i,g}$。

**三类奖励设计**：

1. **格式奖励 $r^{fmt}$**：输出是否符合 `<think>/<answer>` 结构（+1 或 −1）。
2. **结果奖励 $r^{out}$**：BLEU、COMET、COMETKiwi 三个指标的等权平均，衡量最终译文质量。
3. **步骤级过程奖励 $r^{proc}$**（核心创新）：
   - 用冻结的参考模型 $\pi_{ref}$ 计算"过程势能" $\phi_{i,g,k}$，即在包含前 $k$ 个推理步骤的上下文条件下，参考译文的 teacher-forced log-likelihood；
   - 第 $k$ 步的**过程增益**为 $\phi_{i,g,k} - \phi_{i,g,k-1}$，正增益表示该步使参考译文更可预测，负增益表示该步有害；
   - 将每步增益**均匀分配到该步所有 token**上，避免长步骤因 token 多而获得不公平偏置。

**信用分配（Credit Assignment）**：

- 最终 token 接收格式奖励和结果奖励；
- 推理 token 接收分布式过程奖励；
- 通过 return-to-go 机制，终端的序列级奖励传播到所有前置 token，而过程奖励提供密集的步骤级信用信号。
- 关键效果：**同一个 rollout 内不同 token 的 advantage 不再是常数**，而是依赖"该 token 之后的推理后缀是否有助于参考译文"。

**优化目标**：GRPO 风格的裁剪替代目标，配合 KL 正则化。值得注意的是，同一个 $\pi_{ref}$ 同时用于过程评分和 KL 正则，无需额外训练评分模型。

### 6. 主要结论与发现

1. **显式推理的适用边界明确**：LRMs 的显式翻译推理在长上下文（文档级 BlonDe 更高）和高难度输入（Level 2+ 全面占优）中有效，但在术语密集和风格受限场景中会漂移，术语准确率不稳定。
2. **信用分配瓶颈是核心障碍**：仅优化最终输出或整条轨迹，无法识别具体哪一步翻译决策导致了失败，这正是推导出 PAMT 的关键动机。
3. **PAMT 整体有效**：
   - 在域内和 OOD 设置中，PAMT 两个骨干模型（Qwen2.5-7B-Instruct 与 Gemma2-9B-IT）均较基础模型显著提升，平均表现优于所有 MT 专用基线；
   - 与强 LLM/LRM 相比具有竞争力，部分指标超过 GPT-5、DeepSeek-R1 等大型模型（尤其在低资源骨干上）；
   - 在多语言设置中（尤其 X→En 方向）展现出跨语言迁移能力。
4. **过程奖励确实在塑造翻译决策**：训练过程中，术语选择、风格校准、消歧三类步骤在正增益步骤中的占比持续上升，在负增益步骤中下降——证明 PAMT 优化的是领域敏感决策本身，而不仅仅是输出指标。
5. **未拟合冻结参考模型**：结果奖励规模（约 1.7）远大于过程奖励（约 -0.16），KL 稳步上升，说明优化主要由最终翻译质量驱动，过程奖励起辅助塑造作用。

### 7. 优点

- **问题诊断扎实**：先用大规模预分析（15 领域、4 方向）系统刻画了显式推理的"双刃剑"效应，再对症下药，研究逻辑严谨。
- **过程奖励设计精巧**：用冻结参考模型的边际 log-likelihood 变化作为步骤贡献度量，无需额外训练过程奖励模型，无需人工步骤标注，直接复用平行语料中的参考译文，工程上优雅高效。
- **细粒度信用分配**：将过程奖励分配到具体 token，使同一 trajectory 内不同位置的 advantage 不同，从本质上缓解了"一步错、全程罚"的粗粒度问题。
- **与 GRPO 无缝集成**：从标准 GRPO 到 PAMT 的推导清晰（附录 H），Vanilla GRPO 可视为 λ=0 的特例，理论自洽。
- **验证全面性**：域内、域外、多语言、消融、术语风格、训练动态、决策类型、人类评估等多角度验证，在两个不同骨干（Qwen2.5-7B 与 Gemma2-9B）上均验证，结论置信度较高。
- **案例研究具有说服力**：附录 G 展示了同一源句在正/反两种轨迹下，过程奖励精确捕捉到"术语拒绝"（模型在推理中想到正确术语却自我否定）的时刻，直观说明方法价值。

### 8. 不足与局限

- **适用范围受限**：PAMT 只适用于可显式化的翻译过程（即 `<think>` 中表达出来的步骤），不建模未在输出轨迹中暴露的隐性内部推理。
- **依赖平行数据**：过程奖励基于参考译文计算，训练时需要平行语料，在无参考的低资源场景下无法直接使用。
- **步骤分割粗糙**：当前以双换行符分割步骤、并在步内均匀分配奖励，是一种粗粒度的近似；真实步骤贡献可能并非均匀分布。
- **训练成本增加**：每个采样轨迹需对多个步骤前缀调用冻结参考模型做前向计算，训练时间成本上升（推理不受影响）。
- **人类评估规模小**：仅 60 个样本，且偏好评估中"平局"占比很高（51.7%–58.3%），统计区分度有限。
- **极端低资源场景提升有限**：未见语言 En→X 方向 BLEU 极低（5.90–8.63），说明跨语言泛化仍存在明显瓶颈。
- **潜在偏差风险**：自动 MQM 使用 DeepSeek-V3 打分，尽管与 WMT24 人类标注有一致性验证，但对 PAMT（训练时可能见过类似数据分布）的评估可能存在系统性偏差；消融和对比实验未报告显著性检验。
- **理论机制尚待深挖**：论文展示了过程奖励与决策类型之间的相关性，但对"为什么步骤级信用分配能有效抑制漂移"的因果解释仍较为表层。
