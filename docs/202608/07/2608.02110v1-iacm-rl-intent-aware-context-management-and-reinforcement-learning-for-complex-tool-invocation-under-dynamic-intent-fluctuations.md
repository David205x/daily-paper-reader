## 摘要
在真实环境中执行长时程工具调用受到动态用户意图噪声的严重挑战。现有方法试图通过隐式历史扫描或文本压缩来实现鲁棒性，但主要假设在简单场景下指令完美无缺。不可避免地，在波动情境下，过时约束会稀释模型注意力，引发灾难性意图偏离和无限API循环。为解决此问题，我们提出IACM-RL，一个用于鲁棒工具调用的综合框架。首先，我们引入DynamicIntent流程，在13种细粒度波动场景中合成轨迹，并配以五维诊断指标套件。其次，IACM-RL部署基于BeliefState的自生成上下文管理器，主动跟踪变化的目标并使用结构过时标记隔离被覆盖的参数。为自主内化这种状态跟踪能力，我们使用分层意图驱动奖励以及三个辅助损失（动作校准、CM提取和状态蒸馏）来优化策略。在DynamicIntent、BFCL-V3和τ²-Bench上的实验表明，IACM-RL显著优于基线，减少无限循环和过时上下文错误，同时增强跨域泛化能力。

## Abstract
Executing long-horizon tool invocations in real-world environments is severely challenged by dynamic user intent noise. Existing methods attempt robustness via implicit history scanning or text compression, yet predominantly assume perfect instructions in simplistic scenarios. Inevitably, under fluctuating contexts, obsolete constraints dilute model attention, triggering catastrophic intent deviation and infinite API loops. To resolve this, we propose IACM-RL, a comprehensive framework for robust tool invocation. First, we introduce the DynamicIntent pipeline, synthesizing trajectories across 13 fine-grained fluctuation scenarios, paired with a five-dimensional diagnostic metric suite. Second, IACM-RL deploys a BeliefState-based Self-Generated Context Manager that proactively tracks shifting goals and isolates overwritten parameters using structural stale flags. To autonomously internalize this state-tracking capability, we optimize the policy using a hierarchical intent-driven reward alongside three auxiliary losses (action calibration, CM extraction, and state distillation). Experiments on DynamicIntent, BFCL-V3, and $\mathrmτ^2$-Bench demonstrate that IACM-RL significantly outperforms baselines, reducing infinite loops and stale context errors while enhancing out-of-domain generalization.

## 2. 方法论

### 2.1 核心思想
将多轮工具调用建模为 **POMDP**（部分可观测马尔可夫决策过程），并明确提出：状态跟踪应与动作生成解耦。为此引入 **自生成 Context Manager（CM）**，由策略自主生成紧凑状态块，替代原始冗长历史作为动作生成的条件。

### 2.2 DynamicIntent 数据管道
五阶段合成流程：
1. **工具抽象与收集**：通过 UTAL 统一异构 API schema，形成跨源工具池（每轨迹采样候选子集，防止模型记忆工具名）。
2. **依赖图构建**：多 LLM 双轮投票构建工具依赖有向图 **G**，约束感知随机游走采样 Function Sequence Pattern（FSP）作为工作流骨干。
3. **轨迹增强**：围绕 5 大意图波动模式（Modification/Interruption/Clarification/Accumulation/Chaining）实现 13 种细粒度场景。图级方法编辑 FSP 结构，轨迹级方法改写对话；插图谱约束拼接（Algorithm 2）确保插入片段是真正正交的新任务。
4. **数据过滤**：一致性（schema 合规）、合理性（闭环解析）、复杂度（长度预算）三维筛选。
5. **LLM 驱动模拟执行**：无真实后端，由 LLM 模拟工具返回，生成完整多轮对话，并记录 golden map 供奖励与评估使用。

### 2.3 BeliefState 自生成 Context Manager
- BeliefState 包含五个核心组件（实例化为 9 个 XML 子块）：
  \[
  b_t = \langle C_{slots}, G_{current}, A_{last}, Q_{pending}, I_{signal} \rangle
  \]
- **关键机制**：当参数被覆盖时，旧值不删除，而是标记为**结构化过时标记（stale flag）**，显式禁止策略回归旧值。
- **更新时机**：单步训练中每次生成前初始化、生成后记录；多步训练中每个交互边界（用户消息/工具执行）触发更新，并将更新后的 CM 注入系统提示词。

### 2.4 分层意图驱动奖励
\[
R_{total} = \alpha R_{belief} + \beta R_{action} + \gamma R_{outcome} + R_{format}
\]
（\(\alpha=1.0\), \(\beta=1.0\), \(\gamma=0.5\)）

| 层级 | 核心信号 | 监督的 BeliefState 字段 |
|---|---|---|
| 认知层 \(R_{belief}\) | JGA 命中率、SCRR 过时/幻觉惩罚 | \(C_{slots}\) |
| 行为层 \(R_{action}\) | 循环/无效/冗余调用惩罚、轨迹进度、ACR 澄清奖励 | \(A_{last}\), \(Q_{pending}\) |
| 结果层 \(R_{outcome}\) | DTCR 链完成率、ISSR 意图切换 | \(G_{current}\), \(I_{signal}\) |

### 2.5 强化学习优化与三辅助损失
总体损失：
\[
L_{total} = L_{PG} + w_{cal} L_{cal} + w_{ext} L_{ext} + w_{dist} L_{dist}
\]
（\(w_{cal}=0.02\), \(w_{ext}=0.01\), \(w_{dist}=0.01\)）

1. **动作校准损失** \(L_{cal}\)：以工具调用正确性为权重调整响应似然，实现粗细粒度信号连接。
2. **CM 提取损失** \(L_{ext}\)：直接用轨迹优势优化 CM 块 token，使 CM 质量与奖励闭环。
3. **状态蒸馏损失** \(L_{dist}\)：将 CM 条件下的教师策略蒸馏到无 CM 的学生策略，使状态跟踪能力内化到模型权重中。

三者形成递进关系：\(L_{cal}\) 量化动作质量，\(L_{ext}\) 改进 CM，\(L_{dist}\) 将 CM 的知识固化进权重。

### 2.6 两阶段训练
- **前工具调用**：在 17,391 条单步切片上训练，建立工具选择能力（使用 \(R_{single}\)）。
- **第二阶段**：在 5,639 条多轮轨迹上训练，加入分层奖励与三辅助损失（使用 \(R_{total}\)）。

## 6. 主要结论与发现

1. **整体性能领先**：IACM-RL 在三大基准上取得最高平均分（64.0），显著优于所有基线；
2. **交叉域泛化能力强**：OOD Cognitive（36.3）接近 ID（36.5），说明模型学到了可迁移的状态追踪能力，而非表面工具特征记忆；
3. **长时程优势突出**：对话越长，CM 收益越大。>16k tokens 时 PPO-noCM 得分为 0，IACM-RL 达到 34.8（\(\tau^2\)-Bench）；
4. **对干扰的鲁棒性**：L3 级对抗干扰下，IACM-RL 比 PPO-noCM 高 11.2 个百分点；
5. **三辅助损失缺一不可**：移除 \(L_{ext}\) 导致 OOD Cognitive 下降 3.6；移除 \(L_{dist}\) 下降 4.9；
6. **\(R_{belief}\) 是最关键奖励层**：移除后 BFCL 从 63.3 暴跌至 47.5；
7. **Accumulate 是最优 CM 更新策略**：保留跨轮工具结果对长链与并行场景至关重要；
8. **LLM 模拟是可靠代理**：与真实 MCP 执行几乎等价，验证了无后端合成的可行性。

## 7. 优点

### 方法论亮点
- **状态跟踪与动作生成的显式解耦**：首次将“意图状态追踪”从动作生成中结构化分离，改变了传统端到端隐式学习的范式；
- **结构化过时标记**：不用删除而是“标记过时”，防止模型回归旧值，概念简洁、实现优雅；
- **自生成、免标注 CM**：CM 由模型自己生成，使用轨迹优势信号优化，无需人工标注状态；
- **三辅助损失的递进设计**：从动作校准到 CM 提取再到状态蒸馏，实现从显式模块到隐式权重的知识迁移；
- **分层奖励设计**：认知/行为/结果三层与 BeliefState 字段一一对应，实现字段级信用分配；
- **无真实后端的可扩展数据管道**：LLM 模拟工具执行经实验验证与真实执行等价，大幅降低数据构建成本。

### 实验设计亮点
- 13 种细粒度意图波动场景，覆盖全面；
- ID/OOD 按工具源切分，OOD 用未见到工具池，严格测试泛化；
- 对抗干扰实验（chit-chat + fake tasks 注入）直接检验实际场景中的鲁棒性；
- 多维度消融（损失、奖励、更新策略、模型规模、权重敏感性）使结论充分可信。

## 8. 不足与局限

### 实验覆盖局限
- **骨干模型单一**：仅用 Qwen3-8B 和 1.7B；小模型上的收益不均衡，说明方法有效性受模型底层推理能力约束；
- **任务类型有限**：仅包含文本 API 调用，无多模态工具、无代码/软件工程 agent 场景；
- **未与商用闭源模型直接对比**：未做 GPT-4/Claude 等强模型 backbone 的实验；
- **模拟环境偏差风险**：虽然 LLM 模拟与真实 MCP 在核心指标上接近，但真实世界 API 延迟、异常返回、网络错误等未充分模拟。

### 方法局限
- **计算成本**：两阶段训练 + LLM judge（ACR/ISSR 各至多 2 次调用/样本）+ 动态模拟回退，推理时需逐轮生成 CM，成本与延迟较高；
- **OOD 缺陷**：OOD Accumulation 和 Chaining 场景中 IACM-RL 与基线持平或略降（Table 7），说明长链/并行场景下的跨域鲁棒性仍有提升空间；
- **CM 收益依赖长度**：短对话中 CM 增益微弱，额外的显式模块在简单场景中可能并非必要；
- **“信念状态”的完全准确性未保证**：自生成 CM 可能包含幻觉信息，论文未深入分析 CM 生成错误的级联效应。

### 客观性相关
- 数据管线、CM 模板、奖励函数、LLM judge 提示词均由作者团队设计，存在一定的**同源性偏差**风险（如 CM 目标格式与训练数据的一致性可能有利于方法本身）；
- LLM-as-a-judge（GPT-5.4）的评分稳定性取决于提示词设计，论文未报告 judge 与人工标注的一致性系数。
