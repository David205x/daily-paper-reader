## 摘要
大型语言模型（LLM）越来越多地通过指定角色、风格、格式和安全要求的系统提示进行控制。然而，模型只能通过上下文学习隐式地遵循这些提示，这对于复杂或组合性的提示可能不够。现有方法通常需要模型微调或响应级别的重排序，限制了它们在轻量级推理时控制中的实用性。我们提出了SyRuP，一种解码时框架，用于在保持基础LM冻结的同时改进系统提示的遵循。SyRuP从系统提示条件偏好对中训练一个交叉注意力奖励头，将系统提示视为独立的记忆以生成token级别的遵循分数。在推理时，SyRuP通过将基础logits与学习到的奖励信号以及捕获系统诱导logit偏移的可选对比信号相结合，对基础LM的top-k候选进行重排序。在系统提示遵循基准上的实验表明，SyRuP在适度的推理开销下始终优于提示和解码时基线。这些结果表明，显式的token级别指导是实现可靠系统提示遵循的有效且实用的机制。

## Abstract
Large Language Models (LLMs) are increasingly controlled through system prompts that specify roles, styles, formats, and safety requirements. However, models follow these prompts only implicitly through in-context learning, which can be insufficient for complex or compositional prompts. Existing approaches often require model tuning or response-level reranking, limiting their practicality for lightweight inference-time control. We introduce SyRuP, a decoding-time framework for improving system-prompt adherence while keeping the base LM frozen. SyRuP trains a cross-attention reward head from system-prompt-conditioned preference pairs, treating the system prompt as a separate memory to produce token-level adherence scores. At inference, SyRuP reranks the base LM's top-k candidates by combining base logits with the learned reward signal and an optional contrastive signal capturing system-induced logit shifts. Experiments on system-prompt following benchmarks show that SyRuP consistently outperforms prompting and decoding-time baselines with moderate inference overhead. These results suggest that explicit token-level guidance is an effective and practical mechanism for reliable system-prompt following.

## 2. 方法论

### 核心思想
- 将系统提示视为独立的记忆源，训练一个轻量级交叉注意力奖励头，在解码时对每个候选token产生遵循分数，并与基座LM的logits及对比信号结合，对top-k候选进行重排序。

### 关键技术细节
- **交叉注意力奖励头**：
  - 使用基座LM（冻结）提取系统提示的隐藏状态 $H(s)$ 作为键-值记忆。
  - 查询来自用户输入和已生成前缀的拼接隐藏状态 $H_{\text{ctx},t}$。
  - 通过交叉注意力计算输出，再经两层MLP融合，取最后位置得到解码状态向量 $z_t$。
  - token级遵循分数：$r_t(v) = z_t^\top e_v$，其中 $e_v$ 是token嵌入。
- **训练**：
  - 使用系统提示条件偏好对 $(s, x, y^+, y^-)$，采用Bradley-Terry目标优化序列级奖励（token级奖励的平均）：
    \[
    \mathcal{L}_{\text{RM}} = -\log \sigma\left(\beta(R^+ - R^-)\right)
    \]
  - 仅更新奖励头参数（交叉注意力投影和MLP）。
- **解码引导**：
  - 对每个解码步，从基座LM的top-k候选集合 $\mathcal{C}_t$ 中选择：
    \[
    y_t = \arg\max_{v \in \mathcal{C}_t} \left[\ell_t(v) + \lambda_r r_t(v) + \lambda_c \Delta_t(v)\right]
    \]
  - $\ell_t(v)$ 为基座logits，$\Delta_t(v)$ 为对比信号（系统提示logits减去中性提示logits），$\lambda_r, \lambda_c$ 为权重。纯奖励引导时 $\lambda_c=0$。
- **算法流程**：
  - 训练阶段（Algorithm 1）：
    1. 冻结基座LM，为每个系统提示预计算 $H(s)$ 并缓存。
    2. 对每个偏好对中的 $y^+, y^-$，逐token计算 $z_t$ 和 $r_t$，聚合为序列奖励。
    3. 优化Bradley-Terry损失。
  - 解码阶段（Algorithm 2）：
    1. 计算并缓存 $H(s)$。
    2. 每步计算基座logits $\ell_t$，生成top-k候选。
    3. 通过奖励头得到 $z_t$，计算每个候选的 $r_t(v)$ 和 $\Delta_t(v)$（若使用）。
    4. 按加权和选择最优token。
