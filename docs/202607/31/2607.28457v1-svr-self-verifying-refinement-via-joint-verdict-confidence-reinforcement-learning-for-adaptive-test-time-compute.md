## 摘要
扩展测试时计算可以改善语言模型的推理能力，但统一的计算预算会浪费在简单输入上，而验证器引导的细化依赖于外部反馈。我们提出了自我验证细化（SVR），一种无外部验证器的多轮强化学习框架，学习将自我验证用作计算控制策略。在每一轮中，模型生成一个解决方案，并附带一个离散的正确性判定和一个置信度分数；仅当判定为“正确”且置信度超过阈值时，模型保留当前答案，否则利用其自身的自我验证继续细化。真实正确性仅用于构建训练奖励，从不通过细化提示暴露给策略，也不在推理时要求提供。SVR使用GRPO在固定步数轨迹上进行训练，奖励促进解决方案正确性、校准感知的自我验证以及准备停止的正确状态；自适应停止仅在推理时激活。在七个数学推理基准上，使用Qwen3.5-2B，SVR实现了0.563的宏平均准确率，平均仅需2.99次推理轮次。在评估的完整系统比较中，它超过了标准GRPO、强多轮基线和固定预算的启发式评分反馈参考，同时所需的轮次远少于固定的十轮推理。这些结果表明，学习到的自我验证可以作为答案保留和自适应测试时计算分配的有效内部控制信号。

## Abstract
Scaling test-time computation can improve language-model reasoning, but uniform budgets waste computation on easy inputs, while verifier-guided refinement relies on external feedback. We introduce Self-Verifying Refinement (SVR), an oracle-free multi-turn reinforcement learning framework that learns to use self-verification as a compute-control policy. At each turn, the model produces a solution together with a discrete correctness verdict and a confidence score; it retains the current answer only when the verdict is Correct and confidence exceeds a threshold, and otherwise continues refinement using its own self-verification. Ground-truth correctness is used only to construct training rewards and is never exposed to the policy through refinement prompts or required at inference. SVR is trained with GRPO on fixed-horizon trajectories using rewards that promote solution correctness, calibration-aware self-verification, and stop-ready correct states; adaptive stopping is activated only at inference. On seven mathematical reasoning benchmarks with Qwen3.5-2B, SVR achieves a macro-average accuracy of 0.563 with only 2.99 inference turns on average. In the evaluated complete-system comparison, it exceeds standard GRPO, strong multi-turn baselines, and a fixed-budget oracle-guided score-feedback reference while requiring substantially fewer turns than fixed ten-turn inference. These results demonstrate that learned self-verification can serve as an effective internal control signal for answer retention and adaptive test-time compute allocation.

## 1. 核心问题与研究动机

- 论文聚焦于**测试时计算（Test-Time Compute）的分配策略**问题。扩展推理计算可以提升语言模型推理能力，但存在两大痛点：
  - **均匀预算浪费**：给所有输入分配相同的推理轮次/采样数（如固定10轮），简单问题被过度计算，而难问题可能仍不够。
  - **外部反馈依赖**：验证器引导的方法依赖外部奖励模型、执行结果或正确性反馈，在部署时成本高或不可用。
- 此外，**多轮细化存在双刃剑效应**：后续轮次可能修复错误答案，也可能覆盖原本正确的答案（destructive revision）。
- 核心研究问题：**模型能否仅依靠自身生成的信号来决定“保留当前答案”还是“继续细化”，而无需推理时的外部正确性反馈？** 论文提出以模型自身的“自我验证”（self-verification）作为内部控制信号，实现自适应的测试时计算分配。
- 由于校准误差即分配误差——低估会让正确答案被不必要地修改，高估会让错误答案提前终止——因此置信度校准在方法论中的位置至关重要。

## 2. 方法论：SVR 框架

### 2.1 核心思想

- 提出 **Self-Verifying Refinement (SVR)**，一个无外部验证器的多轮强化学习框架。
- 每一轮输出包含四部分：推理轨迹 `r_t`、任务答案 `a_t`、离散判定 `v_t ∈ {Correct, Incorrect, Unsure}`、置信度 `c_t ∈ [0,1]`。
- **停止规则**：仅当判定为 Correct 且置信度 `c_t ≥ γ`（部署阈值，主实验取 0.85）且生成未截断时，返回当前答案；否则继续细化，直到最大预算 `T_max`（主实验取 10 轮）。
- 真实正确性标签仅用于构建训练奖励，**不**出现在细化提示中，推理时也不可访问——满足“oracle-free”的信息边界。

### 2.2 关键公式与算法流程

- **自适应停止时间**（Eq. 4）：
  ```
  t̂_γ = min({t ∈ {1,...,T_max} : q_t=0, v_t=C, c_t ≥ γ} ∪ {T_max})
  ```
  即首次满足“未截断 + 判定正确 + 置信度达标”的轮次，否则取最大预算轮。

- **训练目标**（Eq. 7）：固定轮数 `T_tr=3` 下，平均每轮三组分奖励：
  ```
  R^SVR(τ) = (1/T_tr) Σ_t [ r_solve,t + r_verify,t + λ_fmt·r_fmt,t ]
  ```
  - `r_solve,t`：当前答案正确性 + 跨轮进步（wrong→correct 奖励，correct→wrong 惩罚）+ 长度形状惩罚 + 截断惩罚。
  - `r_verify,t`：四个组件的组合——
    - Brier 校准（confidence 与 correctness 的均方误差）；
    - 过度自信惩罚（Correct 判定但回答错误时，按置信度加权）；
    - 错误识别奖励（Incorrect 判定且回答确实错误）；
    - 停止就绪奖励（正确答案且判定 Correct 时，置信度越高奖励越高）。
  - `r_fmt,t`：任务答案格式 + 自我检查块格式。

- **优化方式**：基于 GRPO 的组相对优势（Eq. 10），每轨迹归一化后的轨迹级回报，只在最后一个轮次（第 3 轮）的 token 上应用策略梯度损失；前两轮提供细化上下文并贡献轨迹奖赏，但不作为独立优化样本。

- **训练/推理分离**：
  - 训练：固定轮数 `T_tr=3`，强制延续（uncensored），自适应停止关闭；
  - 推理：自适应停止激活，模型变为调度器，依据自身判断决定何时保留答案。
  - 这种分离使同一策略可通过调整 γ 支持不同的精度–计算权衡，无需重新训练。

## 6. 主要结论与发现

- **SVR 在 All-7 达到 0.563 宏平均准确率，平均仅 2.99 轮、8.56k tokens/样本**，远超固定预算基线（10 轮）的准确率和 token 效率。
- 相对最强非 oracle 多轮基线 Murphy 提升 7.5 个百分点（All-7）；相对 oracle-guided 参考提升 4.4 个百分点。
- **自适应停止优于任何固定预算**：固定预算最优仅达 0.450（All-7），自适应达 0.563——优势来自实例相关的答案保留，而非单纯生成更多轮次。
- **SVR 匹配 Maj@10 的精度，但只消耗约一半的 token**。
- **消融验证各组件互补性**：移除整个 R_verify 或任一关键组件（校准、过度自信惩罚、停止就绪）均降低聚合精度或计算效率；verdict-only 和 confidence-only 均比联合接口差。
- **PSE 是主要局限**：All-7 上仍达 29.9%（Math-5 为 37.0%），尤其是在 MinervaMath（53.3%）等困难基准上，错误提前停止是显著失败模式。
- 阈值扫描显示性能与阈值呈非单调关系：γ=0.85 是评估网格上的最优全局工作点，过低允许错误自信终止，过高会延迟终止而暴露正确答案于后续回归。

## 7. 优点

- **真正的 oracle-free 推理控制**：细化过程和停止决策均只依赖策略自身生成的 verdict-confidence 信号，无需外部验证器/评估器/环境反馈，部署友好。
- **训练与推理分离的巧妙设计**：固定轮数训练保证中间状态覆盖充分（uncensored supervision），推理时自适应停止控制计算量，γ 为推理时自由调节的权衡旋钮。
- **丰富多层次的奖励设计**：将解答正确性、跨轮进步、校准、过度自信惩罚、错误识别、停止就绪联合建模，使自我验证成为可操作的“控制信号”而非事后描述。
- **诊断指标丰富且客观**：不仅报告准确率和 token 数，还引入 ESR、PSE、Brier、AUROC、Overconfidence 等指标，允许衡量控制器可靠性而非仅看精度。
- **实验设计细致**：固定预算扫描直接暴露答案保留问题（如 GSM8K 任何轮正确率 0.925 但第 10 轮仅 0.736），有力支撑自适应时机和答案保留的必要性。
- **充分的对照与消融**：奖励组件消融、结构消融、阈值扫描、种子稳定性验证，边际清楚。

## 8. 不足与局限

- **实验范围有限**：
  - 仅验证数学推理领域（Countdown、GSM8K、MATH 系），未覆盖代码、生物、法律等多领域；
  - 仅用 Qwen3.5-2B 一个小型模型，缺乏对更大模型（7B/32B+）或不同模型家族的评估。
- **基准规模问题**：AIME26（30 题）和 AMC23（40 题）样本量过小，单题变动的波动就达数个百分点，降低结论可靠性。
- **统计显著性不足**：仅 3 个训练种子，未做正式显著性检验。
- **早期停止错误仍然偏高**：PSE 在数学基准上达 37.0%，这在任务高风险场景中可能不可接受；自我验证信号在困难问题上校准质量仍不理想（如 MinervaMath Brier 高达 0.482）。
- **阈值固定但非最优**：γ=0.85 为全局折中，某些基准单独最优阈值差异明显（如 Countdown 最优在 γ=0.65），统一阈值牺牲了部分基准的性能。
- **正确性依赖直接标签**：训练奖励依赖任务级二元正确性标签，该方案对无法自动验证复杂开放任务（如开放式生成、设计、创意任务）不直接适用。
- **两阶段式开销**：训练需完整多轮 rollout（3 轮/轨迹），且强制延续说明第一、二轮不参与策略梯度更新，训练效率与标准单轮 GRPO 相比更低。
- **未报告训练时长**：缺少训练轮数与 GPU 时长的直接报告，不利于可复现性和工程成本评估。
