## 摘要
基于可验证奖励的强化学习是激发大型语言模型推理能力的一种强大范式，但在竞赛级数学问题上存在严重的奖励稀疏性问题。一种常见的补救措施是将原子知识点（KP）——从标准答案中提炼出的简短自然语言提示——注入提示中。然而，现有方法要么在离线状态下固定选择，要么仅仅放大注入文本的整体数量，而忽略了最具信息量的选择维度：注入哪些原子知识点子集，以及何时注入。我们提出AdaKP，一种在线选择器，在强化学习训练过程中重新选择每个问题的知识点子集。其核心是一个熵代理，通过知识点引起的下一个词元熵减少来为其评分——仅需一次廉价的前向传播，并对其截断偏差有可证明的界限——取代了昂贵的基于 rollout 的估计。三种轻量机制使该信号可在线使用：动量平滑器吸收逐步噪声，退休与复活管理器修剪弱知识点同时保持探索性，以及自适应调度器将重新评估前置到训练早期。AdaKP还贡献了一个预飞行验证门，在启动任何昂贵运行之前，针对留一法地面真实值认证该代理，将方法级风险转化为可证伪的检查。作为标准DAPO+GRPO训练器的完全加法分支实现，无需修改优化器，AdaKP在所有八个竞赛数学基准上以可忽略的额外成本优于强静态选择基线，将经过验证的在线知识点子集选择定位为面向推理强化学习中一个实用且尚未充分探索的维度。

## Abstract
Reinforcement learning with verifiable rewards is a powerful paradigm for eliciting reasoning in large language models, yet it suffers from severe reward sparsity on competition-level mathematics. A common remedy injects atomic knowledge points (KPs) - short natural-language hints distilled from gold solutions - into the prompt. Existing methods, however, either fix this selection once offline or merely scale the monolithic quantity of injected text, leaving untouched the most informative axis of choice: which subset of atomic KPs to inject, and when. We introduce AdaKP, an online selector that re-chooses each problem's KP subset over the course of RL training. At its core is an entropy proxy that scores a KP by the reduction in next-token entropy it induces - a single inexpensive forward pass, with a provable bound on its truncation bias - in place of expensive rollout-based estimation. Three lightweight mechanisms make this signal usable online: a momentum smoother that absorbs per-step noise, a retirement-and-revival manager that prunes weak KPs while preserving exploration, and an adaptive scheduler that front-loads re-evaluations into early training. AdaKP further contributes a pre-flight validation gate that certifies the proxy against a leave-one-out ground truth before any expensive run is launched, turning method-level risk into a falsifiable check. Realized as a fully additive fork of a standard DAPO+GRPO trainer with no optimizer changes, AdaKP improves over a strong static-selection baseline on all eight competition-mathematics benchmarks at negligible added cost, positioning online, validated KP-subset selection as a practical and as-yet under-explored axis for reasoning-oriented reinforcement learning.

## 1. 论文的核心问题与整体含义

- **背景**：基于可验证奖励的强化学习（RLVR）能够在较小的基础模型中激发长链式推理，但在竞赛级数学问题上存在严重的**奖励稀疏**问题——一个未训练的 1.5B 模型在多数 rollout 上答错，导致 GRPO/DAPO 等优化器的优势信号退化。
- **已有解法**：从标准答案中蒸馏出原子知识点（KP，即简短的自然语言提示）注入训练 prompt，代表性工作是 KnowRL 的静态 CSS 选择。但现有方法存在两类缺陷：
  - 离线方法（如 CSS）**一次性固定**每个问题到知识点子集的映射，训练中不再更新，假设 KP 效用沿策略轨迹保持不变；
  - 在线自适应提示方法（GHPO、HINT、ADHint、Stepwise Hints 等）只调整提示的**整体数量或粒度**，仍然把提示视为单一整体，未在原子知识点层面进行子集选择。
- **核心问题**：在线强化学习训练中，**应该注入哪些原子知识点、以及何时重新选择**——这是一个此前被忽略的关键自由度。
- **论文含义**：AdaKP 是第一个在 RL 训练过程中对原子知识点做**在线子集选择**的方法，将静态选择变为动态、可验证、低开销的在线过程，并证明了其在实际竞赛数学基准上的有效性。

## 2. 论文提出的方法论

### 2.1 总体框架

AdaKP 作为 DAPO+GRPO 训练器的**完全加法分支**，不修改优化器、损失函数或 rollout 路径，只改变每个训练步骤中 prompt 的 Hint 块内容，因此可以精确隔离其贡献。

核心设计围绕三个约束展开：
- **C1**：对整个语料库（约 8.8k 题）打分必须分钟级完成，不能使用多 rollout 信号；
- **C2**：单步代理分数噪声大，朴素 top-k 选择会导致选择震荡；
- **C3**：每个问题的候选 KP 池很小（5–7 个），贪婪选择容易过早坍缩到高分割的子集。

每个组件对应解决一个约束。

### 2.2 熵代理（Entropy Proxy）

- 得分定义：  
  `score(q, k) = H(π_proxy(·|q)) − H(π_proxy(·|q ⊕ k))`  
  其中 `H` 是前 K=50 个生成位置的平均首 token Shannon 熵，`q ⊕ k` 是将 KP 注入 Hint 块后的 prompt。
- 理论基础：该熵差等价于“首 token 与 k 的条件互信息”，在期望上按 KP 携带的关于首条解码决策的信息量排序，从而刻画奖励稀疏性的驱动力。
- 实现成本：通过一次 vLLM 前向传播，共享无 KP forward，每个候选 KP 只需 `|P(q)|+1` 次短前向，避免了 rollout 级估计。
- 截断偏差有界：由于 vLLM 只返回 top-L（L=20）log 概率，作者证明了截断重归一化熵的偏差上界为 `ε log|V| + H₂(ε)`，在实际尾质量 ε ≲ 0.05 时可忽略，加上 O(K^{-1/2}) 有限 K 误差。

### 2.3 三个轻量自适应机制

1. **动量平滑器（EMA）**：  
   `s_{q,k}^{(t)} = α · score^{(t)}(q,k) + (1−α) · s_{q,k}^{(t−1)}`，默认 α=0.3。抑制单步噪声，并在训练开始时与静态 CSS 对齐。
2. **退休与复活管理器**：  
   - 每个 KP 维护一个计数器 c_{q,k}，若连续未被选中 n_retire=3 次则退休（从活动池中移除）；
   - 每 m_revive=5 次重评估，以 r_revive=0.1 的比例随机复活已退休 KP，保持探索；
   - 若某问题全部 KP 退休，则回退到缓存选择，保证 Hint 块非空。
3. **自适应调度器**：采用对数退避重评估间隔  
   `Δ(t) = Δ₀ · (1 + log(1 + (t/T)·c))`，默认 Δ₀=200、c=5、T=2960 步。训练早期重评估更频繁，共约 7 次，使在线重选在剩余步数最多时发挥最大作用。

### 2.4 预飞行验证门

- 在训练启动前，对每个 benchmark 分层抽样最多 30 道题（有 |C(q)|≥2 的题），计算 LOO 边际准确率作为地面真值与熵代理得分的 Spearman 秩相关。
- 要求 ρ > 0.6 且 95% bootstrap 置信区间下界 > 0.4，否则阻止训练启动。
- 同时对比了 Max-logit、Perplexity 与 Random 三种替代代理，只有熵代理通过门。

## 6. 论文的主要结论与发现

1. **H1 成立**：KP 的重要性跨策略非平稳。全局平均 Jaccard=0.537，显著低于 0.7 的强非平稳阈值；仅 AIME25 例外（0.730），被认为是噪声。
2. **主效果显著**：AdaKP 在 8 个 benchmark 的平均准确率 71.93%，比静态 CSS 高 +1.85%，在 Hard-3 上高 +3.36%，且没有 benchmark 退化。
3. **收益集中在稀疏奖励区**：最困难的 AIME25、HMMT25、CMIMC25 增益最大（+3.02、+3.54、+3.52），接近饱和的 AMC23、MATH-500 增益最小（+0.23、+0.35），说明收益来自选择质量的提升而非统一分布偏移。
4. **组件消融可解释**：熵代理贡献最大（去掉后掉 1.62），其次为动量（−0.91）、退休机制（−0.73）、固定调度（−0.43）。诊断指标显示健康的选择 churn 应在 0.2–0.5，KP 覆盖率在 0.8 以上。
5. **验证门有效**：熵代理的 Spearman ρ=0.68 且下界 0.55，通过门；Max-logit（0.41）和 Perplexity（0.53）虽显著但不过门，Random 无相关。这证明熵代理的信息量是有效的。
6. **超参数不敏感**：11 个扫描点全部在 1 个点以内变化，其中 Δ₀、n_retire、K 几乎不影响，α 和 ρ_sel 略重要但整体稳健。
7. **成本可忽略**：在线重评估总开销 <1%，而离线 CSS 约等于整个训练成本。

## 7. 优点

- **方法新颖性**：首次将在线子集选择引入原子 KP 注入，填补了“选择哪些 KP + 何时更新”这一空白维度。
- **低成本高可用**：熵代理用一次前向传播替代昂贵 rollout，且 Truncation bias 有理论证明，配合共享 forward 和缓存，开销可忽略。
- **模块化设计**：三大机制分别对应三个具体问题（噪声、探索、时间调度），消融可以精确归因。
- **工程完整性**：实现为 DAPO+GRPO 的加法 fork，无优化器改动，禁用后与上游逐位一致，可复现性强；公开代码、训练日志和脚本。
- **预飞行验证门**：在昂贵训练前用 CPU 分钟级验证代理有效性，将方法级风险转化为可证伪检查，这一先验验证思路值得借鉴。
- **实验诊断深入**：除准确率外，还报告了池 churn、覆盖率等行为指标，帮助理解机制。

## 8. 不足与局限

- **模型规模单一**：所有实验仅 1.5B 规模，未验证 7B 或更大模型的可迁移性（作者自述为下一步工作）。
- **代理冻结**：熵代理使用初始权重，未随训练更新；因此无法直接利用 H1 所记录的策略漂移，不能观察到当前策略下 KP 排名变化，只能通过 EMA 和探索机制间接获益。作者明确承认这是“可部署的第一步”，当前策略重打分是主要未来方向。
- **地面真值近似**：验证门和 H1 测试用 LOO 边际准确率而非完整的 CSS（因为未公开 CSS 搜索代码），可能影响排序语义的精确性（但作者论证 LOO 是 CSS 核心机制，且计算量低两个数量级）。
- **种子单一**：仅 seed 42，没有多次重复实验来估计方差；消融/扫描运行截断至 1500 步，与主运行的 2960 步不完全一致（pilot 确认但存在一定风险）。
- **离线策略评估表 2**：在 OpenMath 上做离线评估，与表 1 的 RL 训练结果不可直接比较，容易造成混淆。
- **Jaccard 测量的粗糙性**：非平稳性检验中 top-30% 集合很小，每 benchmark 的样本量不平衡，个别异常值可能被过度解读。
- **没有与并发在线提示方法直接对比**：虽然定位表将其与 GHPO/HINT/ADHint 等区分，但实验未将 AdaKP 与这些“量变”方法作实证比较，只与静态选择比较。作者说明这是因为它们针对不同轴，但严格说缺乏同场景下的对照。
- **应用范围**：仅针对竞赛数学和 KP 注入场景，较难推广到更一般的推理任务或非文本提示。
