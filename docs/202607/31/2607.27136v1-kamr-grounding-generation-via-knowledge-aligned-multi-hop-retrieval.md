## 摘要
基于图的检索增强生成越来越依赖于多跳检索，其中回答查询需要组合多个连接的知识图谱三元组。然而，现有的检索器通常通过全局语义匹配独立地对三元组进行排序。此外，许多多跳基准只提供最终答案，这限制了对查询-三元组对齐的监督，并导致结构上必要但弱对齐的事实被遗漏。为了解决这些问题，我们提出了一种知识对齐的多跳检索器KAMR，它区分了受查询强约束的锚定三元组与弱对齐但结构上与之相连的连接三元组。为了缓解查询-三元组对齐监督的缺乏，我们通过掩码三元组元素并提示LLM生成相应的查询来构建部分对齐数据集，并优化两个对比目标以进行对级和元素级匹配。在推理时，KAMR全局检索锚定，然后局部扩展以收集连接证据。在四个基准、三个LLM骨干和十四个基线上，KAMR一致地提高了多跳检索和下游问答性能。

## Abstract
Graph-based retrieval-augmented generation increasingly relies on multi-hop retrieval, where answering a query requires composing multiple connected knowledge-graph triplets. However, existing retrievers often rank triplets independently via global semantic matching. Moreover, many multi-hop benchmarks provide only final answers, which limits supervision for query--triplet alignment and causes structurally necessary but weakly aligned facts to be missed. To address these issues, we propose a knowledge-aligned multi-hop retriever, KAMR, which distinguishes anchor triplets that are strongly constrained by the query from connected triplets that are weakly aligned yet structurally linked to the anchors. To mitigate the lack of query-triplet alignment supervision, we build a partial alignment dataset by masking triplet elements and prompting an LLM to generate corresponding queries, and optimize two contrastive objectives for pair-level and element-level matching. At inference time, KAMR retrieves anchors globally and then expands locally to collect connected evidence. Across four benchmarks, three LLM backbones, and fourteen baselines, KAMR consistently improves multi-hop retrieval and downstream question answering performance.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- 论文聚焦于**基于知识图谱的检索增强生成（Graph RAG）**中的**多跳检索**问题。实际问答中，回答一个查询往往需要组合多个在知识图谱中相连的三元组，而非单条孤立事实。
- 现有检索器大多通过**全局语义匹配**对候选三元组独立排序（如 BM25、稠密检索器），忽略了图谱中三元组之间的**结构连通性**；这使得一些与查询文本弱对齐、但在推理链上必需的事实容易被遗漏。
- 另一大难题是**缺乏查询–三元组对齐监督**：许多多跳问答基准（如 CWQ）只提供最终答案，不标注应检索的支撑三元组；即便有标注（如 PathQuestion），也存在查询只约束三元组部分元素的问题，导致训练目标与推理需求不匹配。
- 整体含义：多跳检索不能将全部三元组等同对待，而应区分不同角色，并兼顾“语义相关性”与“结构可组合性”，进而为生成模型提供更完整、可组合的证据链。

## 2. 论文提出的方法论

### 核心思想

- 提出**KAMR（Knowledge-Aligned Multi-hop Retriever）**，将多跳检索目标分为两类：
  - **锚点三元组（Anchor Triplets）**：与查询共享两个元素（头实体/关系/尾实体中的任意两个），语义对齐强、容易被检索到。
  - **连接三元组（Connected Triplets）**：与查询仅共享一个元素，但通过共享实体与锚点或已有证据在图谱中相连，负责补全推理链条，通常弱对齐。

### 关键技术细节

1. **部分对齐数据集构建**：
   - 从 Freebase 中选出与 CWQ 和 PathQuestion 关联的实体三元组，避免数据泄漏。
   - 对每个三元组进行“掩码一个元素”操作，得到三种部分三元组（如 (h,r)、(r,t)、(h,t)），再提示 LLaMA-3.1-8B-Instruct 生成对应的自然语言问题，最终形成约 84 万条合成训练数据。

2. **预训练损失设计**：
   - 总损失 $L = L_a + L_c$。
   - $L_a$（对级对齐）：使用 InfoNCE 损失，将查询编码与部分三元组编码（两个元素拼接后编码）进行对比学习，用于锚点三元组检索。
   - $L_c$（元素级对齐）：同样使用 InfoNCE 损失，但匹配对象是查询编码与单个三元组元素（头实体、关系或尾实体）的编码，用于连接三元组检索。

3. **推理流程**（两阶段）：
   - **锚点检索**：对每个候选三元组，生成其三种部分三元组，取查询与这些部分三元组的最大余弦相似度作为该三元组的打分，选择 Top-M 个作为锚点。
   - **连接检索**：从当前证据集出发，迭代地在其邻域内选取满足“与查询仅共享一个元素且与证据图连通”的候选三元组；打分时使用该三元组中不与已有证据共享的剩余元素与查询的元素级相似度。不断扩展，直到达到预算或无法新增。
   - 最终返回 $T_q = A_q \cup C_q$（锚点与连接三元组合并）。

## 6. 论文的主要结论与发现

- KAMR 在**多跳检索**（Triplet Recall、Path Recall）上显著优于所有基线，尤其在 PQ-3H 上大幅提高 Path Recall（N=2 时 85.78 vs 最强基线约 59.35），表明能更稳定地恢复完整推理链。
- 在**下游问答**中，KAMR 在三个 LLM 骨干上均取得最佳或接近最佳结果，说明结构感知的检索能有效提升生成接地（grounding）质量。
- 消融实验验证：锚点预训练损失 $L_a$ 对模型影响极大（去掉后准确率从 75.86 降至 48.79），连接三元组的元素级损失 $L_c$ 和推理时的局部扩展也都有明显贡献。
- 与基线相比，KAMR 能检索到语义较远但结构相邻的连接三元组（如 Joan of Arc 例子），弥补了全局语义检索的不足。
- 在单跳数据集 WebQSP 上，KAMR 依靠锚点检索仍能达到可比的性能，说明其具备一定的泛化能力。

## 7. 优点

- **问题建模清晰**：明确区分“锚点”与“连接”两类三元组，并给出形式化定义，将“语义对齐”和“结构连通”解耦。
- **免显式多跳监督**：通过三元组掩码 + LLM 生成问题的方式自动构建部分对齐训练数据，避免了对复杂推理路径标注的依赖，增强了适用性。
- **预训练与推理目标一致**：对级损失对应锚点检索、元素级损失对应连接检索，两阶段推理与训练目标自然衔接。
- **实验验证充分**：在多个数据集、多个骨干、多个基线上展现一致改进，且消融实验较完整地验证了各组件必要性。
- **可移植性强**：KAMR 仅作为独立轻量检索器，可与任意 LLM 生成器组合，不需要端到端训练。
