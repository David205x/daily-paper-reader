## 摘要
多视角空间推理要求视觉语言模型跨图像比较视觉证据、对齐对象对应关系，并在长视觉上下文中推断空间关系——在这种场景下，思维链推理往往会变得冗长但准确性并未提升。基于可验证奖励的强化学习天然适合该任务，但标准GRPO奖励依赖于稀疏的结果级反馈，既无法指示推理轨迹出错的位置，也无法控制其长度。我们提出LenGuard-GPC，一个密集奖励框架，同时解决这两个问题。对于每条采样的推理轨迹，它在标准提示和引导提示下比较逐词预测分布，并将产生的逐词KL散度作为密集奖励信号。由于这种KL惩罚会随词元累积，若不加以约束，它会奖励更短的响应而不顾其质量，因此我们引入分阶段长度奖励，将推理长度控制在合理范围内，而非简单鼓励简洁性。在六个多视角空间推理基准上，LenGuard-GPC在降低平均响应长度的同时，相比原始GRPO提升了准确率。

## Abstract
Multi-view spatial reasoning requires vision-language models to compare visual evidence across images, align object correspondences, and infer spatial relations over long visual contexts, a setting where chain-of-thought reasoning tends to grow verbose without becoming more accurate. Reinforcement learning with verifiable rewards is a natural fit for this task, but standard GRPO reward relies on sparse outcome-level feedback and gives no signal about where a reasoning trajectory goes wrong, nor any control over its length. We propose LenGuard-GPC, a dense reward framework that addresses both problems together. For each sampled trajectory, it compares the token-wise predictive distributions under a standard prompt and a guided prompt, and uses the resulting token-sum KL divergence as a dense reward signal. Since this KL penalty accumulates over tokens and would otherwise reward shorter responses regardless of their quality, we introduce a staged length bonus that keeps reasoning length within a controlled range without simply encouraging brevity. On six multi-view spatial reasoning benchmarks, LenGuard-GPC improves accuracy over vanilla GRPO while reducing average response length.

# LenGuard-GPC 论文详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：多视角空间推理要求视觉语言模型（VLM）跨多个图像比较视觉证据、对齐物体对应关系、推断空间关系。在此场景下，链式推理（CoT）容易变得冗长但准确性不增反降。
- **背景**：标准 GRPO（Group Relative Policy Optimization）只提供稀疏的结果级奖励（最终答案正确性），无法定位推理轨迹中具体哪一步出错，也无法控制推理长度。这导致两个困境：
  - 无谓的长轨迹：模型可能描述无关细节，引入错误累积。
  - 无控制的短轨迹：模型可能通过简短回答猜测答案，缺乏充分推理。
- **目标**：设计一种能同时提供密集过程反馈和长度控制的强化学习奖励框架，以提升多视角空间推理的准确性与效率。

## 2. 方法论

### 核心思想
- **引导提示一致性（Guided-Prompt Consistency）**：对于每条采样推理轨迹，比较模型在**标准提示**与**引导提示**下的逐词预测分布（通过 teacher forcing 计算），用 KL 散度衡量两者偏离程度，作为密集过程级奖励。
- **分阶段长度奖励（Staged Length Guard）**：为应对 KL 散度累加天然偏好短回答的偏置，设计分阶段长度奖励，避免模型崩溃为过短回答或边界聚集行为。

### 关键技术细节
1. **引导提示构造**：对每个训练实例，用 GPT-5.3-Chat 生成一句额外的推理指导（h），附加到标准提示中形成引导提示 xgp = (I, q, h)。引导提示仅在训练时用于奖励计算，推理时不需额外开销。
2. **KL 散度奖励**：
   - 对于标准提示 x 下采样的轨迹 y = (y1,...,yT)，计算每个位置 t 的 KL 散度：  
     Dt = DKL( πθ(·|x, y<t) ∥ πθ(·|xgp, y<t) )
   - 累加得到总散度 SKL(y) = Σ Dt，奖励定义为 rKL = -λKL * SKL(y)（λKL = 5×10⁻³）。
3. **分阶段长度奖励 rlen(T)**：
   - 定义三个长度边界 l1=160, l2=360, l3=768（token 数）。
   - 奖励分段：T < l1 得 0；[l1, l2] 从 r1=0.25 线性递增到 r2=0.30；(l2, l3] 保持 r2；T > l3 不再额外奖励。
   - 长度奖励系数 λlen 未明确给出（结合总奖励公式 r = λtask * rtask - λKL * SKL + λlen * rlen，推测 λlen=1）。
4. **总奖励组合**：每条轨迹的总奖励 ri = λtask * (λacc * racc + λformat * rformat) + rKL + rlen，其中 λtask=1, λformat=0.2, λacc=1（注释中未提 λtask 具体值，但实验中似加权求和）。
5. **GRPO 更新**：每组 G 条轨迹，将总奖励归一化得到优势 Ai，然后用标准 GRPO 目标更新策略（无需价值模型）。

### 算法流程（Algorithm 1）
- 输入：训练实例 (I, q, a)，策略 πθ，组大小 G。
- 1. 构造标准提示 x 和引导提示 xgp。
- 2. 从 πθ(·|x) 采样 G 条轨迹 {yi}。
- 3. 对每条轨迹计算 racc, rformat, rKL, rlen，组合成 ri。
- 4. 组内归一化得到优势 Ai。
- 5. 使用标准 GRPO 目标更新 πθ。

## 7. 优点

- **密集过程奖励新颖性**：利用引导提示与标准提示的分布差异作为过程信号，无需额外训练奖励模型或人类标注，计算高效（仅需一次 teacher forcing 前向传播）。
- **长度控制的精细设计**：分阶段奖励不是简单惩罚或奖励长度，而是动态平衡 KL 紧凑性和长度充分性，避免短回答和边界聚集两个极端。
- **低推理开销**：引导提示仅在训练阶段使用，推理时与基线相同，不增加运行时成本。
- **机制通用**：框架可适用于视频理解、文档推理等其他长上下文多模态任务，只需构造相应引导提示。
- **实验设计全面**：包含域内/域外、主结果、细粒度、消融、效率分析多个维度，结果可信。
