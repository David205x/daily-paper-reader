## 摘要
尽管大型语言模型（LLM）因其强大的推理能力和广泛的世界知识最近在推荐系统中受到关注，但以往基于LLM的代理存在幻觉和上下文长度限制，因此不适用于全排序推荐任务。为了通过架构设计而非修改LLM本身来规避这些限制，我们提出了一种基于代理的推荐框架——基于记忆的自主语言代理个性化推荐工具学习（PRTA），其中LLM作为中央规划器，与多个推荐模型作为工具进行交互。基于LLM的代理负责高级推理和个性化工具选择，而传统推荐模型则利用其在行为模式建模中的可扩展性执行全排序评分。为了支持个性化工具选择，我们设计了反思机制，使代理能够根据用户档案和候选排名列表为每个用户评估和比较工具。在三个公共数据集上的大量实验表明，PRTA在全排序推荐性能上优于传统推荐和基于LLM的基线方法。

## Abstract
Although large language models (LLMs) have recently gained traction in recommender systems due to their strong reasoning capabilities and extensive world knowledge, previous LLM-based agents suffer from hallucination and context-length limitations, and thus are not suitable for full-ranking recommendation tasks. To circumvent these limitations through architectural design rather than modifying the LLM itself, we propose an agent-based recommendation framework, memory-based $\textbf{P}$ersonalized $\textbf{R}$ecommendation $\textbf{T}$ool learning via autonomous language $\textbf{A}$gents (PRTA), in which an LLM acts as a central planner interacting with multiple recommendation models as tools. The LLM-based agent is responsible for high-level reasoning and personalized tool selection, while traditional recommendation models perform full-ranking scoring, leveraging their scalability in modeling behavioral patterns. To support personalized tool selection, we design reflection mechanisms that enable the agent to evaluate and compare tools for each user based on user profiles and candidate ranked lists. Extensive experiments across three public datasets demonstrate the superiority of \modelname over traditional recommendation and LLM-based baselines in improving full-ranking recommendation performance.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- **PRTA框架**：基于记忆的个性化推荐工具学习（Personalized Recommendation Tool learning via autonomous language Agents）。LLM作为中央规划器，与多个推荐模型（工具）交互，负责推理与工具选择；传统推荐模型执行全排序评分。
- **每个用户**维护一个**个性化工具记忆（PT Memory）**——一个权重向量，表示各工具的适用性，通过加权聚合各工具排名分数得到最终排名列表。

### 2.2 关键技术细节
- **工具集**：采用三个预训练推荐模型：LightGCN（图结构）、SASRec（序列）、SimpleX（矩阵分解）。
- **用户档案生成**（公式1）：利用LLM根据用户历史交互项的描述生成用户档案。
- **三阶段反射机制**：
  1. **局部工具评估（Local Tool Evaluation）**：LLM评估每个工具返回的top候选列表与用户近期交互的相关性（-1/0/1），按学习率α更新PT记忆权重。
  2. **全局工具比较（Global Tool Comparison）**：LLM在所有工具中选择最相关的一个，按β更新权重，提供跨工具对比视角。
  3. **排序比较（Ranking Comparison）**：基于用户未暴露给工具的最新交互项在工具排名中的位置，以排名倒数归一化更新权重，作为文本评估的补充信号。
- **推理阶段**：加权聚合后对top候选进行**上下文重排（Contextual Reranking）**，进一步基于文本特征微调最终排名。

## 6. 论文的主要结论与发现

- **PRTA在全排序条件下显著优于所有基线和独立工具**，在Amazon上Recall@10提升60%，NDCG@10提升66.15%。
- **解耦设计有效**：传统推荐模型负责行为模式，LLM负责语义推理，避免了LLM直接排序的缺陷。
- **反射机制贡献**：局部评估和全局比较均提供增量收益，上下文重排对语义一致的数据集（Amazon）提升最大。
- **PT记忆可视化**：SASRec（序列推荐）权重普遍偏高，表明顺序模式与用户历史更一致；SimpleX（MF）权重偏低，语义相关性不足。
- **鲁棒性**：PRTA通过聚合多个工具输出，避免单一RAG方法的偏见，比“工具+重排”基线更稳定。

## 7. 优点

- **架构创新**：通过解耦行为建模与语义推理，从架构层面规避LLM的幻觉和上下文限制，无需修改LLM本身。
- **可插拔性**：兼容任何能输出全排序分数的推荐模型，易于扩展。
- **可解释性**：PT记忆中的工具权重直接反映每个用户对不同推荐策略的偏好，提供决策洞察。
- **实验严谨性**：消融实验完整，包含对比多种范式（图、序列、MF、扩散模型等），并考虑了RAG变体。
- **计算高效**：推理阶段每用户<0.5秒，适合作为离线或二阶段重排组件。

## 8. 不足与局限

- **实验规模有限**：数据集用户数较小（最多4303），在百万级用户和亿级商品上的性能未验证。
- **工具选择**：仅采用了三种推荐模型，未探索更多样化或业界常用的召回与排序模型。
