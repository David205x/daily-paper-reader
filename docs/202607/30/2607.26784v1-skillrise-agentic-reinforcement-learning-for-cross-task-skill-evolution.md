## 摘要
大型语言模型智能体经常遇到相关但不同的任务，这些任务共享可复用的解决方案模式。然而，标准的智能体强化学习将任务视为独立的片段，而现有的技能学习方法要么专注于重复尝试同一任务，要么使用多个阶段的流水线，将提取、检索和执行纠缠在一起。我们提出SkillRise，一个统一的强化学习框架，用于跨任务学习技能。SkillRise将相关实例组织成逐渐具有挑战性的序列，并使用单一策略在任务求解和管理一个不断演化的技能文档（该文档直接传递给下一个任务）之间交替。解耦的跨任务信用分配通过当前任务结果监督求解，并通过折扣的下游结果监督管理。在ALFWorld、WebShop和ScienceWorld上的实验表明，SkillRise在比较方法中实现了最强的Pass@1性能，比最强基线提升了2.3到8.5个百分点。尽管在不同任务上训练，其学到的管理策略在重复尝试同一任务时仍然有效。进一步分析显示了跨任务的测试时缩放：即使在每个任务只尝试一次的情况下，随着相关任务序列变长，性能也会提升。这一趋势表明SkillRise跨任务复用可迁移技能，而非受益于同一任务的重复采样。SkillRise在显著降低多阶段技能学习流水线的运行时开销的同时，保持了强大的性能。这些结果共同为LLM智能体提取、提炼和跨任务复用可迁移技能提供了一种简单有效的训练范式。

## Abstract
Large language model agents often encounter related yet distinct tasks that share reusable solution patterns. Yet standard agentic reinforcement learning treats tasks as independent episodes, while existing approaches to skill learning either focus on repeated attempts of one task or use pipelines with multiple stages that entangle extraction, retrieval, and execution. We introduce SkillRise, a unified reinforcement learning framework for learning skills across tasks. SkillRise organizes related instances into progressively challenging sequences and uses a single policy to alternate between task solving and curating an evolving skill document passed directly to the next task. Decoupled credit assignment across tasks supervises solving with the current task outcome and curation with discounted downstream outcomes. Experiments on ALFWorld, WebShop, and ScienceWorld show that SkillRise achieves the strongest Pass@1 performance among the compared methods, with gains over the strongest baseline ranging from 2.3 to 8.5 percentage points. Although trained across distinct tasks, its learned curation policy remains effective for repeated attempts on the same task. Further analysis reveals scaling at test time across tasks: performance improves with longer sequences of related tasks even when each task is attempted only once. This trend suggests that SkillRise reuses transferable skills across tasks rather than benefiting from repeated sampling of the same task. SkillRise further retains strong performance while substantially reducing the runtime overhead of skill learning pipelines with multiple stages. Together, these results provide a simple and efficient training paradigm for LLM agents to extract, refine, and reuse transferable skills across tasks.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 将**相关但不同的任务实例**按难度递增组织成序列，智能体在序列中进行**连续滚动**：先利用当前技能文档解决当前任务，然后根据刚刚的交互轨迹**整理（curate）一个不断演化的技能文档**，该文档作为唯一的信息通道传递给下一个任务。
- 通过**解耦的信用分配**：任务求解只由当前任务结果监督，技能整理则由后续任务的折扣回报监督，使两个行为获得与其时间角色匹配的学习信号。

### 关键技术细节

#### (a) 跨任务序列构建
- 从同一任务族（如ALFWorld中的Pick、Clean等）中选取不同实例，并按难度递增排列（如WebShop中按所需属性和选项数量排序）。
- 序列长度 \(K\)（实验中设为3），每个序列中的任务实例不同，但共享可抽象化的交互常规。

#### (b) 跨任务滚动与技能演化
- **初始化**：技能文档 \(S_0 = \emptyset\)（空）。
- 对序列中的第 \(i\) 个任务：
  - **任务求解**：策略 \(\pi_\theta\) 基于任务指令 \(x_i\) 和当前技能文档 \(S_{i-1}\) 生成轨迹 \(\tau_i\)，获得任务奖励 \(r_i = R(\tau_i)\)。
  - **技能整理**（除最后一个任务外）：同一策略 \(\pi_\theta\) 基于旧文档 \(S_{i-1}\)、轨迹 \(\tau_i\) 和奖励 \(r_i\) 生成新文档 \(S_i\)，该文档将用于下一个任务。
- 注意：只有技能文档跨任务传递，之前的轨迹不保留。每个试次独立从空文档开始演化为自己的文档。

#### (c) 解耦信用分配与角色感知的组相对优化
- **信用分配**：
  - 任务求解：回报 \(G_{i,z}^{\text{solve}} = r_i\)（仅当前任务结果）。
  - 技能整理（\(i < K\)）：回报 \(G_{i,z}^{\text{curate}} = \sum_{j=i+1}^{K} \gamma^{j-i} r_j\)（折扣的下游任务结果），\(\gamma\) 为跨任务折扣因子（实验中设为0.6）。
- **组相对优势**：对同一序列、同一任务位置 \(i\)、同一阶段 \(z\) 下的 \(N\) 个试次，计算平均回报 \(\bar{G}_{i,z}\)，然后每个试次的优势 \(A_{i,z}^{(n)} = G_{i,z}^{(n)} - \bar{G}_{i,z}\)。
- **优化目标**：使用带裁剪的PPO目标联合优化求解和整理阶段的所有token，但各个阶段使用各自的优势值，确保信号不混淆。

## 7. 优点：方法或实验设计上的亮点

- **简洁的端到端形式**：将技能提取、提炼、应用集成在单一策略中，避免外部存储、检索模块和教师模型，易于训练和部署。
- **解耦的跨任务信用分配**：巧妙区分求解和整理两个角色的不同时间作用，使用不同的回报（当前 vs. 折扣下游），使得学习信号清晰，且对折扣因子鲁棒。
- **角色感知的组相对优势**：分组时同时考虑位置和阶段，防止不同角色的优势互相干扰，提升了训练稳定性。
- **渐进式任务序列构建**：从易到难排列相关实例，自然形成课程学习，促进技能迁移。
- **跨任务测试时缩放**：首次在LLM代理中展示出随着相关任务序列变长性能提升的现象，揭示了跨任务泛化的内在能力。
- **充分的消融和对比**：覆盖多种基线、消融关键组件、验证模型规模泛化，论证扎实。

## 8. 不足与局限

- **依赖任务族元数据**：当前方法需要预先知道任务族信息来构建相关序列；在实际开放场景中，自动发现此类关系是重要未来方向（论文也承认这一点）。
- **模型规模限制**：实验限于最大4B参数模型（Qwen3-4B），更大规模（如7B、70B）的评估尚未进行，可能影响结论普适性。
- **基准类型有限**：仅基于三个文本交互环境，缺乏对多模态、真实世界操作、以及不容易获得可验证奖励的任务的评估。
- **技能文档的可解释性**：虽然提供了案例，但未系统分析整理出的技能文档质量（如抽象程度、完整性、一致性）。
- **训练计算成本**：虽然相对多阶段流水线高效，但与其他单任务RL方法相比，SkillRise需同时处理序列和整理阶段，具体绝对训练时间未与普通RL方法（如GRPO）直接对比。
- **序列长度K固定**：实验仅采用K=3进行训练，未测试不同训练序列长度对学习效果的影响（仅在测试时变长）。
